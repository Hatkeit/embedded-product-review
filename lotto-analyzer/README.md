# 로또 6/45 과거 1등 패턴 분석기 (Excel VBA)

과거 1등 당첨번호를 불러와서 **과거 1등 번호들과 통계 패턴이 가장 비슷한 조합**을 계산하는 엑셀 파일입니다.

> **꼭 알아두실 점**
> 로또는 매 회차가 독립된 무작위 추첨이라서, 어떤 계산으로도 당첨확률을 올릴 수 없습니다.
> 모든 조합의 1등 확률은 똑같이 **1 / 8,145,060**입니다.
> 이 파일의 "점수"는 과거 1등 번호들의 패턴과 얼마나 닮았는지를 나타낼 뿐, 당첨 가능성이 아닙니다.

## 파일

| 파일 | 설명 |
|---|---|
| `로또번호_분석.xlsm` | 분석 엑셀 파일 (매크로 포함) |
| `LottoAnalyzer.bas` | 같은 VBA 코드 (매크로가 빠졌을 때 직접 가져오기용) |
| `ThisWorkbook_code.txt` | 파일을 열 때 버튼을 만드는 코드 (ThisWorkbook 모듈용) |
| `build/` | 파일 생성 스크립트, 검증 스크립트 |

## 설치

1. `로또번호_분석.xlsm`을 `C:\Users\END_USER\Dropbox\MPPT\사양서` 폴더에 저장합니다.
2. 인터넷에서 받은 파일은 매크로가 차단됩니다. 파일을 우클릭 → **속성** → 아래쪽 **차단 해제** 체크 → 확인을 누르세요.
3. 엑셀로 열고 **콘텐츠 사용**을 누르면 `설정` 시트에 버튼 2개가 생깁니다.
   버튼이 안 보이면 `Alt+F8` → `EnsureButtons`를 실행하세요.

### 매크로가 안 보일 때 (예비 방법)
1. `Alt+F11`로 VBA 편집기를 엽니다.
2. **파일 → 파일 가져오기** → `LottoAnalyzer.bas`를 선택합니다.
3. 왼쪽의 `ThisWorkbook`을 더블클릭하고 `ThisWorkbook_code.txt` 내용을 붙여넣습니다.
4. **다른 이름으로 저장 → Excel 매크로 사용 통합 문서 (*.xlsm)** 로 저장합니다.

## 사용법

1. `설정` 시트의 **① 당첨번호 엑셀 불러오기** 버튼을 누르고 당첨번호 파일(.xls/.xlsx/.xlsm/.xlsb/.csv)을 고릅니다.
   - 파일 선택 창은 `설정!C4`에 있는 폴더에서 열립니다.
     기본값은 `C:\Users\END_USER\Dropbox\MPPT\_MicroInverter\V2000\DB\MOSFET`입니다.
   - 동행복권 "회차별 당첨번호" 엑셀 다운로드 파일을 그대로 쓸 수 있습니다.
     년도 칸이 병합되어 있거나 최신 회차가 위에 있어도 회차 순서대로 정리됩니다.
   - 직접 만든 파일은 `회차 | 번호1~6 | 보너스` 순서로 작성하고, 제목 줄에 `회차`라는 글자를 넣어주세요.
   - `당첨번호` 시트에 직접 붙여넣어도 됩니다. (A열 회차, B~G열 번호, H열 보너스)
2. **② 추천번호 계산** 버튼을 누르면 결과가 나옵니다.
   - `추천번호` 시트: 추천 조합, 점수, 각 조합의 패턴 값
   - `통계` 시트: 계산 근거 (번호별 출현 횟수, 항목별 분포와 점수)
   - 8,145,060개 조합을 모두 계산하므로 PC에 따라 수십 초 정도 걸립니다. 진행률은 상태표시줄에 나옵니다.

## 계산 방법

규칙이 고정되어 있어서 **같은 데이터와 같은 설정이면 결과가 항상 같습니다.** (난수를 쓰지 않습니다.)

과거 1등 번호에서 다음 10개 항목의 분포를 셉니다.

| # | 항목 | 설정 칸 (가중치) |
|---|---|---|
| ① | 번호별 출현빈도 (전체 회차) | C13 |
| ② | 번호별 출현빈도 (최근 N회, N = C9) | C14 |
| ③ | 6개 번호의 합계 (±7 범위로 묶어서 셈) | C15 |
| ④ | 홀수 개수 | C16 |
| ⑤ | 저번호(1~22) 개수 | C17 |
| ⑥ | 연속번호 쌍의 수 | C18 |
| ⑦ | 끝수(일의 자리) 종류 수 | C19 |
| ⑧ | 한 구간(1~9, 10~19, 20~29, 30~39, 40~45)에 몰린 최대 개수 | C20 |
| ⑨ | 직전 회차와 겹치는 번호 수 | C21 |
| ⑩ | AC값 (번호 사이 차이값의 다양성) | C22 |

- 각 조합의 점수는 `Σ 가중치 × ln(과거 1등에서 그 값이 나온 비율)`입니다.
  번호빈도 항목은 평균 대비 비율에 ln을 씌운 값을 씁니다.
  과거 1등 조합에서 자주 나온 패턴일수록 점수가 높고, 0에 가까울수록 "흔한 패턴"입니다.
- 1단계에서는 8,145,060개 조합 전체를 ①~⑨ 기준으로 채점하고 상위 20,000개를 남깁니다.
- 2단계에서는 남은 조합에 ⑩ AC 점수를 더해 다시 순위를 매깁니다.
- 위에서부터 고르되, 추천 조합끼리 겹치는 번호가 `C8`개를 넘지 않게 합니다.
- `C10 = Y`이면 이미 1등으로 나왔던 조합은 뺍니다.
- 점수가 같으면 번호가 작은 조합이 먼저 옵니다.
