입력: `pstxprt.dat` / `pstchip.dat` / `pstxnet.dat` (PSTWRITER 17.4, 2026-09-21). 부품 651개, 넷 360개, 회로도 10페이지.

|---|---|
| `floorplan_top.svg/.png` | 상면(부품면) 배치 계획도 — 패키지 심볼 실제 크기, 하면 부품은 점선 고스트, 소형 SMD는 군집 면적 |
| `floorplan_bottom.svg/.png` | 하면(서멀패드면, 좌우 반전) — 발열 高 부품, 서멀패드 접촉 존, THT 리드 돌출(접촉 불가) 영역 |
| `parts_classification.csv` | 651부품 전체: 페이지/블록, PSM, **SMT/THT**, **상면/하면**, 발열 등급(H/M/L), 배치 좌표 또는 군집, 주요 넷 |
| `placement_draft_allegro.txt` | 개별 배치 168부품의 좌표 초안 (mm, 좌하단 원점, MIRROR=YES 는 하면). Allegro File → Import → Placement 형식과 대조 후 사용 |

## 2. 하면 서멀패드 존

| 존 | 부품 | 부품 높이 | 비고 |
|---|---|---|---|
| A-FET / B-FET | Q1~Q4 + U13 / Q5~Q8 + U14 | 1.0 mm (PQFN 5×6) | 드라이버를 FET 중앙에, 게이트 ≤ 15 mm |
| A-SiC / B-SiC | D3, D8 / D14, D19 | 4.5 mm (D2PAK) | PHV 정류, 캐소드 탭 = PHV 전위 → 절연 서멀패드 필수 |
| C-UNFOLD | D23, D24, Q12 (DPAK) + Q13, Q14 (D2PAK) + 소스 션트 R200/201/211/212 | 2.4 / 4.6 mm | 두 단 페데스탈 또는 갭필러 |

존별 높이가 다르므로 히트싱크(케이스) 쪽에 페데스탈 높이를 달리하거나 1~2 mm 갭필러로 흡수. THT 리드가 돌출하는 영역(빗금)은 히트싱크와 접촉 불가 → 존과 겹치지 않게 배치했음.

트랜스 T2/T4/T6/T8/T9 는 DIP 타입으로 **상면** 실장. FET 존(1차 핀 쪽)과 SiC 존(2차 핀 쪽) 사이에 두고, 하면의 트랜스 리드 영역은 히트싱크 릴리프 포켓으로 처리. 코어 방열은 상부 커버 갭필러 또는 포팅으로.

## 3. Enphase IQ7 대비

| 항목 | 이 설계 (250×250 계획) | Enphase IQ7 |
|---|---|---|
| 외형 | 보드 250 × 250 mm (62,500 mm²) | 212 × 175 × 30.2 mm (케이스, 37,100 mm²), 1.08 kg |
| 두께 요인 | 전해캡 12개 눕힘 실장(높이 ≈ 19 mm) + DIP 트랜스 높이(확인 필요) + PCB + 하면 히트싱크 | 30.2 mm, 완전 포팅 |
| 입력 | PV 2채널(A/B) 독립 MPPT, 채널당 2700 µF×6 | PV 1채널 |
| 방열 | 하면 SMT 전력소자 → 절연 서멀패드 → 케이스 | 포팅 + 케이스 |

전해캡 12개를 눕혀 좌측 세로 컬럼(x 13~57, 각 44 × 18.5 mm)에 배치. 상면 최대 높이는 이제 DIP 트랜스(T2/T4/T6/T8)가 결정하므로 트랜스 높이 확인이 필요. 캡 몸체는 접착/홀더 고정, 리드 끝은 FET 쪽.

## 4. KS/IEC 관점 — 이 배치가 반영한 것과 아직 검증되지 않은 것

이 도면은 기능 블록 배치도이며 KS 적합성 검증을 거친 배치가 아니다. 적용 표준은 KS C 8565(소형 태양광 인버터, 계통연계형), KS C IEC 62109-1/-2(PV 전력변환장치 안전), KS C IEC 60664-1(절연 협조), KS C IEC 62116(단독운전 방지 시험)이며, 배치 단계에서 반영한 항목과 실제 보드에서 확인해야 할 항목은 다음과 같다.

| 항목 | 배치에 반영 | 실제 보드에서 확인 필요 |
|---|---|---|
| 절연 협조 (1차 PV·제어 ↔ 2차 PHV·AC) | 절연 경계 x=140, 경계 통과 부품은 트랜스·옵토·AMC 만 | 넷 쌍별 연면/공간거리를 Constraint Manager 에 넣고 DRC: 400 V PD2 CTI≥175(IIIa) 기준 기본 4.0 / 강화 8.0 mm 연면, OVC III 4 kV 임펄스 기준 기본 3.0 / 강화 5.5 mm 공간거리 (KS C IEC 60664-1 표 값으로 재확인) |
| 경계 통과 부품 | ELD207·FOD817 연면 부족 가능성 플래그 | 옵토·트랜스 보빈(1차-2차 핀 간 ≥ 8 mm, 3중 절연선/마진 테이프) 인증서 확인 |
| 하면 전력소자 ↔ 히트싱크(케이스) | PHV/드레인 전위 탭 → 절연 서멀패드 전제 | 패드 내전압(≥ 4 kV, 강화 또는 기본+PE 본딩), 케이스 PE 본딩 저항 ≤ 0.1 Ω (J5/J10/J17/J18 FGND) |
| 보호 소자 | MOV·SIDACtor·Y캡을 AC 탭·PE 근처, 퓨즈 F1 L 라인 | Y캡 등급(Y1/Y2), 접촉전류 한도, F2/I_GRID_LK 경로 의도 |
| 계통 차단 | LS1 릴레이 + Q13/Q14 반도체 스위치 직렬 | KS C 8565 / 62109-2 의 독립 2중 차단 수단 요건 충족 여부는 회로 설계에서 확인 |
| EMC | CM 초크 L7/L8·X/Y캡을 AC 탭 바로 앞, ESP32 안테나 에지 | 실측 (KC 전자파 기준) |

## 5. 넷리스트에서 확인 필요한 항목 (배치 전 수정 권장)

1. **`NC` 네트에 122핀이 묶여 있음** (U17/U16 등의 미사용 핀). Allegro 로 가면 실제로 서로 연결됨 → Capture 에서 No-Connect 처리 또는 NC 네트 제거.
2. **T7 (PV_B 채널, 2페이지) 전류 트랜스 핀 4/5/6/8 이 `PV_A+`** 에 연결됨. T5 는 `PV_B+`. 오결선 의심.
3. **R219 / R228 (20 mΩ 2512)** 가 `AC_L_IN`, `AC_N_IN` 을 같은 노드(N17987925, U10 IN1+, D42 로 VDDA_3V3/GND 클램프)에 연결 → L–N 40 mΩ 단락 형태이며 절연 경계를 넘음. 20 MΩ 분압 의도라면 절연 정격 저항 체인으로 변경.
4. **C162 / C164 (0.33 µF X2)** 가 `PV_B+` ↔ `I_GRID_LK`(F2, J18 FGND) 연결. PV+ → 섀시 Y 경로이면 Y1/Y2 등급·위치(양면에 걸침) 확인. J18 은 GND_EARTH 가 아니라 I_GRID_LK.
5. **절연 부품 연면거리**: ELD207(mini-flat), FOD817D3SD 는 400 V 급 강화절연(≥ 8 mm)에 부족할 수 있음. MOC3063S(SMD DIP-6), AMC3301/3302(SOIC-16W) 는 8 mm 급.
6. **CUSTOM 트랜스 T2/T4/T6/T8/T9** 가 SMD CT 와 같은 8.4×7.2 mm PSM(XFMR185P838X721X550-8) 을 쓰고 있음 → DIP 풋프린트로 교체 후 배치 (도면은 26×22 / 16×14 자리표시).
7. DNP 표시 부품: RV2, D37, C52 (VALUE = NC).
8. ESP32-S3-WROOM 내장 안테나: 금속 케이스 안에서는 동작 불가 → 외부 안테나 모듈(-1U) 또는 케이스 창 검토.
