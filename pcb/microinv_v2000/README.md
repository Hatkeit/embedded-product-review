입력: `pstxprt.dat` / `pstchip.dat` / `pstxnet.dat` (PSTWRITER 17.4, 2026-09-21). 부품 651개, 넷 360개, 회로도 10페이지.

## 2. 하면 서멀패드 존

| 존 | 부품 | 부품 높이 | 비고 |
|---|---|---|---|
| A-FET / B-FET | Q1~Q4 + U13 / Q5~Q8 + U14 | 1.0 mm (PQFN 5×6) | 드라이버를 FET 중앙에, 게이트 ≤ 15 mm |
| A-XFMR / B-XFMR | T2, T4 / T6, T8 | ≤ 8 mm (평면형 가정) | CUSTOM PSM 자리표시 26×22. 높이 > 8 mm 이면 상면 이동 또는 히트싱크 포켓 |
| A-SiC / B-SiC | D3, D8 / D14, D19 | 4.5 mm (D2PAK) | PHV 정류, 캐소드 탭 = PHV 전위 → 절연 서멀패드 필수 |
| C-UNFOLD | D23, D24, Q12 (DPAK) + Q13, Q14 (D2PAK) + 소스 션트 R200/201/211/212 | 2.4 / 4.6 mm | 두 단 페데스탈 또는 갭필러 |

존별 높이가 다르므로 히트싱크(케이스) 쪽에 페데스탈 높이를 달리하거나 1~2 mm 갭필러로 흡수. THT 리드가 돌출하는 영역(빗금)은 히트싱크와 접촉 불가 → 존과 겹치지 않게 배치했음.

## 3. Enphase IQ7 대비

| 항목 | 이 설계 (250×250 계획) | Enphase IQ7 |
|---|---|---|
| 외형 | 보드 250 × 250 mm (62,500 mm²) | 212 × 175 × 30.2 mm (케이스, 37,100 mm²), 1.08 kg |
| 두께 요인 | 전해캡 18×40 mm 12개 (상면 40 mm) + 하면 히트싱크 → 45~50 mm 이상 | 30.2 mm, 완전 포팅 |
| 입력 | PV 2채널(A/B) 독립 MPPT, 채널당 2700 µF×6 | PV 1채널 |
| 방열 | 하면 SMT 전력소자 → 절연 서멀패드 → 케이스 | 포팅 + 케이스 |

전해캡 12개가 면적·두께·수명을 지배함. IQ7급 두께를 목표로 하면 필름/폴리머 캡 또는 캡 수량 재검토가 필요.

## 4. 넷리스트에서 확인 필요한 항목 (배치 전 수정 권장)

1. **`NC` 네트에 122핀이 묶여 있음** (U17/U16 등의 미사용 핀). Allegro 로 가면 실제로 서로 연결됨 → Capture 에서 No-Connect 처리 또는 NC 네트 제거.
2. **T7 (PV_B 채널, 2페이지) 전류 트랜스 핀 4/5/6/8 이 `PV_A+`** 에 연결됨. T5 는 `PV_B+`. 오결선 의심.
3. **R219 / R228 (20 mΩ 2512)** 가 `AC_L_IN`, `AC_N_IN` 을 같은 노드(N17987925, U10 IN1+, D42 로 VDDA_3V3/GND 클램프)에 연결 → L–N 40 mΩ 단락 형태이며 절연 경계를 넘음. 20 MΩ 분압 의도라면 절연 정격 저항 체인으로 변경.
4. **C162 / C164 (0.33 µF X2)** 가 `PV_B+` ↔ `I_GRID_LK`(F2, J18 FGND) 연결. PV+ → 섀시 Y 경로이면 Y1/Y2 등급·위치(양면에 걸침) 확인. J18 은 GND_EARTH 가 아니라 I_GRID_LK.
5. **절연 부품 연면거리**: ELD207(mini-flat), FOD817D3SD 는 400 V 급 강화절연(≥ 8 mm)에 부족할 수 있음. MOC3063S(SMD DIP-6), AMC3301/3302(SOIC-16W) 는 8 mm 급.
6. **CUSTOM 트랜스 T2/T4/T6/T8/T9** 가 8.4×7.2 mm 자리표시 PSM(XFMR185P838X721X550-8) 사용 → 실제 풋프린트로 교체 후 배치.
7. DNP 표시 부품: RV2, D37, C52 (VALUE = NC).
8. ESP32-S3-WROOM 내장 안테나: 금속 케이스 안에서는 동작 불가 → 외부 안테나 모듈(-1U) 또는 케이스 창 검토.
