# 1편 — 1ED3431 상태핀 RDYC·FLT_N, 정상은 평선이다

## 본문

MicroInv 500W 보드에 1ED3431MU12M을 10개 썼다. DC/DC 4채널, DC/AC 4채널, 클램프 2채널.
브링업하면서 상태핀 때문에 가장 많이 헤맸으므로 먼저 정리한다.

**소제목: 이름이 아니라 극성**

핀 이름이 RDYC와 FLT_N이다. 슬래시나 언더바가 붙은 쪽이 Low active다.

- **RDYC** — pin 5. High active. 준비되면 HIGH로 릴리즈
- **FLT_N** — pin 6. Low active. 고장이면 LOW

**정상은 둘 다 HIGH.** 의미는 정반대인데 레벨이 같다.
"FLT/RDY"로 뭉뚱그려 부르면 헷갈린다.

**소제목: 둘 다 오픈드레인이고, 입력이기도 하다**

외부 풀업 필수. 데이터시트 §3.2가 typical 2.2kΩ을 VCC1으로 올리라고 한다.
우리 보드는 4.7kΩ(R219/R220 → P3V3)을 썼다. 동작은 하지만 임피던스가 2배라 노이즈에 약하다.

그리고 §4.3.2/§4.3.3 — 이 두 핀은 **출력이면서 fault-off 입력**이다.
외부에서 LOW로 당기면 드라이버가 명령으로 받는다.
그래서 레일에 직결하면 안 되고(관통 전류), 띄워도 안 된다(노이즈가 명령이 됨).

내부 풀다운이 1MΩ(Table 12) 있으므로, 외부 풀업이 없으면 LOW로 읽힌다.

**소제목: 정상 파형은 사실 파형이 아니다**

정상 운전에서 두 핀은 완전한 DC HIGH다. PWM이 아무리 토글해도 반응하지 않는다.
뭔가 그려지면 이미 무슨 일이 일어난 거다.

볼 가치가 있는 구간은 둘.

**전원 투입 시퀀스** (§4.1, §4.2.1)
1. VCC1이 V_UVLO1H 넘음 → 입력측 기동, ADJA/ADJB 판독
2. VCC2가 V_UVLO2H 넘음 → 출력측 기동
3. 설정 전송 + 자체 시험, 기동 지연 약 200µs
4. RDYC 릴리즈 HIGH

이 구간의 RDYC LOW는 정상이다. 그리고 FLT_N은 IC가 어서트하지 않으므로
VCC1 풀업을 따라 처음부터 HIGH다.

**스위칭 중** — 완전한 평선이어야 한다.

**소제목: 상태 조합**

| RDYC | FLT_N | 의미 |
|---|---|---|
| HIGH | HIGH | 정상 |
| HIGH | LOW | 드라이버는 건강, 애플리케이션 고장 래치 |
| LOW | HIGH | 준비 안 됨 (전원·통신·ON핀) |
| LOW | LOW | 둘 다 눌림 — 외부·배선 |

두 번째 줄이 중요하다. **RDYC=HIGH는 VCC1/VCC2 UVLO 해제, 내부 절연 통신 정상,
ADJ 판독 성공을 한 번에 증명한다.** 우리 보드는 6채널이 한 버스에 묶여 있어서,
RDYC가 HIGH면 그 6개가 전부 정상이라는 뜻이다.

**소제목: Table 5 — 출력이 실제로 어떻게 되나**

| 조건 | ON | OFF |
|---|---|---|
| 정상 IN=H | high | tri-state |
| 정상 IN=L | tri-state | low (하드 스위칭) |
| RDYC H→L | → tri-state | → **fault off (soft-off)** |
| FLT_N H→L | → tri-state | → **fault off (soft-off)** |
| VCC1 손실 | → tri-state | → fault off |
| VCC2 손실 | tri-state | **active shut down** |

핵심: **모든 비정상 경로의 턴오프는 soft-off**다. 정상 턴오프만 하드 스위칭.
그리고 RDYC나 FLT_N이 LOW면 IN은 완전히 무시된다(표의 x).

**삽입 이미지**: 기동 시퀀스 다이어그램 / 정상 스위칭 평선 / Table 5

# 2편 — RDYC가 LOW에서 안 올라온다: 원인과 진단

## 본문

전원을 넣었는데 RDYC가 LOW에서 꿈쩍도 안 한다.

**소제목: RDYC가 LOW가 되는 조건은 6가지뿐 (§4.3.2 ready sources)**

1. VCC1 < UVLO1
2. VCC2 < UVLO2
3. **VEE2 over GND2 연결 실패** — 검출 임계 V_VEE2,NC = 0.5V
4. 내부 절연 신호 전송 이상
5. **ON 핀 전압이 VEE2 + 2V 이상** (기동 시 스위치가 꺼져 있어야 함)
6. 외부에서 LOW 구동

여기 **과온이 없다.** 과온은 FLT_N 쪽이다(§4.3.3). FLT_N의 고장원은
DESAT과 과온 두 가지뿐. 이걸 헷갈리면 엉뚱한 데를 판다.

**소제목: 1분 측정 — 전압값이 범인을 가른다**

4.7kΩ 풀업 + P3V3 기준.

| 실측값 | 의미 |
|---|---|
| 0.05~0.35V | 능동 싱크. 진짜 어서트 (V_OL max 300mV @ 5mA) |
| 0.6~0.8V | 다이오드 클램프 — MCU 미전원 시 ESD 경로 |
| 1~2.5V | 누설 분압 — 잔사 |
| ~0V (수Ω) | 물리 단락 |
| 약 2.9V | MCU 내부 풀다운(40kΩ)과의 분압 |

마지막 줄이 유용하다. **내부 풀다운만으로는 LOW가 안 된다.**
0.4V 이하면 누군가 능동적으로 당기고 있는 것.

**소제목: 실제 원인 — 플럭스 잔사였다**

수삽 보드. 전원 정상, 부품 정상. 그런데 RDYC가 안 올라옴.

세척하니 살아났다.

메커니즘은 두 가지 가능성이 있다.

첫째, **ADJB 판독 노드.** Table 4를 보면 ADJB가 1.05kΩ 미만이거나 GND1에 단락되면
"stopped — 게이트 드라이버 동작 정지"다. 우리 보드는 1.33kΩ(set up 0)을 썼는데,
정지 경계까지 여유가 21%뿐이다. 계산하면 **병렬 누설 약 5kΩ이면 정지 영역**.

둘째, **RDYC 네트 자체.** 4.7kΩ 풀업에 11kΩ 누설이면 노드가 2.31V가 되는데
이게 V_IH(70% of 3.3V = 2.31V) 경계다. **RDYC 네트가 ADJB보다 오히려 민감하다.**

어느 쪽이었는지는 확정 못 했다. 다만 둘 다 고임피던스 노드이고, 세척으로 해결됐다.

**소제목: no-clean이라도 인두 부위는 세척**

no-clean은 리플로우 프로파일로 완전 열처리되는 전제다.
**인두로 국부 가열한 잔사는 활성 상태로 남는다.** 수삽·리워크 부위는 반드시 세척.

**삽입 이미지**: 전압 판별 표 / ADJB 설정 표(경계 강조)

# 3편 — ADJA·ADJB, 저항 하나로 정하는 보호 파라미터

## 본문

1ED34x1은 **입력측에 저항 하나만 달면 출력측 보호 동작이 설정된다.**
편리한데 함정도 있다.

**소제목: 무엇을 정하나**

- **ADJA (pin 3)** — soft-off 전류. 15~233mA (1ED3431M)
- **ADJB (pin 4)** — DESAT 리딩에지 블랭킹 + 필터 시간

둘 다 GND1으로 저항 1개. **1.33kΩ ~ 28.0kΩ, E96 1% 중 지정된 16개 값만 유효** (Table 13).

**소제목: 동작 원리**

원래 이런 설정은 고압측에 부품을 붙여서 한다. 이 IC는 그걸 없애고,
**기동할 때 저항값을 읽어 16단계 코드로 변환한 뒤 절연 배리어 너머로 전송**한다(§4.2.1 step 2).

**소제목: 대가 첫째 — 기동 시 1회만 읽는다**

§4.4.2: "The gate driver IC reads the resistor value once during start-up."
다음 전원 차단까지 유지된다. **저항을 바꾸면 반드시 콜드 파워사이클.**

**소제목: 대가 둘째 — 양 끝의 의미가 핀마다 반대다**

| | < 1.05kΩ 또는 GND1 | > 45.3kΩ 또는 VCC1 |
|---|---|---|
| ADJA | default 146mA | **동작 정지** |
| ADJB | **동작 정지** | default (leb 400ns, filter 225ns) |

**ADJB는 낮은 쪽이 정지다.** 우리 보드는 ADJA·ADJB 모두 1.33kΩ = set up 0.
- ADJA 1.33kΩ → soft-off **15mA** (선택 가능한 최소값)
- ADJB 1.33kΩ → 블랭킹 650ns / 필터 1575ns

ADJB가 정지 경계 바로 위다.

**소제목: 설정 표 (1ED3431M)**

| set up | 저항 | ADJA soft-off | ADJB 블랭킹/필터 |
|---|---|---|---|
| 0 | 1.33k | 15mA | 650 / 1575ns |
| 1 | 1.58k | 29mA | 650 / 1775ns |
| 2 | 1.91k | 44mA | 650 / 1975ns |
| 3 | 2.26k | 58mA | 650 / 2375ns |
| 4 | 2.74k | 73mA | 650 / 2775ns |
| 5 | 3.32k | 87mA | 650 / 3175ns |
| 6 | 4.02k | 102mA | 650 / 3575ns |
| 7 | 4.87k | 116mA | 650 / 3975ns |
| 8 | 5.90k | 131mA | 1150 / 3975ns |
| 9 | 7.15k | 146mA | 1150 / 3575ns |
| 10 | 8.66k | 160mA | 1150 / 3175ns |
| 11 | 10.7k | 175mA | 1150 / 2775ns |
| 12 | 13.7k | 189mA | 1150 / 2375ns |
| 13 | 17.4k | 204mA | 1150 / 1975ns |
| 14 | 23.2k | 218mA | 1150 / 1775ns |
| 15 | 28.0k | 233mA | 1150 / 1575ns |

**소제목: 표가 V자 구조라는 게 유용하다**

블랭킹이 setup 0~7은 650ns, 8~15는 1150ns이고 필터는 증가했다 감소한다.
그래서 **set up 0(1.33k)과 set up 15(28.0k)는 필터가 1575ns로 똑같고 블랭킹만 다르다.**

→ **ADJB를 28.0kΩ으로 바꾸면 DESAT 특성은 그대로면서 블랭킹은 늘고,
정지 경계에서 20배 이상 멀어진다.** 바꿀 예정.

ADJA도 15mA는 너무 느리다. IPB339N20NM6의 Q_g가 약 26nC(15V 환산)이므로
게이트 방전에 1.7µs가 걸린다. RDYC 복귀 지연으로 이어지므로 10.7kΩ(175mA)으로 올릴 것.

참고로 데이터시트 표준 응용 회로(Figure 17)는 **ADJA·ADJB 모두 10kΩ**을 쓴다.

**삽입 이미지**: 설정 표 / 경계값 계산

# 4편 — 턴오프 게이트 저항 0옴이 RDYC를 떨어뜨렸다

## 본문

증상.

- VCC1/VCC2 인가하면 RDYC·FLT_N 둘 다 HIGH (정상)
- **IN+에 PWM을 넣는 순간 RDYC가 LOW**
- PWM 끄면 복귀
- MCU를 떼고 시험해도 재현 → 펌웨어·핀 설정 문제 아님

**소제목: 게이트망을 다시 읽었다**

회로도를 정밀 추적하니 실제 결선이 이랬다.

```
ON  (12) ─┬─[ R55 40.2Ω ]─┬─ GATE   ← 두 개 병렬 = 20.1Ω
          └─[ R56 40.2Ω ]─┤
OFF (11) ───[ R54  0Ω   ]─┤
CLAMP(10) ──[ R189 0Ω   ]─┘
```

R55·R56이 ON 핀에 병렬로 붙어 있고, **턴오프는 0Ω**이었다.

**소제목: 계산**

데이터시트 Table 14: R_DSON,H typ 1.12Ω, R_DSON,L typ 0.82Ω.
MOSFET 내부 R_g는 1.5Ω으로 가정.

| | 총 저항 | 밀러 전류 | 밀러 구간 |
|---|---|---|---|
| 턴온 20.1Ω | 22.7Ω | 0.42A | 12ns |
| **턴오프 0Ω** | **2.3Ω** | **2.4A** | **2ns** |

di/dt = 2.4A / 2ns = **1.2 × 10^9 A/s**

**소제목: 그 전류가 흐르는 경로**

턴오프 전류는 게이트 → OFF 핀 → VEE2로 빠지는데, MOSFET 소스는 GND2로 돌아온다.
**즉 VEE2(9·16번)와 GND2(15번) 사이 경로에 이 전류가 흐른다.**

그리고 §4.2에 이런 기능이 있다.

> "The gate driver IC has a built-in connection check for VEE2.
> A loss of VEE2 connection will be detected and signaled via RDYC."

검출 임계는 Table 11의 **V_VEE2,NC = 0.5V**.

L·di/dt로 계산하면 **경로 인덕턴스 0.5nH만 있어도 0.6V**. 5nH면 6V.
정상적인 패턴 인덕턴스만으로도 임계를 넘을 수 있는 조건이었다.

PWM이 없으면 전류가 0이라 전압도 0 → RDYC HIGH.
PWM을 넣으면 매 턴오프마다 발생 → RDYC LOW. **증상과 정확히 일치.**

**소제목: 해결**

R54를 0Ω → **15Ω**으로 교체. 그리고 같이 DESAT 감지망도 연결했다.
결과: PWM 인가 중에도 RDYC·FLT_N 둘 다 HIGH 유지.

15Ω이면 턴오프 밀러 전류가 0.32A, 밀러 구간 16ns로 di/dt가 약 8분의 1이 된다.

**소제목: 다만 확정은 못 했다**

두 가지를 동시에 바꿔서 어느 쪽이 원인이었는지 모른다.
DESAT 핀을 0Ω으로 GND2에 직결했던 것도 문제였을 수 있다 —
GND2 바운스가 핀에 그대로 실려 절대최대(-0.3V)를 순간 침범하면
출력측 로직이 교란되고, 그러면 ready source 4번(내부 신호 전송)이 무너진다.

**확정하려면 DESAT은 연결한 채 OFF만 0Ω으로 되돌려 재현**하면 된다.
나머지 9채널에 무엇을 적용할지가 이 결과로 정해진다. (TODO)

**소제목: 배운 것**

게이트 저항은 스위칭 속도만 정하는 게 아니라
**IC 자신의 감시 회로가 견딜 수 있는 di/dt를 정하는 것**이기도 하다.

그리고 이런 문제의 답은 전기적 특성 표가 아니라 **기능 설명 절**에 있다.
"이 IC가 무엇을 감시하는가"를 읽어두지 않으면 원인에 도달할 수 없다.

**삽입 이미지**: 게이트망 결선도 / 저항값별 계산표 / 턴오프 전류 경로

# 5편 — RDYC·FLT_N을 공통으로 묶을 때 알아야 할 것

## 본문

우리 보드는 DC/DC 4채널 + 클램프 2채널 = **6개의 RDYC가 한 노드**,
FLT_N도 마찬가지다. 풀업은 각각 4.7kΩ 하나씩(R219/R220 → P3V3).
MCU로는 RDY_DDC → pin 120, RDY_DAC → pin 121, FLT_DDC → pin 93.

한 채널만 문제 생겨도 전체를 세우려는 의도로 이렇게 배선했다.

**소제목: 이건 데이터시트 권장 구조다**

§4.3.2: "In a typical application the RDYC pins of all gate driver ICs
in the inverter are connected together and form a single wire RDYC signal."

FLT_N도 §4.3.3에 같은 문장. 즉 정상적인 설계다.
(처음엔 이걸 구조적 결함으로 오해했다가 데이터시트 보고 정정했다.)

**소제목: 첫째 — 어느 채널인지 알 수 없다**

RDYC는 6개의 AND. 하나만 준비 안 돼도 라인은 LOW이고 전기적으로 구분할 방법이 없다.
Infineon 커뮤니티에도 같은 사례가 올라와 있다.

브링업에서는 뼈아프다. 대책:
- 채널별 풀업 자리(R50/R51 계열, 현재 NC)를 살려두고 디버그 때 버스를 끊을 수 있게
- 다음 리비전에서는 섹션 단위로라도 분리

**소제목: 둘째 — 글리치 내성이 100ns뿐이다**

Table 16: t_RDYCMIN, t_FLT_NMIN = 85 / 100 / 115ns.

즉 **115ns를 넘는 교란 한 번이면 묶인 6채널 전부 fault-off**다.
그리고 §4.3.2.1:

> "After an external RDYC low signal the IC is actively pulling RDYC to low
> until the voltage at ON pin falls below the VEE2+2V threshold."

여기에 t_SSIO(입출력 재동기) 최대 13µs가 더해진다.
게다가 fault-off는 soft-off라 ADJA 설정을 따르는데, 우리는 15mA(최소값)라
게이트 방전에만 1.7µs가 걸린다.

**결과: 교란 1회 → RDYC LOW가 15µs 이상으로 확대.**
PWM 50kHz(주기 20µs)에서 사이클마다 한 번씩 교란이 오면
**멀티미터로는 그냥 DC LOW로 보인다.** 실제로는 반복 중인데도.

그래서 이런 증상은 반드시 **스코프로 시간축을 확대**해서 봐야 한다.
한 번 떨어져 계속 LOW인지, 15µs 단위 반복인지에 따라 원인이 완전히 다르다.

**소제목: 셋째 — 클리어는 상승 에지에서 일어난다**

§4.3.2.2. RDYC를 t_CLRMIN(typ 1.0 / max 1.2µs) 이상 LOW로 당겼다가
**놓는 상승 에지**에서 FLT_N이 클리어된다. 추가 조건도 있다.
- IN이 LOW
- ON 핀이 VEE2+2V 아래
- 고장 원인 해소

**LOW로 유지하면 영원히 안 풀린다.** 그리고 MCU 핀을 입력 전용으로만 두면
고장 한 번에 전원 재투입 외에 복구 방법이 없다. 클리어 루틴 구현 필요. (TODO)

**소제목: 넷째 — MCU 핀 설정**

이 핀들은 입력 겸용이라 MCU가 출력 LOW를 내면 그대로 차단 명령이다.
확인할 것:

- 리셋 직후 기본 상태
- 초기화 코드가 포트를 일괄 설정하며 덮어쓰지 않는지
- **타이머 대체기능 매핑에 pin 120/121이 포함되지 않는지** —
  PWM을 켜는 순간 그 핀이 타이머 채널로 전환되면 증상이
  "PWM 인가 시 RDYC LOW"로 나타난다
- 초기화 순서는 **값을 먼저 1로 쓰고 모드를 나중에**

부작용 하나. RDYC가 흔들렸다 복귀할 때마다 그 상승 에지가
**6채널 전부의 FLT 래치를 지운다.** RDYC가 불안정한 동안의 FLT 관측값은 신뢰할 수 없다.

**소제목: 정리**

공통 배선 자체는 정상 설계다. 다만 네 가지를 모르면 브링업에서 며칠을 쓴다.

- 채널 구분 수단을 설계 단계에서 남겨둘 것
- 글리치 내성 100ns를 감안해 배선·풀업(2.2kΩ)·필터를 설계할 것
- 클리어 시퀀스를 펌웨어에 구현할 것
- MCU 핀은 입력 또는 오픈드레인으로 고정, 대체기능에서 제외

**삽입 이미지**: 공통 버스 구조도 / 교란 확대 타임라인 / 클리어 시퀀스
