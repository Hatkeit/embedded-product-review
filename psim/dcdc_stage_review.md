# DC/DC 단(段) 적합성 검토 — 마이크로인버터 전단(前段)

**검토 대상 문헌**
Ravyts et al., *"Practical Considerations for Designing Reliable DC/DC Converters, Applied to a BIPV Case"*, **Energies 2020, 13, 834** (KU Leuven / EnergyVille).

**검토 목적**: 본 논문의 DC/DC 컨버터를, 우리가 설계한 단상 계통연계 인버터
(**Vdc 400 V / 250 W / 220 Vrms 60 Hz**, `grid_tied_inverter_control.c`)의
**전단 DC/DC 단(PV → 400 V DC 링크)** 으로 사용 가능한지 평가.

---

## 1. 논문 컨버터 요약

| 항목 | 값 |
|------|-----|
| 토폴로지 | **IIBC** (Isolated Interleaved Boost Converter, 절연·인터리브 부스트) |
| 변압비 | n = 5, 절연(갈바닉 분리) |
| 입력 전압 | **10–30 V** (40-cell PV 모듈), 토폴로지군 정격 20–50 V |
| 출력 전압 | **400 V (정전압 제어)** |
| 출력 전력 | 모듈 레벨 약 **200–300 W** |
| 스위칭 주파수 | 100 kHz |
| 스위치 S1,S2 | 100 V Si MOSFET, Ron 3.1 mΩ (접지 기준) ×2 |
| 출력 정류 다이오드 | 600 V, Vf 1.4 V ×2 (동기정류 미적용) |
| 입력 인덕터 L1,L2 | 47 µH / 14 A ×2 (AEC-Q200) |
| 입력 캡 Cin | 100 V MLCC 5×4.7 µF |
| **출력 캡 C1,C2** | **520 V 필름 4×1 µF = 4 µF** |
| 효율(피크) | **93.3 %** @ Vin 30 V |
| PCB | 125 × 55 mm |
| 설계 초점 | **신뢰성·고온·장수명**(BIPV, 패널 후면 장착) |

> 중요: 이 컨버터는 **DC 마이크로그리드(400 V DC 버스)** 용 모듈레벨 컨버터(MLC)입니다.
> 논문은 "AC 변환이 필요 없는 DC 버스"를 명시 — 즉 **그 자체로는 마이크로인버터가 아니라, 인버터의 DC/DC 전단에 해당**합니다.

## 3. 핵심 결론

### ✅ 토폴로지·동작점은 우리 마이크로인버터 전단으로 "매우 적합"
- 출력 **400 V** 가 우리 DC 링크 사양과 **정확히 일치**.
- 250 W 급, 절연형, 인터리브, 접지기준 스위치 → 마이크로인버터 전단으로 이상적 후보.
- 신뢰성·고온 장수명 설계 사상이 마이크로인버터(패널 후면, 25년) 요구와 부합.

### ❌ 그러나 "그대로"는 부적합 — 단상 인버터용으로 2가지 필수 보완

**(1) DC 링크 커패시턴스 — 가장 치명적인 갭**
단상 인버터는 **120 Hz(2ω) 맥동전력**이 DC 링크로 역류합니다.
논문 출력캡은 **필름 4 µF**(DC 버스를 여러 컨버터가 공유한다는 가정)뿐:

```
리플 ΔVdc = P / (2·ω·C·Vdc)
  C = 4 µF   →  ±207 V (51.8 %)   ← 사용 불가
  C = 104 µF →  ±8 V   (2 %)      ← 최소
  C = 470 µF →  ±1.8 V (0.4 %)    ← 우리 인버터 설계값(권장)
```
→ **출력단에 ~470 µF급 벌크 캡(전해/필름 뱅크) 또는 능동 전력디커플링(active power decoupling)을 반드시 추가**해야 함.
(주의: 전해캡은 논문이 회피한 부품 — 신뢰성과 상충. 장수명 유지하려면 **능동 디커플링** 또는 대용량 필름 권장.)

**(2) DC/AC 인버터 단 결합 — 우리가 만든 알고리즘으로 완성**
이 DC/DC는 220 Vac 출력단이 없음. 우리 `grid_tied_inverter_control.c`(400 Vdc→220 Vac)를
후단으로 붙이면 **완전한 2단형 단상 마이크로인버터**가 됨.

### △ 추가 확인 사항
- **입력 전압 범위**: 논문은 40-cell 모듈(10–30 V) 기준. 실제 사용할 패널의 Vmp/Voc가
  토폴로지 정격(20–50 V)·MOSFET 100 V 내압에 맞는지 재확인.
- **저입력(10 V) 시 전력**: 250 W → 입력전류 26.8 A(인터리브 분할 후 인덕터당 13.4 A ≈ 14 A 정격, **마진 거의 없음**).
  MPP가 25–30 V 부근이면 여유 충분하나, 10 V 부근 연속 250 W는 인덕터·MOSFET 발열 한계.
- **효율**: 93.3 %(DC/DC) × ~96 %(인버터) ≈ **시스템 ~90 %**. 최신 상용 마이크로인버터(CEC 95–97 %)
  대비 낮음 — 동기정류/소프트스위칭 미적용 때문(논문이 신뢰성 위해 의도적 배제). 효율 우선이면 개선 필요.

## 4. 권장 2단형 마이크로인버터 구성

```
   PV 모듈            IIBC DC/DC (본 논문)        DC 링크            DC/AC (우리 코드)        계통
  10–30 V  ──▶  [절연 인터리브 부스트, MPPT] ──▶  400 V  ──▶  [H-Bridge + PR/PLL] ──▶  220 Vac
                  입력전류제어=MPPT            +벌크캡 470µF        MODE 1: DC링크 400V 정전압        60 Hz
                                              /능동 디커플링
```

**제어 역할 분담(중요)** — 우리 인버터 코드의 `MODE 1`(DC 링크 전압 제어)이 여기에 정확히 들어맞음:
- **DC/DC 단**: 입력전류 제어로 **MPPT** 수행(출력은 400 V 버스 추종)
- **DC/AC 단(우리 코드, MODE 1)**: **DC 링크를 400 V로 정전압 제어**하며 들어온 전력을 계통으로 송전

이 분담이 2단형 단상 마이크로인버터의 표준 구조이며, 우리가 이미 구현한 MODE 1과 일치합니다.

## 5. 최종 판정

| 용도 | 판정 |
|------|------|
| **마이크로인버터의 DC/DC 전단(段)** 으로 | ✅ **적합** (출력 400 V·절연·신뢰성 우수) — 단, **DC 링크 벌크캡/능동 디커플링 추가 필수**, 패널 입력범위·효율 확인 |
| **완전한 마이크로인버터(단독)** 로 | ❌ 부적합 — AC 출력단 없음(DC 버스 전용). 우리 DC/AC 단과 결합 필요 |

> 요약: **토폴로지·400 V 출력·신뢰성은 우리 마이크로인버터 전단으로 훌륭히 부합**하나,
> 논문이 "DC 버스"를 전제했기에 **단상 120 Hz 맥동을 흡수할 DC 링크 에너지 버퍼가 빠져 있는 것이 결정적 차이**입니다.
> 이 두 가지(벌크 디커플링 + 우리 DC/AC 단)를 보완하면 적합한 250 W/400 V/220 V 마이크로인버터가 됩니다.
