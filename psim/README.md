# 단상 계통연계형 인버터 제어 알고리즘 (PSIM)

**Single-Phase Grid-Tied Inverter — Vdc 400 V / 250 W / 220 V**

PSIM 시뮬레이션용 단상 계통연계 인버터 제어 알고리즘입니다.
제어 로직은 `grid_tied_inverter_control.c`(PSIM **Simplified C Block**)에 구현되어 있습니다.

---

## 1. 시스템 사양

| 항목 | 값 | 비고 |
|------|-----|------|
| DC 링크 전압 `Vdc` | **400 V** | 계통 피크(311 V)보다 충분히 높음 → 계통연계 가능 |
| 정격 출력 `Po` | **250 W** | 유효전력, 역률 1 |
| 계통 전압 `Vgrid` | **220 Vrms** (피크 311.1 V) | 단상 |
| 계통 주파수 | 60 Hz | 국내 기준 (50 Hz면 `F_GRID` 수정) |
| 스위칭 주파수 `fsw` | 20 kHz | 제어 샘플링 = 50 µs |
| 토폴로지 | 단상 풀브리지(H-Bridge) + L 필터 | 유니폴라 SPWM |

### 정격 전류 계산
```
I_rms  = Po / Vgrid      = 250 / 220       = 1.136 A
I_peak = I_rms * √2      = 1.136 * 1.414   = 1.606 A
```

## 2. 전력단(파워 스테이지) 회로 구성

```
            +----+      L=5mH  R=0.1Ω
   Vdc ---+--| S1 |----+--/\/\--(L)----o  Vgrid (220Vrms, 60Hz)
   400V   |  +----+    |                  계통 AC 전원
  (Cdc)   |  +----+    |
   ===    +--| S3 |----+   (A상 레그)
   470µF  |  +----+    |
          |            |
          |  +----+    |    +----+
          +--| S2 |    +----| S4 |---- (B상 레그, 반대 다리)
             +----+         +----+
```

- **DC 링크 커패시터** `Cdc = 470 µF`
  단상 인버터는 120 Hz(2차) 맥동전력이 존재 → DC 리플 억제용.
  `ΔVdc = Po / (2·ω·Cdc·Vdc) = 250 / (2·377·470µ·400) ≈ 1.8 V` (약 0.45 %)

- **필터 인덕터** `L = 5 mH`, 등가저항 `R = 0.1 Ω`
  유니폴라 SPWM 기준 전류 리플:
  `ΔI_pp ≈ Vdc / (8·fsw·L) = 400 / (8·20k·5m) = 0.5 A` (피크의 약 31 %, 데모 적정)
  리플을 더 줄이려면 `L`을 키우거나 LCL 필터로 확장하세요.

### PSIM 부품 권장값
| 부품 | 값 |
|------|-----|
| DC 전압원 (또는 PV/배터리) | 400 V |
| DC 링크 커패시터 Cdc | 470 µF |
| MOSFET/IGBT ×4 | H-Bridge |
| 필터 인덕터 L | 5 mH |
| 인덕터 저항 R | 0.1 Ω |
| 계통 전원 (AC) | 220 Vrms, 60 Hz, 위상 0° |

## 3. 제어 구조

```
                     ┌──────────────┐
   Vgrid ──────────▶ │  SOGI-PLL    │──▶ theta, Vamp
                     └──────────────┘        │
                                             ▼
  [MODE0] P_ref=250W ─┐               iref = Iamp·sin(theta)
  [MODE1] Vdc_ref=400 ┼─▶ 외부루프 ─▶ Iamp ─┘     │
   Vdc ───────────────┘                            ▼
                                        ┌──────────────────┐
   Igrid ───────────────────────────▶  │ PR 전류 제어기    │
                                        │ (60Hz 무한이득)   │
                                        └──────────────────┘
                                                 │ u_pr
                          Vgrid(피드포워드) ──────┼───▶ vinv_ref
                                                 ▼
                                        m = vinv_ref / Vdc
                                                 │
                                                 ▼  유니폴라 SPWM
                                          삼각파 캐리어 비교 → S1~S4
```

1. **SOGI-PLL** — 계통 전압으로부터 위상 `theta`, 주파수, 진폭 `Vamp`를 추정.
   단상에서는 직교 신호(qv')를 SOGI(2차 일반화 적분기)로 생성해 SRF-PLL을 구성합니다.
2. **외부 루프** — 전류 진폭 지령 `Iamp` 생성
   - **MODE 0 (기본)**: 전력 지령. `Iamp = 2·P_ref / Vamp` (DC원이 이상적 400 V 전압원일 때 권장)
   - **MODE 1**: DC 링크 전압 제어. PV/배터리처럼 DC측이 전력원일 때 `Vdc`를 400 V로 유지하며 잉여전력을 송전.
3. **전류 지령** — `iref = Iamp·sin(theta)` → 계통 전압과 동상(역률 1).
4. **PR(비례공진) 전류 제어기** — 60 Hz에서 무한 이득 → 정상상태 추종오차 0.
   dq 변환 없이 정지좌표계에서 AC 지령을 직접 추종(단상에 적합).
5. **계통 전압 피드포워드** — `vinv_ref = u_pr + Vgrid` 로 외란(계통전압) 보상, 응답 개선.
6. **변조신호** — `m = vinv_ref / Vdc`, ±0.98로 포화. 유니폴라 SPWM 비교용.
   풀브리지 차동 출력은 `m·Vdc`(범위 ±Vdc)이므로 `Vdc`로 정규화합니다(반브리지의 `Vdc/2` 아님).
   계통 피크 311 V < Vdc 400 V → 변조지수 약 0.78로 선형영역 동작.

## 4. C 블록 입출력 매핑

PSIM `Simplified C Block` (입력 3, 출력 6) 기준:

| 입력 | 신호 | 단위 | 연결 |
|------|------|------|------|
| `x[0]` | Vgrid | V | 계통 전압 센서 |
| `x[1]` | Igrid | A | 인덕터 전류 센서 (+: 인버터→계통) |
| `x[2]` | Vdc | V | DC 링크 전압 센서 |

| 출력 | 신호 | 용도 |
|------|------|------|
| `y[0]` | **m** | PWM 변조신호 (-1~1) → 삼각파 캐리어 비교 |
| `y[1]` | theta | PLL 위상 (모니터링) |
| `y[2]` | iref | 전류 지령 (모니터링) |
| `y[3]` | Iamp | 전류 진폭 지령 (모니터링) |
| `y[4]` | Vamp | 계통 전압 진폭 추정 (모니터링) |
| `y[5]` | ferr | PLL 위상오차 (모니터링) |

> 전류/전압 센서에 스케일(게인)이 있으면 C 블록 입력 전에 환산해 **실제 물리값(V, A)** 이 들어가도록 하세요.

## 5. PWM(유니폴라 SPWM) 설정

H-Bridge 유니폴라 변조는 두 레그를 `m`, `-m` 으로 각각 비교합니다.

- **삼각파 캐리어**: 진폭 1(피크 ±1), 주파수 **20 kHz**
- **A 레그(S1/S3)**: `m  > carrier` → S1 ON, 아니면 S3 ON
- **B 레그(S2/S4)**: `-m > carrier` → S2 ON, 아니면 S4 ON

PSIM 구현:
1. C 블록 출력 `m` 과, 부호반전(`-1` 게인)한 `-m` 두 신호 생성
2. 각각 `Comparator`로 삼각파 캐리어와 비교
3. 비교 출력으로 4개 스위치 게이팅 (각 레그 상·하단은 상보, 데드타임 추가)

> 유니폴라는 등가 스위칭 주파수가 2배(40 kHz 효과) → 전류 리플·필터 부담이 작습니다.

## 6. 제어 이득 설계

### PR 전류 제어기 (내부 루프)
플랜트 `i/v = 1/(Ls+R)`, 목표 대역폭 `fc ≈ 1.5 kHz` (= fsw/13).
```
ωc   = 2π·1500 = 9425 rad/s
Kp_i = ωc·L    = 9425 · 5m  ≈ 47      → KP_I
공진이득 Ki_r  = 2000 (60Hz 부스트)    → KI_R
공진대역 ωc_r  = 10 rad/s (선택도)      → WC_R
```
공진부 전달함수: `R(s) = 2·ωc_r·s / (s² + 2·ωc_r·s + ω0²)` (60 Hz에서 이득 1).

### SOGI-PLL
```
SOGI 게인 k = √2 = 1.414   → SOGI_K
PLL  Kp = 180,  Ki = 3200  → KP_PLL / KI_PLL  (정규화 위상오차 기준, ωn≈100rad/s, ζ≈0.7)
```

### DC 링크 전압 PI (MODE 1)
```
Kp_v = 0.5,  Ki_v = 20     → KP_V / KI_V   (내부 루프보다 ~10배 느리게)
```

> 모든 이득은 시작값입니다. 오버슈트/리플을 보며 `KP_I`, `KI_R`, PLL 이득을 조정하세요.

## 7. 사용 절차 (PSIM)

1. 위 회로(H-Bridge + L 필터 + DC원 + AC 계통)를 PSIM에 작성.
2. **Simplified C Block** 추가 → 입력 3 / 출력 6 설정 → `grid_tied_inverter_control.c` 내용 붙여넣기.
3. 센서(Vgrid, Igrid, Vdc) → C 블록 `x[0..2]` 연결.
4. C 블록 `y[0]`(m) → PWM 비교기 → 스위치 게이트.
5. **Simulation Control**: `Time step ≤ 1 µs` (예 0.5 µs), Total time 0.1 s 이상.
   > C 블록의 `delt`는 시뮬레이션 스텝 = 제어 주기로 사용됩니다. 캐리어 20 kHz를 충분히 해상하도록 1 µs 이하 권장.
6. 실행 후 확인:
   - `Igrid` 가 `Vgrid` 와 **동상 정현파**(역률 1)
   - 출력전력 ≈ **250 W**, `theta` 가 0~2π 톱니파로 안정 잠금
   - DC 링크 전압 400 V 부근 유지
