# HF-Link 사이클로컨버터 토폴로지 검토 (마이크로인버터 적합성)

**대상**: Figure 2-1 "Cycloconverter With Full Bridge on DC and Half Bridge on AC side"
(DC측 풀브리지 + 고주파 변압기 + AC측 사이클로컨버터)

---

## 1. 토폴로지 정의

**고주파 링크(HF-link) 사이클로컨버터형 단일단 절연 DC-AC 인버터.**

```
 DC원 ─[풀브리지 Q1~Q4]─HFAC→[변압기 T1]→HFAC─[L1]─[사이클로컨버터 S1A/B,S2A/B + C2/C3]→ 60Hz 계통
        ① 고주파 인버전        ② 절연·변압          ③ 필터   ④ HF→LF 직접 변환
```

- **단일 전력변환단**: 중간 DC 링크(예 400 V 버스)가 **없음**. DC→HFAC→LFAC를 한 번에.
- 우리 2단형(IIBC DC/DC → 400 V 링크 → H-Bridge DC/AC)과 대비되는 구조.

## 2. 동작 원리

| 단계 | 블록 | 역할 |
|------|------|------|
| ① | 풀브리지 Q1~Q4 | DC를 수십~수백 kHz 고주파 구형파/PWM으로 변환(Vp) |
| ② | 변압기 T1 | 갈바닉 절연 + 권선비 전압변환, HF라 소형·경량 |
| ③ | L1 | 누설/필터 인덕터, 전류 성형 |
| ④ | 사이클로컨버터 S1A/B,S2A/B,C2/C3 | HF AC를 60 Hz 계통 정현파로 직접 합성(PWM 변조 + 극성 언폴딩), C2/C3가 반브리지 중점 형성 |

**★ 양방향(4상한) 스위치**: AC측은 전압 양/음·전류 양방향이라, MOSFET 2개를 back-to-back으로
묶어 4상한 스위치를 구성(S1A+S1B, S2A+S2B). 1방향 스위치로는 AC 처리 불가.

## 3. 마이크로인버터 적합성

| 항목 | 평가 | 비고 |
|------|------|------|
| 갈바닉 절연 | ✅ | HF 변압기, 안전규격 용이 |
| 전해캡 불필요 | ✅ | DC 링크 전해캡 없음 → 고온·25년 수명 유리 |
| 전력밀도/효율 | ✅ | 단일단 + HF 변압기, 고밀도·고효율 잠재력 |
| 도통 손실 | △ | AC측 back-to-back 직렬 도통 → 손실↑ (GaN 권장) |
| **커뮤테이션** | ❌ 난점 | DC 링크 無 → 프리휠 경로 無, 인덕성 전류 전환 스파이크. 매트릭스식 다단계 커뮤테이션/클램프 필수 |
| **2ω(120Hz) 디커플링** | ❌ 난점 | DC 링크 노드가 없어 APD 부착 곤란. 맥동이 PV로 반사 → MPPT 저하. 입력측 능동버퍼/대용량캡 필요 |
| 제어 복잡도 | △ | HF-link 동기·커뮤테이션 타이밍 |

## 4. 2단형(우리 설계)과의 트레이드오프

| | HF-link 사이클로컨버터(단일단) | 2단형 IIBC+H브리지+APD(우리) |
|---|---|---|
| 변환단 수 | 1 (고효율·고밀도) | 2 |
| DC 링크 | 없음 | 400 V (APD로 2ω 흡수, 검증 리플 1 Vpp) |
| 2ω 디커플링 | **어려움**(링크 없음) | 쉬움(APD) |
| 커뮤테이션 | **어려움**(4상한) | 쉬움(표준 H-Bridge) |
| 절연 | HF 변압기 | IIBC 변압기 |

## 5. 결론

마이크로인버터용으로 **사용 가능한 정통 단일단 토폴로지**이며, 절연·무전해캡·고밀도라는
마이크로인버터 요구에 부합. 단, **(1) 사이클로컨버터 커뮤테이션, (2) 2ω 전력 디커플링** 두
난제를 반드시 해결해야 함. 특히 2ω는 DC 링크가 없어 2단형보다 오히려 더 까다로움.

> **선택 기준**
> - 효율·전력밀도 최우선 + 커뮤테이션 감당 가능 → HF-link 사이클로컨버터
> - 2ω 처리의 단순함·견고함·설계 용이성 우선 → 2단형 + APD(본 저장소 구현)

## 6. 제어 알고리즘 구현 (`cycloconverter_control.c`)

본 토폴로지의 PSIM 제어 C 블록을 구현·검증했습니다.

**구조 (2계층)**
- (A) 제어법: SOGI-PLL + PR 전류제어 → 인버터 전압지령 `v_inv_ref`, 변조 `m = v_inv_ref/(n·Vin)`
- (B) 변조→게이트: HF 풀브리지가 `|m|` 듀티로 PWM(능동/프리휠), 사이클로컨버터가
  `sign(m)·(HF극성)`에 맞춰 출력 극성 언폴딩 → HF 1주기 평균출력 = `n·Vin·m`

**C 블록 I/O**
| 입력 | 출력 |
|------|------|
| x[0]=Vgrid, x[1]=Igrid, x[2]=Vin | y[0..3]=Q1~Q4(풀브리지), y[4..7]=S1A/S1B/S2A/S2B(사이클로), y[8]=m, y[9]=iref, y[10]=theta |

**검증 (게이트레벨 폐루프, 8게이트→변압기 n=8→사이클로 라우팅→L1→계통 재구성)**
| 지표 | 결과 | 목표 |
|------|------|------|
| 평균전력 | **250.3 W** | 250 W |
| Vrms / Irms | 220.0 V / 1.139 A | 220 / 1.136 |
| 역률 | **0.999** | ≈1 |

→ 제어법·변조·언폴딩 게이트 로직 정상. 예시 사양: Vin≈50 V, n=8 (n·Vin≈400 V), fs(HF)=50 kHz.

**커뮤테이션(실하드웨어 주의)**: 사이클로 상/하 전환 시 4상한 스위치는 **매트릭스컨버터식
4-step 커뮤테이션** 또는 RC/능동 클램프로 인덕성 전류경로를 끊김 없이 확보해야 함
(코드의 `DT_HF` 표기). 본 평균/게이트 검증은 제어법 타당성 확인용이며, 스파이크·THD·효율은
PSIM 스위칭+기생성분 모델에서 최종 튜닝 필요.
