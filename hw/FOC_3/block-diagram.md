## 2. 블록 요약

| # | 블록 | 기본안 | 상태 | 상세 |
|---|---|---|---|---|
| B1 | 전원 입력·보호 | 대전류 퓨즈·주회로 역접속 보호는 **호스트 책임**으로 문서화. 모듈에는 세라믹 C 뱅크 + 버스 분압만 | 결정 필요 (Elmo 처리 방식 ❓) | SD §1 |
| B2 | 회생 과전압 처리 | **브레이크 초퍼 (모듈 내 MOSFET + 외부 저항)** + MCU 비교기 + 과전압 차단. TVS는 ESD/서지용으로만 | 결정 필요 (경로 B/C에 따라 임계값 변동) | SD §2 |
| B3 | 3상 브리지 | TOLL × 6 — 경로 B (IPT017N12NM6, 120 V) 또는 C (IPT025N15NM6, 150 V). 풋프린트 공용 | **B/C 미확정** | SD §3 |
| B4 | 게이트 드라이브 | 6ED2742S01Q, 부트스트랩 3채널, Rg_on/Rg_off 분리 | 유력 | SD §4 |
| B5 | 전류 센싱 | **로우사이드 션트 3개 (0.5 mΩ) + 외부 증폭 3채널**. 6ED2742 내장 앰프는 단일 채널(VSS–COM, 🔍)이라 상전류 3채널 불가 → OC 보호/DC 링크용으로만 옵션 | 3션트 기본, 2션트 대안 | SD §5 |
| B6 | 버스 전압·온도 | 분압 50.8 : 1 (FS 167.6 V), NTC × 1 (전력부), MCU 내부 온도 | 초안 | SD §6 |
| B7 | 보조 전원 | VL(12–95 V) → LM5169 × 2 (12 V, 5 V) → LDO 3.3 V / 3.3 VA. VBUS 다이오드-OR 옵션 | 초안 | SD §7 |
| B8 | MCU | PSC3M8, 패키지 VQFN-64 또는 LQFP-64/80 (핀 수 확인 후) | 핀 배정 전부 ❓ | SD §8 |
| B9 | CAN FD | TLE9251V (5 Mbps, VIO 3.3 V) | 초안 | SD §9 |
| B10 | 엔코더 | ABZ 차동(RS-422) + Hall 3선 + 절대치 직렬(RS-485, BiSS-C/SSI) + 엔코더 5 V 전류제한 출력 | 지원 범위 결정 필요 | SD §10 |
| B11 | STO | 2채널 옵토 입력. 채널 1 = 게이트 전원 차단, 채널 2 = PWM 경로 차단, 각각 MCU 피드백 | 기능안전 인증 범위 ❓ | SD §11 |
| B12 | 디버그 | SWD 패드 + UART(TTL) 핀 | 초안 | SD §12 |

## 3. 미확정 결정 3가지 — 이 초안의 분기점

| 결정 | 선택지 | 이 초안의 기본 | 결정 조건 |
|---|---|---|---|
| **전력 소자 경로** | B: 120 V / C: 150 V | 풋프린트 공용, 회로 상수는 두 경로 병기 | 오버슈트 실측(더블펄스), 브레이크 초퍼 임계값, 단가·재고 (02 §5) |
| **회생 처리** | ① 브레이크 초퍼 + 외부 저항 ② 과전압 시 PWM 차단만(호스트 책임) ③ TVS 클램프 | ① | 경로 B면 ①이 사실상 필수 (SD §2). 경로 C면 ②도 검토 가능 |
| **션트 개수** | 3 / 2 / 1(DC 링크) | 3 | 과변조(버스의 96 %, ✅ Elmo) 영역에서 2션트 측정 창 부족 → 3 권장. 면적이 막히면 2 |
