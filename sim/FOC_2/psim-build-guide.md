# FOC_2 — PSIM 회로 구성 가이드

작성 2026-10-24 · 대상: PSIM 사용자 (회로·열 모듈 경험 있음)
계획·판정 기준: [plan.md](plan.md) · 기준값: [crosscheck_results.md](crosscheck_results.md)

> 이 문서는 클라우드 환경에서 썼고 PSIM을 직접 실행하지 못했다. 요소 이름과 메뉴 위치는
> PSIM 버전마다 다를 수 있으니, 요소가 **무엇을 하는지**를 기준으로 맞춰 쓰면 된다.
> 정의가 버전마다 다를 수 있는 파라미터(PMSM 역기전력 상수, 열 모듈 E 보정 방식)에는 ⚠를 붙였다.

## 0. 공통 설정

| 항목 | 값 | 이유 |
|---|---|---|
| Time step | **≤ td / 10** (td 100 ns → 10 ns) | 데드타임 구간 다이오드 도통을 해상해야 함 |
| Total time | 기본파 3–5주기 (fe 100 Hz → 30–50 ms) | 손실은 fe와 무관 (동기 정류). 짧게 돌려도 됨 |
| Print time | 마지막 1주기만 | 평균·RMS를 정상상태 1주기로 계산 |
| 기본파 fe | 100 Hz (손실 검증용 임의값, 동작점 아님) | Python `time_domain(fe=100)`과 같게 |
| 기준점 | 경로 B, 85 V, 35.3 A RMS, PF 1, fsw 40 kHz, td 100 ns | 체크 표가 이 조건. **fsw·td는 선정값 아님** |

측정은 PSIM의 평균/RMS 측정 요소나 SimView의 Avg/RMS 기능을 쓰고, **마지막 1주기 구간**으로 맞춘다.

## 3. S1 — 동작점·손실 (모터 없음)

### 3.1 전력단

1. DC 전압원 85 V (OP2는 95 V). S1에서는 이상 전원에 직접 연결하고, C_bus는 넣지 않는다.
   - 커패시터 리플은 `I_dc`에서 계산한다: I_cap,rms = √(I_dc,rms² − I_dc,avg²). C를 넣으면 전원 내부 임피던스 가정이 끼어든다.
2. 하프브리지 3개 (S1–S6, §2 설정).
3. 하단 션트 3개: 1 mΩ (docs/01 §4 #3 가정), 각 하단 소스와 DC- 사이.
4. **부하 = 전류원 2개 + 결선 1개**
   - A → N: 정현 전류원 `Ipk = 49.92 A`, 주파수 fe, 위상 θ_i
   - B → N: 같은 진폭, 위상 θ_i − 120°
   - C → N: **직접 결선** (전류원 3개를 Y로 묶으면 KCL이 과구속되므로 i_C = −i_A − i_B가 결선으로 정해지게 한다)
   - 역률은 전류원 위상으로 정한다: θ_i = θ_v − φ, φ = acos(PF). 회생(S3)은 φ = 180°.
   - 전류원 부하는 하드 스위칭 전류를 강제하므로 손실 검증에 적합하다. 같은 전류에서 동기 정류 손실은 부하 종류와 무관하다 (plan.md §4.1).

### 3.2 변조 (개방루프 SVPWM)

1. 기준 전압 3개: `v_x* = Vph_pk · cos(θ_v − k·120°)`, Vph_pk = m · Vdc/2. 선형 한계 m = 2/√3 → Vph_pk = 85/√3 = **49.07 V**.
2. 영상분 주입 (min-max): `v0 = −(max(v*) + min(v*)) / 2`, `v_x' = v_x* + v0`.
   - PSIM 수학 블록(Max/Min, 합산기)이나 C 블록으로 만든다. crosscheck.py `svpwm_duty()`와 같은 식이다.
3. 듀티 `d_x = 0.5 + v_x'/Vdc` → 0–1 삼각파(fsw, **중앙정렬**)와 비교 → 상단 게이트 신호, 반전 → 하단.
   - 중앙정렬이어야 Python의 DC 링크 전류 계산(대칭 PWM 상태 구간)과 맞는다.
4. **데드타임**: 상단·하단 신호 각각의 **상승 엣지만 td 지연** (하강 엣지는 그대로). PSIM의 on-delay 계열 요소나 C 블록으로 구현한다.
   - plan.md §4.1의 "양쪽 턴온 엣지 지연"과 같은 방식이어야 x1·x5·E9 행이 맞는다.

### 3.3 측정 → 체크 표

| 체크 표 # | PSIM에서 잴 것 |
|---|---|
| E1 | V_AN의 기본파 RMS (FFT 또는 1주기 푸리에). 순시 RMS가 아니다 |
| E2 | I_A RMS, 피크 |
| E3 | Σ (V_xN · I_x) 1주기 평균 |
| E4 | S1 채널 전류 RMS (다이오드 제외) |
| E5 | I_dc 평균 |
| E6 | √(I_dc,rms² − I_dc,avg²) |
| E7–E8 | I_Rsh_A RMS, 3개 저항 손실 합 |
| E9 | (데드타임 0 케이스의 V_AN 기본파) − (td 케이스의 V_AN 기본파) 피크. 두 번 실행한다 |
| x1–x2 | 스위치 i²·R 1주기 평균 (S1 개별, 6개 합) |
| x5 | 다이오드 Vf · i 평균 6개 합 (Vf = 1 V이므로 W 값 = W/V 계수) |

## 5. S2 — 열 모듈

PSIM 열 모듈은 Device Database의 소자 데이터(도통 곡선, 스위칭 에너지 E(Id), 다이오드 Vf·Err, 열 임피던스)로 손실을 계산해 Pcond·Psw 출력 노드로 내보낸다.
**OptiMOS 데이터시트에는 Eon/Eoff 곡선이 없다**(IGBT와 다름). 그래서 E(Id)를 만드는 방법을 둘 준비했다.

| 방법 | E(Id) 출처 | 무엇을 검증하나 | 기대 결과 |
|---|---|---|---|
| **A** | `crosscheck.py`가 내보낸 [`energy_IPT017N12NM6_85V.csv`](energy_IPT017N12NM6_85V.csv) (🔢, 하한) | **PSIM 회로·열 모듈 구성**이 Python과 같은 계산을 하는지 | B3·B4·B6 ±10 % 일치 |
| **B** | Infineon SPICE 모델로 **이중펄스 시뮬레이션**: 85 V, Id 5–100 A, 실제 Rg·드라이버 모델(가능하면 6ED2742S01Q 출력단 등가), 루프 인덕턴스 ❓ sweep | **Python 손실 모델의 하한 가정**(Qgs2 누락, Rg 0, ZVS 무시)이 얼마나 빗나가는지 | 차이 = 결과. crosscheck.py 보정값으로 되먹임 |

방법 A 주의:
- CSV 열은 `Eon` (= ½·V·I·t_vf + Qoss·V), `Eoff` (= ½·V·I·t_vr), `Err_diode` (= Qrr·V)다. **PSIM 다이오드 Err를 0으로 두면 Err를 Eon에 더해 넣고, 다이오드 Err 칸에 넣으면 Eon에 더하지 않는다** (이중 계상 방지).
- ⚠ PSIM이 데이터베이스 시험 전압과 회로 전압의 차이를 E에 어떻게 보정하는지(선형 비례 여부)는 사용 중인 버전의 매뉴얼에서 확인한다. CSV는 85 V 기준이다. OP2(95 V)는 `export_energy_tables(vdc=95)`로 다시 만든다.
- C(150 V)는 Qgd ❓라 CSV를 만들지 않았다. 원문 대조 후 `crosscheck.py` DEVICES를 고치면 자동으로 생긴다.

### 5.1 열 회로 2단계

1. **Tj 고정**: 소자 열 노드를 고정 온도원(열 도메인의 전압원)에 바로 연결한다. 도통 곡선은 그 Tj의 Rds가 2.55 mΩ(B)가 되게 넣는다 → Python과 같은 조건이 되어 B1–B6을 비교할 수 있다.
2. **전열 해석**: 원문의 Rds-Tj 곡선과 ZthJC를 넣고, 케이스 → TIM(❓) → 호스트 PCB(❓, docs/01 §5 #4) → 주위 온도로 열 회로를 잇는다. 호스트 PCB 열저항은 ❓이므로 **sweep해서 Tj ≤ 한계를 만족하는 PCB 열저항 상한을 역산**하는 데 쓴다. 이것이 01 §5 #4에 답하는 경로다.
   - 저속 고토크(fe 수 Hz 이하)에서는 한 소자가 기본파 반주기 내내 피크 전류를 받는다 → Tj 리플이 커진다. fe sweep(1/10/100 Hz)으로 확인한다.

## 6. S3 — 회생 (전력 등가, 모터 없음)

S1 회로에 다음을 바꾸거나 더한다.

1. 공급: DC 전압원(85/95 V) → **직렬 다이오드** → R_supply(❓, sweep) → DC+. 다이오드는 회생 전류를 받지 못하는 최악 조건을 만든다.
2. C_bus (❓ sweep 100/220/470/1000 µF) + ESR(❓)을 DC+–DC-에 연결한다.
3. 전류원 위상 φ = 180° (PF −1) → 정격 회생 3,675 W가 버스로 들어온다.
4. **초퍼**: DC+ → R_brake → 스위치 → DC-. 히스테리시스 비교기(V_on/V_off ❓)로 구동한다.
   - 체크 표 R1·R2는 **초퍼를 끄고** 85 V에서 시작해 잰다 (dV/dt, 96 V 도달 시간).
   - 초퍼를 켠 케이스는 V_bus,max(오버슈트 포함)를 B 96 V / C 120 V 한계와 비교한다.
5. ⚠ 전류원 부하는 버스 전압이 올라도 회생 전력이 줄지 않는다 → **실제보다 가혹한 쪽**이다. 실제 감속 에너지는 S4에서 본다.
6. 경로 B·95 V 공급에서는 커패시터 여유가 1 V뿐이다(crosscheck §5). 초퍼 임계를 95 V 직상으로 두면 공급 리플·과도에 오동작할 수 있으니, 그 사이 간격을 S3에서 확인한다.

## 7. S4 — FOC 폐루프 (모터 사양 확정 후)

| 블록 | 구성 | 대응 Python |
|---|---|---|
| 모터 | PMSM 요소: Rs, Ld, Lq, 극수(= 2 × 극쌍), 역기전력 상수, J, 축 시정수 ⚠ PSIM PMSM의 역기전력 상수는 **Vpk/krpm (선간 피크, 기계 1000 rpm 기준)** 형식으로 알고 있다. 버전 도움말에서 정의를 확인하고 crosscheck의 `psi_pm`과 맞춘다: Vpk/krpm = √3 · ψ_pm · p · (2π·1000/60) | `foc_sim()` |
| 기계 부하 | 정속 구간: 정토크 부하 (Python과 같게 TL = 1.5·p·ψ·iq_motoring). 제동 구간: 0 | 동상 |
| 위치/속도 | 모터 요소의 축 각도 출력을 그대로 쓴다 (센서 모델 생략) | — |
| 좌표 변환 | abc→dq (전류), dq→abc 또는 αβ (전압) | — |
| 전류 루프 | 이산 PI, 샘플·갱신 주기 1/fsw, **1 Ts 연산 지연** (ZOH + unit delay). Kp = L·ωc, Ki = Rs·ωc (극점-영점 상쇄), 전향 보상 −ωLq·iq, +ω(Ld·id + ψ) | 동일 |
| 전압 제한 | 원 제한 |v_dq| ≤ Vdc/√3, 포화 시 적분 정지 | 동일 |
| 변조 | §3.2 SVPWM + 데드타임 | Python은 평균화 + 데드타임 오차 (4/π)·td·fsw·Vdc |
| 버스 | S3 회로 (다이오드 공급, C_bus, 초퍼) | 동일 |

시나리오: 0 – t_end/2 정속(iq_motoring), t_end/2 – t_end 제동(iq_braking, 음수). 비교 항목: V_bus 최대·최소, 초퍼 소산 에너지, 종료 속도.
Python: `python3 crosscheck.py --motor motor.json` (`motor_params.template.json`을 복사해 채움). Python 쪽은 평균화 모델이라 **스위칭 리플과 Coss에 의한 데드타임 축소는 없다** → V_bus 피크는 PSIM이 조금 높게 나오는 게 정상이다.

S4에서 추가로 볼 것:
- 데드타임에 의한 5·7차 전류 고조파 (상전류 THD), 보상 on/off 비교
- 전류 0 근처의 클램프 현상 (데드타임 중 Coss 충방전으로 전압 오차 부호가 흐려지는 구간)
- 하단 션트 샘플링 창: 하단 ON 시간이 t_min(❓)보다 짧은 섹터에서 2상 재구성 로직 필요 여부 (crosscheck §2 "하단 션트 샘플링 창" 표)
