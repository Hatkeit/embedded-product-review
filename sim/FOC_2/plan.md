## 2. 시뮬레이션 단계

| 단계 | 모델 | 부하 | 필요한 입력 | 답하는 질문 | 모터 사양 필요 |
|---|---|---|---|---|---|
| **S1** 동작점·손실 | 3상 브리지 + 개방루프 SVPWM + 데드타임 | **전류원 2개 + 결선 1개** (정현, PF 설정) | 소자, fsw, td | Q1·Q2·Q3·Q5 | **아니오** |
| **S2** 열 | S1 + PSIM 열 모듈 (Tj 고정 → 열회로) | S1과 동일 | + E(Id) 표, RthJC, 인터페이스·PCB 열저항 ❓ | Q6 | 아니오 |
| **S3** 회생 (전력 등가) | S1 + 단방향 공급(다이오드+R) + C_bus + 초퍼 | 전류원 PF −1 | + C_bus, 초퍼 임계 | Q4 (정격 회생 전력 기준) | 아니오 |
| **S4** FOC 폐루프 | dq PI 전류 루프 + SVPWM + PMSM | PMSM + 관성 | + Rs, Ld/Lq, 극쌍, 역기전력 상수, J | Q3 (전류 왜곡), Q4 (실제 회생 에너지) | **예** |

S1–S3는 모터 사양 없이 지금 실행할 수 있다. 전류원 부하는 동기 정류 MOSFET 인버터의 손실을 전류만으로 결정하므로(§4.1), 손실·열 검증에 모터 모델이 필요 없다.

## 4. 모델 가정과 그 근거

### 4.1 손실 모델 (crosscheck.py와 PSIM 공통)

- **동기 정류**: 데드타임을 빼면 전류 방향과 무관하게 채널이 도통 → 레그당 도통 손실 = I_rms² · R · (1 − 2·td·fsw). **m·PF와 무관** (S1에서 PSIM으로 확인할 첫 항목).
- **데드타임 삽입 방식**: 양쪽 턴온 엣지를 td씩 지연. 데드타임 두 구간 모두 전류 방향 쪽 바디 다이오드가 도통 → 레그당 2·td·fsw·VSD·|i|.
- **하드 스위칭**: 전류 부호에 따라 한쪽 소자만 하드 턴온·턴오프 (반대쪽은 ZVS). 주기당 레그마다 ½·V·|i|·(t_vf + t_vr) + Qoss·V + Qrr·V.
  - t_vf = Qgd / Ig,on, t_vr = Qgd / Ig,off, Ig = 드라이버 피크 전류 (Rg_int·Rg_ext ❓ → 0). **Qgs2 구간 누락 + Rg 0 → 하한.**
  - Qgd·Qoss·Qrr은 데이터시트 측정 조건의 값을 그대로 쓴다 (전압·dI/dt·IF 보정 없음).
  - 소전류 구간(데드타임 안에 Coss 충방전이 끝나는 부분 ZVS)은 무시 → 저전류에서 과대평가.
- **하단 션트**: 동기 정류에서는 양방향 전류가 (1−d) 동안 흐름 → RMS = I/√2 = 25.0 A, m·PF 무관. docs/01 §4 #3의 1.9 W와 일치한다. (초안에 넣었던 IGBT 반주기 식 Ipk²(1/8 − m·cosφ/3π)는 이 회로에 맞지 않아 시간영역 결과와 어긋났고, 그래서 뺐다.)
- **Rds(on)@Tj = ×1.5**는 docs/01의 가정이다. S2에서 데이터시트 곡선으로 대체한다.

### 4.2 Python 결과 요약 — OP1 (85 V, 35.3 A RMS, PF 1), 40 kHz, 100 ns

전체 표는 [crosscheck_results.md](crosscheck_results.md). 수치는 전부 🔢이고, 위 하한 가정 위에서 계산한 값이다.

| 항목 | 경로 B (120 V) | 경로 C (150 V) |
|---|---|---|
| 도통 6개 합 | 9.46 W | 13.91 W |
| 스위칭 (오버랩 + Qoss + Qrr) | 6.08 + 2.71 + 3.07 = **11.86 W** | ❓ + 3.16 + 1.88 (Qgd ❓) |
| 게이트 구동 | 0.33 W | 0.30 W |
| 데드타임 다이오드 | 0.76 W × VSD[V] | 0.76 W × VSD[V] |
| **알려진 합** | **21.6 W + 0.76·VSD** (예산의 54 %) | **19.3 W + 0.76·VSD + 오버랩 ❓** |
| 하단 션트 3개 (1 mΩ) | 1.87 W | 1.87 W |
| 버스 커패시터 리플 | 10.7 A RMS (PF 0.8에서 14.7 A) | 동일 |

관찰 (🔢, 모두 하한 가정 위의 값):
1. 경로 B는 **fsw ≈ 100 kHz에서 알려진 항목만으로 40 W에 닿는다** (39.8 W + 1.9·VSD @100 ns). 션트·자체 소비(2.5 W)까지 넣으면 현실적인 상한은 그보다 낮다.
2. 경로 B의 스위칭 손실 중 **Qoss·Qrr 항(5.8 W @40 kHz)이 V-I 오버랩(6.1 W)과 맞먹는다.** 이 항은 게이트 저항으로 줄일 수 없고 fsw에 비례한다. 경로 C는 Qrr이 작아(184 vs 301 nC) 이 항이 더 작다. C의 Qgd를 확보하면 B/C 역전 구간이 나올 수 있다.
3. **SVPWM 선형 한계에서는 듀티가 0–1까지 간다.** 하단 션트 샘플 창을 확보하려면 m이 줄어든다 (예: 40 kHz·1 µs → 출력 3.38 kW, 단상 기준 보수적 계산). 4.0 kW 표기와 직접 충돌하는 제약이다.
4. **회생**: 경로 B를 95 V 공급에서 쓰면 C_bus 흡수 여유가 1 V(96 V 한계)뿐이다. 정격 회생 전력 3.68 kW·470 µF에서 85→96 V까지 **0.13 ms**. 초퍼나 FW 버스전압 제한이 0.1 ms 단위로 응답해야 한다. 경로 C(→120 V)는 0.46 ms.
5. 데드타임 전압 오차는 40 kHz·100 ns에서 상전압 피크의 0.9 %, 100 kHz·500 ns에서 11 %다.

## 5. Python ↔ PSIM 비교 방법

### 5.1 체크 표

[crosscheck_results.md §7](crosscheck_results.md#7-psim-비교-체크-표--op1-fsw-40-khz-td-100-ns) 표(E1–E9, B1–B6, C1–C6, R1–R2)의 PSIM 열을 채운다. 같은 입력이면 다음 기준으로 일치해야 한다.

### 5.2 판정 기준과 어긋날 때 해석

| 범주 | 기준 | 어긋나면 의심할 것 |
|---|---|---|
| 전기량 (E1–E8) | ±1–5 % | PSIM 측정 구간(정상상태 진입 전 포함 여부), 전류원 위상(PF), SVPWM 영상분 구현 |
| 도통 (x1–x2) | ±5 % | PSIM 소자 Rds 입력(25 °C vs Tj), 데드타임 구간 처리 |
| 스위칭 (x3–x4, x6) | **방법 A: ±10 %** / **방법 B: 차이 자체가 결과** | A: E(Id) 표 입력 방식, Err 이중 계상, PSIM의 전압 보정 방식. B: Python 하한 가정(Qgs2·Rg 누락)의 크기 → 이 차이를 crosscheck.py 보정에 되먹인다 |
| 다이오드 (x5) | ±10 % | PSIM은 Coss 충방전이 데드타임 일부를 차지하므로 다이오드 도통이 짧아짐 (Python 과대평가 방향) |
| 데드타임 전압 오차 (E9) | ±20 % | 같은 이유 |
| 회생 (R1–R2) | ±5 % | 공급 다이오드·R_supply가 전류를 받는지, 초퍼 OFF 여부 |

방법 A·B는 [psim-build-guide.md §5](psim-build-guide.md#5-s2--열-모듈) 참조. 방법 A는 **회로 구성의 검증**이고(같은 가정이므로 일치해야 함), 방법 B(Infineon SPICE 모델 이중펄스)는 **손실 모델의 검증**이다.

## 6. 실행 순서

1. **지금**: `python3 crosscheck.py` → 결과 확인 (완료, 커밋됨)
2. **사용자**: S1을 PSIM으로 구성(가이드 §3), 경로 B·40 kHz·100 ns로 체크 표 E·B 행 채움
3. 데이터시트 원문 대조(§7 #1) → `crosscheck.py` §1 DEVICES 갱신 → 재실행 → 표 재생성
4. S2 방법 A → 방법 B 순으로 열 모듈
5. S3 회생 (C_bus·초퍼 sweep)
6. 모터 사양 확정 후 S4 + `crosscheck.py --motor motor.json`
