# Lipeat 개인 학습기

영상(또는 음성)과 자막을 넣으면 문장 단위로 끊어서 **듣기 → 따라 말하기 → 녹음 비교**를 반복하는 개인 소장용 쉐도잉 학습기입니다.
빌드 도구나 서버 없이 `index.html` 파일 하나로 동작합니다.

## 실행

```bash
# 리포지토리 루트에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000/lipeat/ 열기 (Chrome 권장)
```

`index.html`을 더블클릭해서 열어도 로컬 파일 학습은 되지만, 녹음(마이크)과 YouTube 재생은 `http://localhost` 로 여는 편이 안정적입니다.

## iPhone·Android에서 앱처럼 쓰기 (PWA)

이 앱은 홈 화면에 설치할 수 있는 웹 앱(PWA)입니다. 한 번 설치하면 전체 화면으로 열리고, 앱 화면 자체는 오프라인에서도 뜹니다.

1. 인터넷에서 열리는 주소가 필요합니다. 가장 쉬운 방법은 GitHub Pages입니다.
   - 리포지토리 **Settings → Pages → Source: Deploy from a branch**, 브랜치와 루트(`/`)를 고르고 저장합니다.
   - 몇 분 뒤 `https://<계정>.github.io/<리포지토리>/lipeat/` 로 접속됩니다. (비공개 리포지토리는 GitHub Pro 이상에서만 Pages가 됩니다.)
   - 같은 Wi-Fi 안에서만 쓰려면 PC에서 `python3 -m http.server 8000` 을 띄우고 휴대폰에서 `http://<PC IP>:8000/lipeat/` 로 열어도 됩니다. 단 이 경우 마이크 녹음은 HTTPS가 아니라 막힙니다.
2. **iPhone**: Safari로 주소를 연 뒤 아래 공유 버튼(⬆) → **홈 화면에 추가**. 앱 안에 안내 배너도 표시됩니다.
3. **Android**: Chrome에서 열면 「설치」 배너가 뜨거나, 메뉴(⋮) → **앱 설치**를 누릅니다.

iPhone에서는 「로컬 파일」 탭에서 파일 앱·사진 앱의 영상을 고를 수 있고, 녹음은 iOS 14.5 이상 Safari에서 동작합니다. 저장된 학습 데이터는 설치한 앱 안에 유지되며, 기기 간 이동은 백업 내보내기/가져오기를 사용합니다.

## 사용 순서

1. **영상 선택** – 내 PC의 mp4/webm/mp3 파일을 고르거나, YouTube 주소를 붙여넣습니다.
2. **자막** – 자막 파일이 있으면 SRT/VTT를 붙여넣거나 파일로 엽니다. 없으면 **「자막 만들기」**로 영상에서 자동 생성합니다(아래 참고). 같은 타임코드의 번역 자막을 넣으면 문장 아래에 번역이 표시됩니다.
3. **학습 시작** – 오른쪽 문장 목록에서 문장을 누르면 그 구간만 재생됩니다.

### 자막 자동 생성 (영상만 올리면 됨)

로컬 영상·음성 파일을 고른 뒤 「자막 만들기」를 누르면 브라우저 안에서 [Whisper](https://github.com/openai/whisper) 음성 인식 모델(transformers.js)이 실행되어 타임코드가 맞는 자막을 만듭니다.

- 영상은 서버로 전송되지 않고 기기 안에서만 처리됩니다. 모델 파일은 처음 한 번만 내려받고 브라우저에 캐시됩니다.
- 언어를 지정하면 정확도가 올라갑니다. 모델은 tiny(빠름) · base(보통) · small(정확, 약 250MB) 중 고릅니다.
- WebGPU를 지원하는 브라우저(PC Chrome/Edge 등)에서는 GPU로, 그 외에는 CPU(WASM)로 돌아갑니다. CPU에서는 10분 영상에 몇 분 정도 걸릴 수 있습니다. iPhone에서는 tiny 모델과 짧은 영상을 권장합니다.
- 결과는 SRT 형식으로 자막 칸에 들어가므로 오타나 잘못 잘린 문장을 고친 뒤 시작할 수 있습니다. 학습 화면의 「✎ 수정」으로도 고칠 수 있습니다.
- YouTube 영상은 브라우저가 음성을 읽을 수 없어 자동 생성이 안 됩니다. 아래 「자막 구하기」를 참고하세요.

### 자막 싱크 맞추기

학습 화면의 「자막 싱크」에서 0.1초 단위로 전체 자막을 앞뒤로 밀 수 있습니다. 자막이 영상보다 늦게 나오면 −, 빠르면 +를 누르세요. 값은 세션에 저장됩니다.

### 학습 모드

| 모드 | 동작 |
| --- | --- |
| 듣기만 | 구간을 반복 횟수만큼 재생 |
| 듣고 따라 말하기 | 재생 후 문장 길이만큼 멈춰서 따라 말할 시간을 줌 |
| 따라 말하며 녹음 | 멈춘 동안 마이크로 녹음. 원음과 내 목소리를 번갈아 비교 |

재생 속도(0.5×~1.5×), 반복 횟수, 말하기 시간, 다음 문장 자동 진행, 문장 가리기(블라인드 쉐도잉), 번역 숨기기를 설정할 수 있습니다.

### 단축키

| 키 | 기능 |
| --- | --- |
| `Space` | 연습 시작 / 정지 |
| `←` `→` | 이전 / 다음 문장 |
| `R` | 현재 문장 한 번 듣기 |
| `M` | 학습 완료 표시 |
| `H` | 문장 가리기 토글 |
| `C` | 자막 따라가며 연속 재생 |

## 데이터 저장

- 자막, 진도(완료 표시·마지막 위치), 설정은 브라우저 `localStorage`에 저장되며 「라이브러리」에서 이어서 학습할 수 있습니다.
- 브라우저는 로컬 영상 파일을 기억할 수 없으므로 파일 세션은 이어하기 시 같은 파일을 다시 선택합니다. YouTube 세션은 바로 열립니다.
- 녹음은 메모리에만 있어 페이지를 닫으면 사라집니다. 필요하면 「저장」으로 내려받으세요.
- 다른 기기로 옮기려면 라이브러리의 「백업 내보내기 / 가져오기」(JSON)를 사용합니다.

## 자막 구하기

- 영상 파일에 내장된 자막이나 함께 배포된 `.srt`/`.vtt` 파일을 그대로 사용합니다.
- YouTube 자막은 `yt-dlp --write-subs --write-auto-subs --sub-langs en --skip-download <url>` 로 `.vtt`를 받을 수 있습니다. 자동 생성 자막은 문장이 겹쳐 나오므로 「자동 생성 자막 정리」 옵션을 켠 채로 넣으세요.
- 개인 학습 용도로만 사용하고, 콘텐츠 저작권을 지켜 주세요.
