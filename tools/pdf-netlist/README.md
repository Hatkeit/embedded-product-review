# OrCAD PDF → 넷리스트 복원 스크립트 (V2000 검토용)

OrCAD Capture가 내보낸 PDF는 글자가 Type3 비트맵 글리프라 텍스트 추출이 안 된다.
글리프 이름 `gNN`이 Mac 표준 글리프 순서(chr(NN+29))라는 점을 이용해 문자를 복원하고,
선 색상(파랑=배선, 빨강=접속점, 갈색=핀, 주황=심볼, 검정=전원/포트 기호)으로
넷리스트를 만든다. `pip install pymupdf pillow` 후 `decode.py`의 PDF 경로를 바꿔 쓴다.

| 파일 | 역할 |
|---|---|
| decode.py | Type3 글리프 해독, 조각난 글자 병합 |
| extract.py | 페이지별 배선·접속점·핀·심볼·라벨 추출, 넷 union-find |
| netlist.py | 부품 주석 스택 → 부품, 핀 번호/이름, 넷 이름 |
| globalnet.py | 전원 기호·포트·별칭으로 시트 간 넷 병합 |
| dump.py | 부품별 핀-넷 목록 출력 |
| trace.py | 두 배선이 왜 같은 넷인지 경로 추적(디버그) |
| crop.py | 표시 좌표 기준 확대 이미지 생성 |

한계: 2핀 수동소자의 핀 귀속은 인접 부품과 섞일 수 있다. IC·포트·전원 넷 위주로 읽고
지적 사항은 확대 이미지로 재확인할 것.
