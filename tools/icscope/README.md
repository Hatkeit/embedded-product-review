# ICScope — Op-amp·비교기·인버터 데이터시트/회로 분석기 (Windows exe)

설치 없이 실행하는 단일 실행파일입니다. 실행하면 이 PC 안에서만 동작하는 웹서버(127.0.0.1)가 뜨고
기본 브라우저에 화면이 열립니다. 인터넷 연결을 쓰지 않으며 파일은 외부로 전송되지 않습니다.

## 실행

1. `dist/ICScope.exe` 를 내려받아 더블클릭 (서명되지 않은 exe 라 Windows SmartScreen 경고가 뜨면 “추가 정보 → 실행”).
2. 콘솔 창과 함께 브라우저가 열립니다. 콘솔 창을 닫거나 화면의 **[종료]** 를 누르면 끝납니다.
3. 파일을 화면에 끌어다 놓거나, exe 아이콘 위에 파일을 끌어다 놓아 실행해도 됩니다.
4. 옵션: `ICScope.exe -port 17321 -no-browser [파일...]`

## 넣을 수 있는 파일

| 파일 | 처리 | 신뢰도 |
|---|---|---|
| 데이터시트 PDF | 표(MIN/TYP/MAX/UNIT)에서 핵심 사양, 핀 표, 패키지, 분류 | 값마다 쪽 번호·표 이름 표시 → 원문 대조 |
| OrCAD `pstxnet.dat` (+`pstxprt.dat`, `pstchip.dat`) | 정확한 넷리스트 → 회로 분석 | **정확** |
| OrCAD Capture 회로도 PDF (기본 색상) | 그림 색상(배선 파랑·핀 갈색·접속점 빨강·몸체 주황)으로 넷리스트 복원 → 회로 분석 | **추정** |
| 그 밖의 회로도 PDF | 부품 목록만 (연결 없음) | 품번만 |

넷리스트와 회로도 PDF를 같이 넣으면 분석은 넷리스트로 하고, 회로도 PDF는 **회로도 보기**(해당 부품 위치 확대) 에 씁니다.

## 분석 내용

- Op-amp·비교기·로직 인버터를 품번(또는 IN+/IN−/OUT 핀 이름)으로 찾고, 섹션(게이트)마다
  팔로워 / 반전 / 비반전 / 차동 / 비교기(양귀환 히스테리시스) / 미사용 을 판정.
- 이득, 피드백 극, 입력 분압비·테브난 저항·시정수, 출력 RC 필터, 비교기 히스테리시스(전원 레일 자동 추적) 계산.
- 제안: 션트 차동증폭 → 전류감지 증폭기 IC(가까운 고정 이득), 같은 션트를 이미 재는 IC 가 있으면 중복 표시,
  ADC 앞 버퍼 → 분압 직결(전하분배 오차·재충전 시간 계산) 또는 MCU 내장 OPAMP, 비교기 → MCU 내장 COMP,
  MCU 신호 인버터 → GPIO/타이머 극성 설정, 미사용 섹션·부유 입력 경고.
- 같은 ADC 노드를 두 출력이 구동하는 경우(이중 드라이버), 넷 이름 `NC` 에 여러 핀이 묶인 경우를 경고.
- STM32G474 MCU 핀은 ST 핀 데이터(STM32CubeMX DB)로 ADC/COMP/OPAMP/DAC 기능을 같이 표시.
- 데이터시트를 같이 넣으면 같은 품번의 사양을 회로 카드에 붙이고, 전원 전압을 권장 범위와 비교.
- CSV 저장(회로 분석, 사양), 데이터시트 여러 개 사양 나란히 비교.

## 검증 (개발 중 확인한 것)

- PDF 엔진: 글리프 위치·텍스트를 PyMuPDF 와 대조 — 데이터시트 오차 0, OrCAD 회로도 중앙값 0.01 pt.
- V2001 OrCAD 넷리스트(2026-09-22): U2 차동(이득 51.1/75, 션트 R101 2 mΩ → 0.102 V/A, INA240 과 ADC 노드 이중 구동),
  U3·U4 버퍼(분압 1/51, 1/40.2), U10 (L+N)/2 동상 검출(20 mΩ 입력 경고), U11 1.65 V 기준 버퍼, U12 비교기 히스테리시스 0.30 V,
  미사용 섹션 U4B·U11B, `NC` 넷 150핀 병합 — 수작업 검토서 `docs/V2001-opamp-to-ic.md` 와 일치.
- V2000 회로도 PDF 복원: 2단자 수동소자 513개 중 481개가 정확히 2핀(나머지 대부분 3핀 듀얼 다이오드 등), MCU 128핀 이름·넷 복원.
- 단위 테스트: `go test ./...` (합성 회로로 팔로워·차동·비교기·인버터·NC 판정 확인).

## 한계

- 규칙 기반 추출입니다. 판정 근거(부품·넷·페이지)를 같이 보여주니 설계 결정 전에 원문으로 확인하세요.
- 스캔(이미지) PDF 는 읽지 못합니다. 표 구조가 특이한 데이터시트는 값이 다른 열에 들어갈 수 있습니다
  (데이터시트 탭의 “추출된 표 행 전체”에서 원 행 확인).
- 회로도 PDF 복원은 OrCAD Capture 기본 색상일 때만 동작하며, 2단자 부품의 핀 귀속이 인접 부품과 섞일 수 있습니다.
- 대체 제안은 회로 형태에 따른 일반 대안입니다. 대체 IC 의 공통모드 범위·대역·정밀도는 해당 데이터시트로 확인하세요.

## 빌드

Go 1.22 이상, 외부 의존성 없음(표준 라이브러리만).

```
cd tools/icscope
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags "-s -w" -o dist/ICScope.exe ./cmd/icscope
```

| 경로 | 내용 |
|---|---|
| `internal/pdf` | PDF 파서(xref/객체스트림/필터/암호화), 폰트(Type0/Type1/TrueType/Type3), 페이지 해석기 |
| `internal/datasheet` | 표 머리글·열 경계·행 추출, 핵심 사양 선택, 핀 표 |
| `internal/orcad` | `pstxnet/pstxprt/pstchip.dat` 읽기 |
| `internal/schematic` | OrCAD 색상 회로도 PDF → 넷리스트, 참조번호 위치, 페이지 SVG |
| `internal/analysis` | 부품 분류, 섹션 핀 배정, 회로 형태 판정·계산·제안 |
| `cmd/icscope` | 로컬 웹서버 + 화면(`web/index.html`, exe 에 내장) |
| `cmd/pdfdump`, `cmd/nlcheck` | 개발용 점검 도구 |
