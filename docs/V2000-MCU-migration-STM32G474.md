## 1. 대상 보드 분석 결과

### 1.1 전력단 구조

| 구분 | 내용 |
|---|---|
| 제품 유형 | 2입력(PVA / PVB) 계통연계 마이크로인버터 |
| DC-DC | **채널당 2상 인터리브드 플라이백 × 2채널 = 총 4상** |
| 1차 스위치 | BSC190N15NS3 (150 V) **상당 2개 병렬** → 총 8개 (S100~S103, S200~S203) |
| 게이트 드라이버 | SCT52240STDR 듀얼 드라이버 × 2 (U100, U200), 게이트 저항 10 Ω |
| 트랜스포머 | T100 / T101 / T201 / T202 (4개), 2차 정류 B1D02120E **1200 V** |
| 출력 버스 | **+HV / HGND — 정류된 정현파, 벌크 커패시터 없음** |
| 언폴더 | STF23N80K5 (800 V) × 2 (S300, S301) + OSG65R360DEF (650 V) × 1 (S302) |
| 전력 디커플링 | **PV측 수동 — 2700 µF/63 V 전해 × 8개 = 약 21.6 mF** |
| AC 보호 | GDT(SL1411A600) + MOV 5개 + 퓨즈 T10A250V + 릴레이 K300 |

### 1.2 V2000 사양서와의 교차 검증

이 보드는 §V2000 설계 사양서에서 기술한 **언폴딩 구조 그 자체**이며, 두 가지가 서로를 검증합니다.

1. **+HV 버스에 벌크 커패시터가 없다** (스너버용 10 nF/150 pF 세라믹·필름만 존재).
   → V2000 §2.3의 "언폴딩 구조에는 일정한 DC 링크가 존재하지 않는다"가 실물로 확인됨.
2. **PV측에 2700 µF/63 V 전해 8개 = 21.6 mF** 가 실장되어 있다.
   → V2000 §17.4에서 계산한 "PV측 수동 디커플링 시 500 W당 8.3 mF 필요"와 일치한다
   (2채널·여유분 고려 시 채널당 약 10.8 mF). **본 보드는 수동 디커플링 방식이며,
   따라서 전해 커패시터 수명이 제품 수명의 상한을 결정한다.**
   V2000이 APD를 채택한 이유가 이 보드의 BOM으로 직접 입증된다.

### 1.3 제어 방식 (스키매틱에서 확인된 것)

| 기능 | 구현 |
|---|---|
| 상전류 검출 | **전류 트랜스포머** PA1005.100NL × 4 (TR100/101/200/201) + 다이오드 피크 검출 |
| 사이클별 전류 제한 | F28034 내장 COMP1/COMP2 (PVA) + 외부 비교기 TP1946 × 2 (PVB) |
| **전류 제한 기준의 계통 전압 피드포워드** | U406B(-)에 PVB 상전류, (+)에 **AC-N 전압(ADCINB6)** 을 R455 100 kΩ로 주입 → 피크 전류 한계가 \|v_ac\|를 추종 |
| 계통 영교차 | 외부 비교기 U401(SGM8709) → GPIO24(eCAP1) + 절연 옵토 2채널(GPIO41/42) |
| 언폴더 구동 | GPIO43/GPIO44 → SN74HC14 → 옵토(ELD207) → HEF40106B 버퍼 → 게이트 |
| 언폴더 과전류 | 80 mΩ 션트 × 4 + BC847S 검출 → 옵토(FOD817) → GPIO12(TZ1) |
| 클럭 | 20 MHz 크리스털 Y500 → PLL → 60 MHz |

> **주목할 설계**: U406B의 전류 제한 기준을 AC 전압으로 변조하는 구조는,
> 플라이백이 정현파를 성형할 때 피크 전류 한계도 함께 정현파로 움직여야 한다는 요구를
> **아날로그 하드웨어로 해결한 것**입니다. STM32G474로 이전 시 이 기능은
> 내장 DAC(DAC3/DAC4)를 DMA로 정현파 갱신하여 COMP 기준에 직접 넣는 방식으로
> 대체할 수 있으며, 외부 부품 없이 더 정밀해집니다 (§5.4).

## 3. STM32G474 자원 대조

### 3.1 코어·주변장치 1:1 대조표

| 요구 자원 | TMS320F28034 (현행) | STM32G474 | 판정 |
|---|---|---|---|
| CPU | C28x 60 MHz, 고정소수점 (FPU 없음) | Cortex-M4F **170 MHz** + FPU + **CORDIC** + **FMAC** | **대폭 상위** |
| 코드 메모리 | 64 KB 플래시 | **512 KB** 플래시 | 여유 |
| RAM | 10 KB | **128 KB** (96 KB + **32 KB CCM**) | 여유 |
| ADC 채널 | 12-bit × 16ch, **단일 SAR** 4.6 MSPS | 12-bit, **5개 독립 SAR**, 42ch, 최대 4 MSPS, HW 오버샘플링 16-bit | **상위** (동시 샘플링 가능) |
| 아날로그 비교기 | 3개 (10-bit DAC 기준) | **7개** (12-bit DAC3/DAC4 기준) | 여유 |
| 내장 op-amp | 없음 | **6개** (PGA 모드, ADC 내부 연결) | 신규 이점 |
| 내장 DAC | 없음 (COMP 전용) | DAC1/2 외부 출력 + DAC3/4 내부 | 신규 이점 |
| 고해상도 PWM | ePWM 7모듈, 일부 HRPWM | **HRTIM1**: 마스터 + 6 타이밍 유닛 = **12 출력**, 184 ps | 동등~상위 |
| 범용 PWM | — | TIM1/TIM8/TIM20 (상보+BKIN) 외 다수 | 여유 |
| 트립 입력 | TZ1/TZ2/TZ3 | HRTIM **FLT1~FLT6** + TIM BKIN/BKIN2 | 여유 |
| 캡처 | eCAP 32-bit @ 60 MHz | TIM2/TIM5 **32-bit @ 170 MHz** 입력 캡처 | 상위 |
| UART / I²C / SPI | SCI ×1, I²C ×1, SPI ×2 | USART ×4 + LPUART, I²C ×4, SPI ×4 | 여유 |
| CAN | eCAN ×1 (본 보드 미사용) | **FDCAN ×3** | 상위 |
| 안전 라이브러리 | — | X-CUBE-CLASSB (IEC 60730 Class B) | 인증 시 이점 |

**모든 항목에서 요구를 충족하거나 상회한다. 자원 부족으로 인한 불가 사유는 없다.**

### 3.2 패키지 선정

STM32G474 전 패키지의 자원을 ST 공식 핀 데이터(`STM32_open_pin_data`)에서 직접 집계한 결과다.
**LQFP144 품목은 존재하지 않으며, 최대 패키지는 LQFP128이다.**

| 품번 | 패키지 | I/O | 아날로그 가능 핀 | HRTIM 출력 | ADC1/2/3/4/5 외부채널 | 평가 |
|---|---|---|---|---|---|---|
| STM32G474**Q**Ex | LQFP128 (14×14) | 107 | 42 | 12 | 14/16/15/16/13 | 최대 패키지. 이 설계에는 과잉 |
| STM32G474**P**Ex | UFBGA121 | 102 | 42 | 12 | 14/16/15/16/13 | BGA — 옥외 제품 신뢰성·수리성 관점에서 비권장 |
| STM32G474**V**Ex | LQFP100 (14×14) | 86 | 42 | 12 | 14/16/15/16/13 | **시제품 권장** — 5-ADC 동시 샘플링을 온전히 쓸 수 있는 최소 패키지 |
| STM32G474**M**Ex | LQFP80 (12×12) | 66 | 38 | 12 | 14/16/11/12/9 | 현행 LQFP80과 동일 외형, 양산 원가절감 후보 |
| STM32G474**R**Ex | LQFP64 (10×10) | 52 | 26 | 12 | 14/16/**3/3/2** | 47핀 대비 여유 5핀. HRTIM 12출력은 모두 확보되나 **ADC3/4/5가 사실상 없어 다중 ADC 이점 상실** |
| STM32G474**C**Ex | LQFP48 (7×7) | 38 | 20 | **8** | 10/10/3/3/2 | HRTIM 출력이 8개로 축소 — **탈락** |

패키지가 바뀌어도 코어·플래시·RAM·주변장치 인스턴스 수는 동일하다(같은 다이). 달라지는 것은
**핀으로 나오는 신호의 개수**뿐이다. 특히 ADC3/4/5는 LQFP64에서 외부 채널이 각각 3/3/2개로
줄어 5개 ADC 동시 샘플링 구조를 세울 수 없다. FMC(외부 메모리 버스)는 LQFP100 이상에만 있으나
이 설계에는 불필요하다.

**LQFP64 성립성 — 핀 충돌까지 계산한 결과**

| 항목 | LQFP64 | LQFP100 |
|---|---|---|
| 아날로그 가능 핀 | 26 | 42 |
| 그중 HRTIM 출력 핀과 겹침 | 6 | 6 |
| HRTIM 12출력을 모두 쓴 뒤 남는 아날로그 핀 | **20** | 36 |
| 필요 아날로그 입력 | 16 | 16 |
| ADC3/4/5로 읽을 수 있는 핀 | **8** (그중 5개는 ADC1/2와 공유) | 24 |

산술적으로는 LQFP64도 성립한다(20 ≥ 16). 그러나 남는 4핀 안에 UART·CAN·디버그·DO/DI를
모두 욱여넣어야 하고, ADC3/4/5 전용 핀이 3개뿐이라 **아날로그 16채널 대부분이 ADC1/ADC2에
몰린다.** C28x 대비 개선하려던 동시 샘플링이 바로 이 지점에서 무너진다.

**LQFP100 vs LQFP128 — 상위 패키지로 올릴 이유가 있는가**

두 패키지의 핀 집합을 신호 단위로 차분한 결과, **전력변환에 쓰는 자원은 핀 하나까지 완전히
동일하다.** LQFP128은 LQFP100의 진부분집합이 아니라 상위집합이며, 늘어난 21핀은 전부
범용 포트다.

| 항목 | LQFP100 | LQFP128 | 차이 |
|---|---|---|---|
| I/O | 86 | 107 | +21 (PF 11개 · PG 10개) |
| PA · PB · PC · PD · PE | 각 16 | 각 16 | **동일** — 주요 포트는 100핀에서 이미 전량 인출 |
| 아날로그 입력 핀 | 42 | 42 | **동일한 핀 집합** |
| HRTIM1 출력 | 12 | 12 | **동일한 핀** |
| COMP INP / INM 핀 | 14 / 14 | 14 / 14 | **동일한 핀** |
| DAC 외부 출력 | 3 | 3 | **동일한 핀** |
| 100에만 있고 128에 없는 신호 | — | — | **없음** |
| 128에서 새로 생기는 신호 종류 | — | 19 | **전부 FMC** (A1, A3~A15, A24, NE2~4, INT) |
| 리드 피치 | 0.5 mm | **0.4 mm** | 같은 14×14 몸체에 32핀/변 |

기존 신호 중 배치 선택지가 늘어난 것은 61종이며 TIM20(11종)·SAI1(5)·LPUART1(5)·SPI1(4)·
I2C3/I2C4(각 3)·QUADSPI1(3)에 몰려 있다. ADC1~5도 각각 2종씩 늘지만 이는 `ADCx_EXTI3`
**외부 트리거 입력**이지 변환 채널이 아니다 — 아날로그 채널 수는 변하지 않는다.

FMC는 LQFP100에도 데이터 D0~D15와 A0/A2/A16~A23/A25, NE1이 나와 있어 멀티플렉스 버스는
구성되지만 **A1과 A3~A15가 없어 비멀티플렉스 SRAM/NOR 버스는 세울 수 없다.** 외부 병렬
메모리를 붙일 계획이 있을 때만 LQFP128이 의미를 갖는다.

> **결론 — LQFP128로 올릴 이유가 이 설계에는 없다.** 아날로그·HRTIM·비교기·DAC가 동일한
> 핀에 동일한 수로 나오므로 얻는 것은 범용 GPIO 21개뿐이고, 대가로 리드 피치가
> 0.5 mm에서 0.4 mm로 좁아진다. 옥외 IP67 · 컨포멀 코팅 제품에서 이 피치 축소는
> 실장 수율과 리워크 난도에 그대로 반영된다. LQFP128은 **외부 FMC 버스가 필요하거나
> 범용 I/O가 20개 이상 더 필요할 때**만 검토한다.

**온도 등급 (중요)**

현행 `TMS320F28034PNT` 의 `T` 접미는 −40 ~ +105 ℃ 등급입니다.
IP67 무팬 옥외 제품이므로 STM32도 동등 이상이 필수입니다.

| 접미 | 범위 | 채택 |
|---|---|---|
| `...T6` | −40 ~ +85 ℃ | **불가** |
| `...T7` | −40 ~ +105 ℃ | **최소 요구** |
| `...T3` | −40 ~ +125 ℃ | 권장 (가용 품번 확인 필요) |

> **권장 품번: `STM32G474VET7` (LQFP100, 512 KB, −40~105 ℃)**
> 흔히 쓰는 `...T6` 를 그대로 발주하면 85 ℃ 등급이 들어와 사양 미달이 됩니다.
> 발주서 접미 확인이 이 검토에서 가장 실수하기 쉬운 지점입니다.

| # | 전제 조건 | 성격 |

이것이 이번 교체의 난이도를 실질적으로 낮추는 가장 큰 요인입니다.

## 5. 자원 할당 제안

### 5.1 HRTIM1 — 전력단 전체를 하나의 타이머로

| HRTIM 유닛 | 출력 | 용도 | 비고 |
|---|---|---|---|
| Master | — | 공통 주기 · 4상 인터리빙 위상 기준 | |
| Timer A | TA1 | PVA 1상 (GPIO0 대체) | 위상 0° |
| Timer B | TB1 | PVA 2상 (GPIO2 대체) | 위상 180° |
| Timer C | TC1 | PVB 1상 (GPIO4 대체) | 위상 0° (또는 90°) |
| Timer D | TD1 | PVB 2상 (GPIO6 대체) | 위상 180° (또는 270°) |
| Timer E | TE1/TE2 | 언폴더 게이트 A/B (GPIO43/44 대체) | 60 Hz, 데드타임 HW 생성 |
| Timer F | — | 예비 (APD 등 확장용) | |

**현행 대비 이점**: F28034는 ePWM1~4를 SYNC 체인으로 묶어 위상을 맞춰야 했지만,
HRTIM은 마스터 타이머 기준 위상 오프셋이 하드웨어 기능이다.
또한 언폴더 데드타임(V2000 §6.5의 ±100 µs)을 소프트웨어 타이머가 아닌
**HRTIM 데드타임 유닛으로 생성**할 수 있어 지터가 제거된다.

### 5.2 ADC — 5개 SAR 분산 배치

| ADC | 담당 신호 | 트리거 |
|---|---|---|
| ADC1 | PVA 상전류 ×2 (구 ADCINA2/A4) | HRTIM ADC Trigger (상별 전류 중점) |
| ADC2 | PVB 상전류 ×2 (구 ADCINB6→PVB CT, ADCINB7 계열) | HRTIM ADC Trigger |
| ADC3 | AC-L / AC-N 전압 (고속·필터 4채널) | HRTIM 주기 동기 |
| ADC4 | PV 전압·입력전류 (구 A3/A7/B0/B1/B5) | 주기 동기 (저속) |
| ADC5 | 보조 레일, 절연 감시, 온도 (구 B2/B4) | 소프트웨어 / 저속 타이머 |

**현행 대비 이점**: F28034는 단일 SAR로 16채널을 순차 변환하므로
4상 전류를 **동시에** 샘플링할 수 없다(채널 간 시간 스큐 발생).
G474는 ADC1/ADC2로 PVA·PVB 전류를 동시 취득할 수 있어 상 밸런싱 정밀도가 올라간다.

### 5.3 비교기 — 외부 부품 3개 제거 가능

| COMP | 입력 | 기준 | 대체 대상 |
|---|---|---|---|
| COMP1 | PVA 1상 전류 | DAC3_CH1 | 현행 F28034 COMP1 (동등) |
| COMP2 | PVA 2상 전류 | DAC3_CH2 | 현행 F28034 COMP2 (동등) |
| COMP3 | PVB 1상 전류 | DAC4_CH1 | **외부 U406A (TP1946) 제거** |
| COMP4 | PVB 2상 전류 | DAC4_CH2 | **외부 U406B (TP1946) 제거** |
| COMP5 | AC 전압 영교차 | DAC1 또는 고정 기준 | **외부 U401 (SGM8709) 제거** |
| COMP6 | 언폴더 과전류 (옵션) | DAC | 옵토 이후 디지털 트립 유지 시 미사용 |
| COMP7 | 예비 | | |

모든 COMP 출력은 HRTIM의 FLT 입력 또는 타이머 리셋 이벤트로 **CPU를 거치지 않고**
직결되므로, 사이클별 전류 제한 응답 시간은 현행과 동등하거나 더 짧다.

### 5.4 전류 제한 기준의 정현파 변조 — HW 아날로그에서 DAC+DMA로

현행 보드는 U406B의 비반전 입력에 AC-N 전압(ADCINB6)을 R455 100 kΩ로 주입하여
피크 전류 한계를 \|v_ac\|에 비례시킵니다 (§1.3).

G474에서는 **DAC3/DAC4를 DMA로 구동**하여 정현파 기준 테이블을 출력하는 방식으로
대체합니다.

| 항목 | 현행 (아날로그 주입) | G474 (DAC + DMA) |
|---|---|---|
| 정확도 | 저항 오차 · op-amp 오프셋에 종속 | 12-bit, 온도 드리프트 무관 |
| 위상 정합 | AC 센싱 경로 지연에 종속 | PLL 위상과 소프트웨어로 정확히 정렬 |
| 파형 변경 | 저항 변경 필요 | 테이블 교체 |
| 부품 | R455, R456, U406A/B | 없음 |
| CPU 부하 | 0 | 0 (DMA) |

**아날로그 회로 3개를 제거하면서 정밀도가 올라가는, 이번 교체의 가장 명확한 이득입니다.**

### 5.5 기타

| 기능 | 할당 |
|---|---|
| 계통 영교차 캡처 | TIM2 (32-bit) 입력 캡처 — 170 MHz 분해능 (현행 60 MHz 대비 2.8배) |
| AC 극성 검출 ×2 | 범용 GPIO + EXTI |
| 트립 입력 (TZ1/TZ2) | HRTIM FLT1 / FLT2 |
| 릴레이 구동 | 범용 GPIO |

| EEPROM | I2C1 |
| 디버그 | SWD 2선 (현행 JTAG 5선 대비 핀 3개 절감) |

## 6. 성능 검증

### 6.1 연산 예산

스위칭 주파수를 `fsw` 라 할 때 제어 ISR 1회당 가용 사이클:

| MCU | 클럭 | fsw = 65 kHz | fsw = 100 kHz | fsw = 150 kHz |
|---|---|---|---|---|
| F28034 (현행) | 60 MHz | 923 cycle | 600 cycle | 400 cycle |
| **G474** | **170 MHz** | **2,615 cycle** | **1,700 cycle** | **1,133 cycle** |
| 배율 | | **2.83×** | **2.83×** | **2.83×** |

> **단, 사이클 수 단순 비교는 과대평가입니다.** C28x는 단일 사이클 MAC과
> 32-bit 어큐뮬레이터, 하드웨어 반복 명령을 갖춘 DSP 코어여서
> 제어 루프 코드에 한해 사이클당 효율이 Cortex-M4보다 높습니다.
> 실효 성능비는 2.83배가 아니라 **약 1.5~2배** 로 보는 것이 안전합니다.
> 그래도 여유는 충분하며, 다음 두 가속기가 격차를 다시 벌립니다.

| 가속기 | 용도 | 효과 |
|---|---|---|
| **CORDIC** | sin/cos/atan2 — SOGI-PLL, 정현파 기준 생성 | 소프트웨어 대비 수십 사이클 절감, 룩업테이블 불필요 |
| **FMAC** | FIR/IIR — 전류 보상기, 노치, 반복 제어기(RC) | CPU와 병렬 실행, ISR 부하에서 완전히 분리 |

**결론**: 현행 F28034가 60 MHz·FPU 없이 4상 + 언폴더 + PLL + MPPT를 처리하고 있으므로,
G474에서 연산 여유는 문제되지 않습니다. 오히려 V2000 사양서 §6.4의
**반복 제어기(RC) 도입 여지**가 새로 생깁니다 (현행 F28034에서는 사실상 불가능).

### 6.2 지연 시간

| 항목 | F28034 | G474 | 판정 |
|---|---|---|---|
| 인터럽트 응답 | 약 16 cycle @ 60 MHz ≈ 267 ns | 약 12 cycle @ 170 MHz ≈ 71 ns | 상위 |
| ADC 변환 (12-bit) | 약 217 ns (4.6 MSPS) | 약 200~400 ns / SAR, **5개 병렬** | 동등~상위 |
| 비교기 → PWM 차단 | 내부 직결, 수십 ns | COMP → HRTIM FLT 직결, 수십 ns | 동등 |
| PWM 분해능 | HRPWM 약 150 ps | HRTIM **184 ps** | 동등 |

### 6.3 반드시 지켜야 할 구현 조건

| 조건 | 이유 |
|---|---|
| 제어 ISR 코드를 **CCM SRAM(32 KB)** 에 배치 | 170 MHz에서 플래시는 4 wait state. CCM은 0 wait state. |
| ART 가속기 / 프리페치 활성화 | 플래시 실행 코드의 성능 확보 |
| ISR 실행 시간 상시 계측 (DWT CYCCNT) | V2000 §11.3과 동일 요구. RC 도입 시 필수 |
| FPU 레지스터 lazy stacking 설정 검토 | ISR 진입/이탈 오버헤드 |

| P1 | HRTIM 단독 파형 검증 (전력단 미연결) | 4상 위상·주파수·데드타임이 설계값과 일치 |
| P2 | ADC + COMP 정적 검증 | 기지 전압 인가 시 변환값 오차 < 1 %, COMP 트립 임계 오차 < 2 % |
| P3 | 전류 제한 동작 (저전압 전력단) | 저전압 버스에서 사이클별 전류 제한 동작 확인 |
| P4 | 개루프 정현파 성형 | 저항 부하에서 \|sin\| 파형 육안 확인 |
| P5 | 계통 모의 연계 (Grid Simulator) | THD < 5 %, 역률 > 0.99 |
| P6 | 보호 동작 | V2000 §9.1 전 정정치 시간 이내 차단 |
| P7 | 효율 비교 | **현행 F28034 보드 대비 동등 이상** ← 최종 통과 기준 |

> **P7이 이번 마이그레이션의 최종 판정 기준입니다.** MCU를 바꿔 효율이 떨어지면
> 제어(전류 성형 정밀도, 샘플링 타이밍)에 문제가 있다는 뜻이므로,
> 반드시 동일 전력단·동일 조건에서 A/B 비교해야 합니다.

## 10. 결론

| 질문 | 답 |
|---|---|
| STM32G474로 동작 가능한가? | **가능하다.** 자원 부족에 의한 불가 사유는 없다. |
| 드롭인 교체가 가능한가? | **불가능하다.** PCB 재설계와 펌웨어 주변장치 계층 재작성이 필수다. |
| 아날로그 회로는 재사용되는가? | **거의 그대로 재사용된다.** AFE 출력이 이미 0~3.3 V로 정합되어 있다. |
| 바꿀 만한 이점이 있는가? | 연산 여유 1.5~2배, ADC 동시 샘플링, **외부 비교기 3개 제거(U401/U406A/U406B)**, DAC 기반 전류 기준 정밀화, FDCAN 확보, IEC 60730 Class B 라이브러리 확보 |

| 다음 할 일 한 가지는? | **CubeMX에서 47개 신호 + 4개 COMP 입력의 핀 배치를 확정**하고 패키지를 결정한다 |
