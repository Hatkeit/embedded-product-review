# V2000 주 플라이백 변압기 T2 · T4 · T6 · T8 설계사양서 (Rev 0.1)

- 기준 넷리스트: pstxnet.dat 2026-09-20 (PSTWRITER 17.4). 네 변압기는 심볼·풋프린트·주변 결선이 동일하므로 한 사양으로 통일한다.
- 설계 조건(사용자 제시): PV 입력 18~50 V, 변압기당 150 W max(보드 500 W = 2채널 × 2상, 정격 125 W/상), PHV 400 Vdc.
- 근거 데이터시트: IAUCN10S7L040 (Infineon Rev 1.0), SCS205KNHR (ROHM TSQ50244), PA1005.100NLT (Pulse SPM2007_58), 2EDN7524R(전회 검토).
- 표기: ✔ 넷리스트로 확인 / 계산 = 본 문서 수식 / 미확보 = 데이터 없음(가정 명시)

권선 (PQ35/35 기준, N_p 8 / N_s 80):
- 1차: 10.7 A_rms → 2.4 mm² → 리츠선 0.1 mm × 300가닥(2.36 mm²) 또는 동박 0.15 mm × 20 mm 2겹. **4 + 4 턴으로 분할해 P–S–P 샌드위치**(누설 0.5 % 목표).
- 2차: 0.72 A_rms → 0.16 mm² → TIW 0.5 mm(0.196 mm²) 80턴, 2층. 400 V 권선이므로 층간 테이프.
- 공극은 A_L 값으로 지정: A_L = L_p / N_p² = 24 µH / 64 = **375 nH/T²** (PQ35/35), PQ32/30이면 240 nH/T².
- 코어 손실(추정): ΔB/2 ≈ 41 mT, 100 kHz, 100 ℃ → 약 30~50 kW/m³ × 16.3 cm³ = 0.5~0.8 W (미확보: 재료 곡선으로 확정).
