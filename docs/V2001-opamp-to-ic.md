## 0. 긴급 — `NC` 넷 150핀 병합 (절연 경계 단락) 〔치명〕

이번 추적 중 발견했다. 사용하지 않는 핀에 **넷 이름 `NC`** 를 붙여서, OrCAD가 **150개 핀을 하나의 넷 `NC`로 묶었다.** Allegro는 넷 이름 `NC`를 무연결로 취급하지 않으므로 이 150핀이 한 넷으로 러츠네스트·배선된다. 앞선 검토들에서 각 핀의 넷이 `NC`인 것을 "무연결"로 읽고 넘어갔는데, **실제로는 전부 하나로 이어져 있었다.** (앞서 지적한 "PB10 → R272 → `NC`" 회귀도 같은 원인이다)

## 2. U2 → INA240A2 (이미 실장된 U21·U22)

현재 `ADC_I_PA`·`ADC_I_PB`에는 **U2와 INA240이 동시에 물려 있다**(N13). INA240 한쪽만 남기면 된다.

| 항목 | U2 이산 차동증폭 (현재) | INA240A2 (데이터시트 ✔) |
|---|---|---|
| 이득 | A 51.1 / **B 75** (비대칭, N21) | 50 V/V 고정 (양 채널 동일) |
| 이득 오차 | F급(±1 %) 저항 4개 → 최악 **±2 % 이상** (계산) | **±0.20 % max** |
| 이득 드리프트 | 저항 TCR 의존 | **±2.5 ppm/℃ max** |
| 입력 오프셋 | OPA2387 데이터시트 **미확보** | **±25 µV max** (2 mΩ에서 12.5 mA) |
| CMRR | 저항 정합 의존: (1+51.1)/(4×1 %) ≈ **62 dB** (계산) | **120 dB min** |
| 대역폭 | 피드백 극 **3.1 kHz** | **400 kHz** (출력 필터 R166 1 kΩ + C135 10 nF = 15.9 kHz) |
| 채널 B 입력 | `PV_B−` **단일핀 넷 — 션트 없음** (N15) | R43 2 mΩ에 이미 연결 ✔ |
| 부품 수 | 20개 | 0개 추가 |

**삭제 목록 (20)**: U2, R151, C124, R152~R160, R287, C123, C125, C126, C127, C128, C207, **R101**
→ 해소되는 지적: **N13**(ADC 노드 이중 드라이버), **N14/N21**(U2B 피드백·이득 비대칭), **N15**(PV_B− 션트 없음), **R6/R101 병렬 중복**.

**전제 — G1은 여전히 고쳐야 한다.** INA240 IN+가 `I_PV_A+`(Q1~Q8 소스·드라이버 GND, 32핀)에 있고, 이 넷이 GND에 묶여야 동상전압이 0 V 근처가 된다(INA240 허용 −4~+80 V).

**⚠ 결정 필요 — 앞선 제 권고를 뒤집는 내용입니다.** 션트 검토서 9-5에서는 원본 R103 계승과 DC 정밀도를 이유로 "R101 + U2 존치, R6·INA240 제거"(안 1)를 권했습니다. INA240의 확인된 사양(오프셋 ±25 µV, 이득오차 ±0.20 %, CMRR 120 dB)이 DC 정밀도에서도 이산 회로와 같거나 낫고, 대역은 130배 넓으며, **INA240이 걸린 R6가 지금 넷리스트상 실제 전류 경로**(J3/J4 → R6 → FET 소스)에 있습니다. R101이 있는 `PV_A−`는 단자에 연결되어 있지 않습니다(G2). 그래서 **안 2(R6 + INA240 존치, R101 삭제)** 를 권합니다.
원본처럼 R101 위치(PV− ↔ GND 저측)를 고수하려면 **INA240을 R101 양단으로 옮기고 R6를 삭제**해도 됩니다(저측이라 CM ≈ 0 V). 어느 쪽이든 IC 1개·션트 1개로 끝납니다.

## 3. U3 → 삭제 (분압 직결)

```
V_PA ──R164 1 MΩ──┬── (U3A 버퍼) ── R165 510 Ω ── ADC_V_PA → PA0 (pin 27)
                  R163 20 kΩ   C129 1 nF
                  GND
```

- 분압 테브난 저항 = 1 MΩ ∥ 20 kΩ = **19.6 kΩ**. 버퍼를 빼고 **C129를 1 nF → 10 nF**로 키우면 ADC 샘플 커패시터와의 전하분배 오차가 5 pF/10 nF = **0.05 %(2 LSB)** (C_ADC 5 pF는 앞선 검토와 같은 가정).
- 재충전 시정수 19.6 kΩ × 10 nF = 196 µs → 12비트 정착 9τ = 1.8 ms → 채널당 **약 500 Hz** 샘플까지. PV 전압은 EC 2 700 µF ×6 뒤라 느리므로 MPPT·과전압 감시에 충분하다.
- MCU 내장 OPAMP 팔로워로 바꾸는 방법은 **핀이 맞지 않는다**: PA0는 OPAMP VINP가 없고(COMP1_INM·COMP3_INP), PA2는 **OPAMP1_VOUT** 핀이다(✔ ST 핀 데이터). 내장 OPAMP를 쓰려면 PA1·PA7(OPAMP1_VINP) 등으로 재배치해야 하는데, 버퍼 자체가 필요 없으므로 권하지 않는다.
- **덤**: 분압비 1/51이면 50 V에서 0.98 V로 ADC 범위의 33 %만 쓴다. R163을 **51 kΩ**(R186과 공용)으로 바꾸면 50 V → 2.43 V(81 %), 풀스케일 61.8 V. 테브난 48.5 kΩ, 10 nF에서 샘플 약 230 Hz.

**삭제 (3)**: U3, R161, C130 / **값 변경**: C129·C136 1 nF → 10 nF / R165·R170 510 Ω은 핀 보호용으로 유지.

## 4. U4 → 삭제 (직결)

```
I_GRID_LK ──R183 1 MΩ──R184 1 MΩ──┬── (U4A 버퍼) ── R185 510 Ω ── ADC_I_GRID_LK → PD12 (pin 74)
                                   R186 51 kΩ   C165 2.2 µF
```

- 테브난 2 MΩ ∥ 51 kΩ = **49.7 kΩ**, 이미 **2.2 µF**가 붙어 있어 전하분배 오차는 5 pF/2.2 µF ≈ **2 ppm**. 버퍼가 하는 일이 없다.
- PD12는 **COMP5_INP**이기도 하다(✔ ST 핀 데이터). 내장 DAC 문턱과 비교하면 **누설 과전류를 CPU 개입 없이 하드웨어로 트립**할 수 있다(COMP5 INM에 연결되는 내부 DAC 채널은 **RM0440 확인 필요**).
- U4B 미사용 게이트(부유 입력) 지적도 함께 사라진다.
- **주의(버퍼와 무관)**: 이 입력망은 **계통 L 단자(N17838031)에서 C58 150 nF → R183 + R184 2 MΩ(1206)** 을 거쳐 GND 영역으로 들어온다. 09 시트(F1)와 같은 성격의 절연 경계 횡단이므로, 버퍼를 빼든 말든 **R183·R184의 정격전압·직렬수·연면거리**를 F1과 같은 기준으로 검토해야 한다.

**삭제 (3)**: U4, R181, C163 / R185 유지.

## 5. U10 · U11 · U12 (09 시트 전체) → AMC3301 + 내장 COMP7

09 시트는 계통을 **R219·R228(현재 20 mΩ, F1)** 로 PV측 GND 회로에 직접 끌어와 (L+N)/2를 버퍼링하고 제로크로스를 만든다. 같은 정보를 **강화절연된 U23 AMC3301이 이미 측정**하고 있다.

### 5-1. 현재 AMC3301 출력 배선 (✔)

| AMC3301 핀 | 경로 | MCU 핀 | 그 핀의 내장 기능 (ST 핀 데이터 ✔) |
|---|---|---|---|
| 11 OUTP | R175 1 kΩ → `ADC_V_GRID_N` → R267 0 Ω | **PB15** (pin 69) | ADC2_IN15, ADC4_IN5, **COMP6_INM**, OPAMP5_VINM |
| 10 OUTN | R177 1 kΩ → `ADC_V_GRID_L` → R268 0 Ω | **PB14** (pin 68) | ADC4_IN?, **COMP7_INP**, OPAMP2/5_VINP |

(넷 이름이 뒤바뀌어 있다: OUTP가 `…_N`, OUTN이 `…_L`. 기능에는 영향 없으나 정리 권장)

### 5-2. 제로크로스 구현 — 2안

| 안 | 구성 | 배선 변경 | 비고 |
|---|---|---|---|
| **A** | COMP7: INP = PB14(OUTN), INM = **내부 DAC** = AMC3301 출력 공통모드(약 1.44 V) | 없음 | 공통모드 편차가 위상 오차가 된다 → ADC로 (OUTP+OUTN)/2를 주기 측정해 DAC를 보정 |
| **B (권장)** | COMP7: INP = PB14(OUTN), INM = **PD15**(pin 77, COMP7_INM ✔) ← OUTP를 저항 1개로 추가 연결 | 저항 1개 추가 | **진짜 차동 비교** — 공통모드 오차 없음. PD15는 지금 `NC` 넷(0절) → 고치면 비는 핀 |

**위상 정확도 비교 (계산)**:
- AMC3301 차동 출력 = 152.4 mV pk × 8.2 = **1.25 V pk**, 영점 기울기 1.25 × 2π × 60 = **471 V/s**.
- 내장 COMP 히스테리시스를 10 mV로 두면 지연 **21 µs = 0.46°** (히스테리시스 설정값은 **RM0440 확인 필요**).
- 현재 U12 회로는 히스테리시스 0.30 V / 신호 1.0 V → **약 800 µs = 17°**(KS C 8560 검토서 3-3).
- AMC3301 대역 290 kHz → 지연 수 µs 수준, 60 Hz 위상에 무시 가능.

COMP7 출력을 **HRTIM 외부 이벤트(EEV)로 내부 연결**하면 핀도 필요 없다(COMP7 → EEV 내부 경로는 **RM0440 확인 필요**). 내부 경로가 없으면 COMP7_OUT 핀(PC8 pin 87 / PA8 pin 89)을 EEV 핀으로 되돌리면 된다.
