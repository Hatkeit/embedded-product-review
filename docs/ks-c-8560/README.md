> 작성 목적: 리비전 설계 변경사항 도출 + 인증 필수사항 적용

## 0. 이 문서를 읽기 전에 — 검증 상태 표기 규칙

KS C 8560은 **유료 표준**이며, 본 문서 작성 환경에서 표준 원문·한전·에너지공단 사이트
(`kssn.net`, `standard.go.kr`, `knrec.or.kr`, `kepco.co.kr`)에 **직접 접속이 차단**되어
조항 텍스트를 확보하지 못했습니다. 따라서 모든 항목에 검증 상태를 표기합니다.

| 표기 | 의미 | 취급 방법 |
|---|---|---|
| ✅ | 공개 출처로 확인된 사실 | 그대로 사용 가능 |
| ⚠️ | KS C 8564/8565 인버터 계열 공통 구조 및 분산형전원 연계기술기준에서 업계 통용되는 값 | **표준 원문 구매 후 반드시 대조** |
| ❓ | 미확인 — 원문 또는 인증기관 확인 필요 | 확인 전 설계 반영 금지 |

**⚠️ 및 ❓ 항목의 수치를 설계 스펙으로 확정하기 전에 §8 체크리스트를 먼저 수행하십시오.**

## 2. 🚨 최우선 확인사항 — 표준 유효성 및 통폐합 여부

**리비전 착수 전 가장 먼저 해결해야 할 항목입니다.** 잘못된 표준을 타깃으로 설계하면
리비전 전체가 무효가 됩니다.

### 2.1 확인된 정황 ✅

- KS C 8565의 표준명이 **"중대형 태양광 발전용 인버터"** → **"태양광 발전용 인버터
  (계통연계형, 독립형)"** 로 변경되었고, **2023-08-14 개정판**이 존재합니다.
  ("중대형" 한정어가 삭제됨 = 적용 범위 확대 시사)
- KSSN 검색 시 KS C 8565에 대해 **서로 다른 itemNo의 구·신 항목이 동시에 노출**됩니다.
- 한전 계통연계 신청 시 제출하는 시험성적서 기준으로 **KS C 8564:2021 / KS C 8565:2021**
  이 명시적으로 언급되는 반면, **KS C 8560은 언급되지 않습니다.**

### 2.2 그래서 확인해야 할 것 ❓

1. **KS C 8560:2016이 현재도 "유효" 상태인가, 아니면 폐지(廢止)되었는가?**
   - e나라표준인증에서 KS C 8560의 **표준 상태(유효/폐지/개정)** 와 **최종 개정 이력** 조회
2. **폐지되었다면 KS C 8565:2023으로 통합되었는가?**
   - 통합되었다면 V1200의 인증 타깃 표준은 **KS C 8565:2023**이며, 본 문서의 시험 항목
     체계는 8565 기준으로 재작성해야 합니다.
3. ~~한국에너지공단 신재생에너지센터의 KS인증 대상 품목에 "마이크로인버터"가
   독립 품목으로 등재되어 있는가?~~ → **해소됨 ✅**
   - 마이크로인버터 **KS인증심사기준의 제품시험 결함구분표(31항목)가 확보**되어,
     마이크로인버터가 KS인증 대상 품목임이 확인되었습니다.
     → [`시험항목-결함구분.md`](./시험항목-결함구분.md)
   - **다만 그 심사기준이 근거하는 표준이 KS C 8560인지 KS C 8565:2023인지는
     여전히 미확인**이므로 위 1·2번은 유효합니다.

> **조치:** 한국에너지공단 신재생에너지센터(1855-3020) 및 시험기관(KTC/KTL/KCL)에
> **서면으로 질의**하고 회신을 근거 문서로 보관하십시오. 구두 확인은 인증 심사에서
> 근거로 인정되지 않습니다.

## 4. 시험 항목 체계 — ✅ **확정됨 (별도 문서)**

> **이 절은 [`시험항목-결함구분.md`](./시험항목-결함구분.md) 로 대체되었습니다.**
>
> 초판의 §4는 KS C 8564/8565 계열로부터 **추정**한 목록이었습니다. 이후
> **KS인증심사기준의 「아. 제품시험 결과에 따른 결함 구분」 원문 표(31항목)** 가
> 확보되어, 추정 목록을 폐기하고 1차 자료로 교체했습니다.

### 4.1 확정된 31개 제품시험 항목 요약

| 결함구분 | 개수 | 항목 번호 |
|---|---:|---|
| 경결함 | 1 | 1 (구조) |
| 중결함 | 15 | 7, 9, 10, 11, 13, 16, 19~27 |
| **치명결함** | **15** | 2~6, 8, 12, 14, 15, 17, 18, 28~31 |

**치명결함 15항목:** 절연저항 · 내전압 · 감전보호 · 절연거리 · 출력 과전압/부족전압 보호 ·
단독운전 방지 · 누설전류 · **효율** · **대기 손실** · **최대 전력 추종** ·
출력전류 직류분 검출 · 습도 · 온습도 사이클 · EMI · EMS

### 4.2 초판 §4의 오류 (정정 기록)

추정 목록에 있었으나 **실제 표에는 없는** 항목:

- 역률 시험 — 독립 시험항목으로 존재하지 않음
- IP 등급 / 염수분무 / UV / 진동·충격 — 환경시험은 **습도·온습도 사이클 2종뿐**
- 직류 지락 검출 — 독립 항목 아님

추정 목록에서 **누락했던** 항목:

- **감전 보호 시험**(4, 치명) · **계통전압 위상 급변 시험**(21) ·
  **부하차단 시험**(24) · **부하 불평형 시험**(27)

### 4.3 가장 중요한 시사점

**효율(14) · 대기 손실(15) · 최대 전력 추종(17) 이 치명결함**입니다.
순수 성능 항목이 안전 항목과 동급으로 처리되므로, **원가절감형 리비전은
이 세 항목의 실측 마진을 먼저 확인한 뒤** 절감 범위를 정해야 합니다.

또한 이 표에 **LVRT/FRT 시험 항목이 없습니다.** §5.3의 한전 요구 LVRT 시험성적서는
KS인증 제품시험과 **별개 취득 대상**일 가능성이 높습니다.

## 5. 계통연계 요구사항 — 리비전 최대 영향 영역

KS 표준 시험 항목과 별개로, **한전 계통연계 승인**을 받으려면
「분산형전원 배전계통 연계 기술기준」을 만족해야 합니다.
**이 영역이 V1200 리비전에서 가장 크게 바뀌어야 할 부분입니다.**

### 5.1 비정상 전압 / 주파수 분리 시간 ⚠️

전압 (기준전압 대비 %):

| 전압 범위 | 분리 시간 |
|---|---|
| V < 50 % | 0.5 초 |
| 50 % ≤ V < 88 % | 2.0 초 |
| 110 % < V < 120 % | 1.0 초 |
| V ≥ 120 % | 0.16 초 |

주파수 (60 Hz 계통):

| 조건 | 분리 시간 |
|---|---|
| f > 60.5 Hz | 0.16 초 |
| f < 59.3 Hz (기준 −0.7 Hz) | 0.16 초 |

기타:
- **직류 주입**: 최대 정격 출력전류의 **0.5 %** 초과 금지
- **역률**: 90 % 이상 유지 원칙 ⚠️
- **단독운전**: 발생 후 **0.5초 이내** 계통 가압 중지 ⚠️
- **재연계**: 계통 전압·주파수 정상 복구 후 **5분(300초) 이상** 지연 후 재연계 ⚠️

### 5.2 🔥 저주파수 설정치 변경 — **V1200 펌웨어 필수 수정 항목** ✅

한전이 **「태양광인버터 저주파수 설정치 변경 안내」**를 통해 공지한 사항으로,
**계통 저주파수 시 태양광 발전소가 불필요하게 일괄 탈락하는 것을 방지**하기 위함입니다.

| 구분 | 설정값 |
|---|---|
| **기존** KS 규격 / 연계기술기준 | **59.3 Hz** (기준 −0.7 Hz) |
| **한전 권고** | **57.5 Hz 미만**으로 변경 (기준 −2.5 Hz) |
| **2024 개정 연계 가이드라인** | 기존 *59.8 Hz / 0.16초 분리* → **57.0 Hz / 299초 이후 분리** |

> **성격:** 현재 **의무가 아닌 권고**로 안내되고 있습니다. 다만 2024 개정 가이드라인에서
> 값이 강제 형태로 기술된 정황이 있으므로, **현재 시점의 의무/권고 여부를 한전에 재확인**
> 하십시오. ❓

**V1200 적용 시사점:**
1. UFR 정정치와 분리시간이 **펌웨어에서 파라미터로 변경 가능한 구조**여야 합니다.
   현재 V1200이 **하드코딩**되어 있다면 이번 리비전의 **최우선 수정 항목**입니다.
2. 299초급 지연은 기존 0.16초 설계 대비 **타이머 폭이 1800배 이상** 차이납니다.
   타이머 변수 폭, 워치독, 카운터 오버플로 검토가 필요합니다.
3. 필드에 이미 설치된 유닛까지 고려하면 **현장 펌웨어 업데이트(FOTA/게이트웨이 경유)**
   경로가 반드시 있어야 합니다.
4. 설정 프로파일을 **국가/계통 코드별로 분리**하여 관리하는 구조를 권장합니다.

### 5.3 FRT (계통 지속운전 기능) — LVRT / HVRT ✅

| 항목 | 내용 |
|---|---|
| LVRT | 한전 계통연계 신청 시 **지속운전기능 확인 시험성적서 제출 의무** |
| 시험 규격 | 태양광: **KS C 8564:2021 / KS C 8565:2021** 기준 시험성적서 |
| 시험 절차 표준 | **KS C IEC TS 62910** — 계통연계형 태양광발전 인버터 저전압 계통연계 유지 시험절차 |
| HVRT | **500 kW 이상** 설비 대상 인버터 성능개선(HVRT) **의무화** 진행 중 |
| 제원 조사 | 500 kW 이상 전국 태양광 인버터 대상 지속운전기능 적용 여부 및 제원 조사 시행 |

**V1200 적용 시사점:**
- 마이크로인버터는 **단일기 용량은 작지만 어레이 합산 용량이 500 kW를 넘는 현장**이
  존재합니다. 이 경우 HVRT 의무 대상에 포함될 수 있으므로 ❓ **용량 산정 기준
  (단일기 기준인가, 발전소 연계 용량 기준인가)** 을 한전에 확인해야 합니다.
- V1200이 **LVRT/HVRT 미지원**이라면 이번 리비전에서 **제어 알고리즘 추가가 필수**입니다.
  계통 전압 급감 시 과전류로 정지하지 않고 연계를 유지해야 합니다.
- 시험성적서 확보 계획을 리비전 일정에 **선행 반영**하십시오(시험기관 대기기간 존재).

| **KC 전자파적합성** | 전파법 | 중앙전파관리소 | **필수** |
| **KC 무선(적합성평가)** | 전파법 | 중앙전파관리소 | 무선 통신 탑재 시 **필수** |
| **한전 계통연계 승인** | 송·배전용 전기설비 이용규정 | 한국전력공사 | **필수** |

### 7.2 신재생에너지설비 KS인증 구성 ✅

KS인증은 **제품심사 + 공장심사** 두 축으로 구성되며, 제품 성능만으로는 취득할 수 없습니다.

**① 제품심사 (공인시험)**
- 시험기관: **KTC**(한국기계전기전자시험연구원), **KTL**, **KCL**, **KTR** 등
- 해당 KS 표준 전 시험 항목 수행 → 시험성적서

**② 공장심사**
- 평가 대상: **제조설비 · 검사설비 · 검사방법 · 품질관리방법**
- "KS 수준 이상의 제품을 **지속적·안정적으로 생산할 수 있는 능력**" 평가
- 최초 공장심사 + **3년 주기 정기심사**

> ⚠️ **리비전 시 주의:** 공장심사는 제품이 아니라 **생산 체계**를 봅니다.
> V1200 리비전으로 **검사설비나 검사방법이 바뀌면 공장심사 항목도 갱신**해야 합니다.
> 특히 신규 시험 항목(FRT 등)이 추가되면 **사내 검사설비 보유 요건**이 늘어날 수 있습니다.

### 7.3 리비전 시 인증 유지 판단 ❓

**가장 중요한 실무 판단입니다.** 리비전 범위에 따라 다음이 갈립니다.

| 리비전 범위 | 통상 처리 | 확인처 |
|---|---|---|
| 펌웨어 파라미터 변경 (UFR 설정치 등) | 부분 시험 / 변경 신고 | 인증기관 |
| 제어 알고리즘 추가 (FRT 등) | **관련 항목 재시험** | 인증기관 |
| 전력단 회로·부품 변경 | **광범위 재시험** | 인증기관 |
| 정격 변경 | **신규 인증** | 인증기관 |

> **조치:** 리비전 **설계 확정 전에** 인증기관에 변경 범위를 제시하고
> **재시험 범위를 서면으로 확답** 받으십시오. 설계 후 문의하면 재설계 위험이 있습니다.
