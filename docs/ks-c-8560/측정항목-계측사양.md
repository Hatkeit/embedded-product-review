## 0. 이 문서가 채운 것과 비우고 둔 것

"측정치"는 세 가지로 나뉘며, 현재 확보 상태가 다릅니다.

| 구분 | 내용 | 상태 |
|---|---|:---:|
| **① 측정량·조건·계측사양** | 무엇을 어떤 조건에서 어떤 장비로 재는가 | ✅ **이 문서가 채움** |
| **② 규격 기준값(판정치)** | 합격 한계값 | ⛔ **심사기준 본문 필요** |
| **③ V1200 실측값** | 실제 측정 결과 | ⛔ **시험성적서 필요** |

②는 **심사기준 본문(시험조건·판정기준)** 이 있어야 채울 수 있습니다. 공개 출처로
근거를 댈 수 있는 값만 ⚠️ 표기로 **참고값** 칸에 넣었고, **판정 기준값으로 쓰지
마십시오.** 나머지는 빈칸으로 두었습니다 — 추정치로 채우면 설계 스펙이 오염됩니다.

③은 시험성적서를 주시면 대장에 입력해 마진 분석까지 진행하겠습니다.

> 💡 이 대장은 **공장심사 대비 자료로도 쓰입니다.** KS인증 공장심사는 제품이 아니라
> **검사설비·검사방법·품질관리방법**을 평가하므로, 항목별 계측 사양과 기록 양식이
> 정비되어 있는 것 자체가 심사 근거가 됩니다.

## 1. 측정 불확도가 판정을 좌우하는 4개 항목 ⚠️

대부분의 항목은 계측기 정확도가 문제되지 않지만, **아래 4개는 계측기 성능이
합불을 직접 뒤집습니다.** 리비전 전에 보유 장비 사양부터 확인하십시오.

| # | 항목 | 왜 문제인가 | 요구 계측 사양 |
|---|---|---|---|
| **14** | 효율 **(치명)** | 0.1 %p 차이로 합불이 갈리는데, 일반 전력계 확도로는 그 차이를 분해 못 함 | 전력분석기 **기본확도 0.05 % 급 이상** 권장, DC·AC 동시 측정 |
| **17** | 최대 전력 추종 **(치명)** | 기준이 되는 "이용 가능한 최대전력"을 시뮬레이터가 정확히 재현해야 함 | **PV 시뮬레이터** — I-V 곡선 재현 + **동적 프로파일 지원 필수** |
| **18** | 출력전류 직류분 **(치명)** | 한계가 정격의 0.5 %(예: 5 A 기준 **25 mA**). 계측기 오프셋이 이 수준이면 측정 무의미 | DC 응답 전류 프로브/분류기, **오프셋 교정 이력 필수** |
| **11** | 교류출력전류 변형률 | 계통전압이 이미 왜곡돼 있으면 인버터 THD를 분리 측정 불가 | **저왜율 기준 AC 소스** (계통 직결 측정 금지) |

> 🔴 **14·17·18은 전부 치명결함**입니다. 장비가 부족하면 사내 사전검증이 불가능해
> 공인시험에서 처음 알게 됩니다. 재시험 비용과 일정 손실이 큽니다.

## 2. 항목별 측정치 정의

각 항목의 **측정량 / 단위 / 측정 조건 / 계측 장비 / 참고값**입니다.
참고값 ⚠️는 「분산형전원 배전계통 연계 기술기준」 등 공개 출처 기반이며,
**심사기준의 판정치와 다를 수 있습니다.**

### 1. 구조 시험 (경결함)

| 구분 | 내용 |
|---|---|
| 측정량 | 외관 상태, 주요 치수, 질량, 표시사항 유무 |
| 단위 | mm, kg, 판정(양부) |
| 조건 | 도면·사양서 대조 |
| 계측 | 버니어캘리퍼스, 저울, 육안 |
| 참고값 | — |

> 표시사항 누락이 흔한 지적. 정격 라벨 기재 항목을 사전 목록화하십시오.

### 2. 절연저항 시험 **(치명)**

| 구분 | 내용 |
|---|---|
| 측정량 | 절연저항 |
| 단위 | **MΩ** |
| 측정 개소 | ① PV(DC)측–외함/대지 ② 계통(AC)측–외함/대지 ③ PV측–계통측 |
| 조건 | 인가전압 **DC 500 V** ⚠️ (정격에 따라 1000 V), 인가 시간 규정값 |
| 계측 | 절연저항계(메거) |
| 참고값 | ⚠️ **1 MΩ 이상** (업계 통용) |

> ⚠️ 측정 전 **서지소자(MOV)·Y캡 분리 여부**를 시험 절차에 명시하십시오.
> 분리 여부에 따라 값이 크게 달라져 재현성 분쟁이 생깁니다.

### 3. 내전압 시험 **(치명)**

| 구분 | 내용 |

| 단위 | 판정(양부), mA |
| 측정 개소 | 2번과 동일 |
| 조건 | 규정 AC 전압 **1분간** ⚠️. DC 대체 시 전압 환산 |
| 계측 | 내전압시험기(Hi-pot) — **차단전류 설정값 기록 필수** |
| 참고값 | ⛔ 시험전압은 절연 등급·정격에 따라 산출 (62109-1) |

### 4. 감전 보호 시험 **(치명)**

| 구분 | 내용 |
|---|---|
| 측정량 | ① 접촉전류 ② 보호도체전류 ③ 접지 연속성 저항 ④ **차단 후 잔류전압·방전시간** |
| 단위 | mA, mΩ, V, s |
| 조건 | 정격 운전, 최악 전압 조건 |
| 계측 | **IEC 60990 측정망**, 접지연속성시험기, 오실로스코프(잔류전압 파형) |
| 참고값 | ⛔ 심사기준 확인 |

### 5. 절연거리 시험 **(치명)**

| 구분 | 내용 |
|---|---|
| 측정량 | **공간거리(clearance)**, **연면거리(creepage)** |
| 단위 | **mm** |
| 측정 개소 | 절연 배리어별 (PV–AC, 전력–제어, 충전부–외함) |
| 조건 | **최악 조건** — 부품 공차·조립 편차 누적 |
| 계측 | 측정현미경, 게이지, 3D 측정기 |

> 이 항목은 측정 전에 **절연 협조 계산서**가 있어야 합니다. 계산서 없이 실측만
> 하면 "얼마여야 하는가"를 알 수 없습니다.

### 6. 출력 과전압 및 부족전압 보호 **(치명)**

| 구분 | 내용 |
|---|---|

### 14. 효율 시험 **(치명)** — 🔴 최중요

| 구분 | 내용 |
|---|---|
| 측정량 | **변환효율 η = P_AC / P_DC**, 가중효율 |
| 단위 | **%** |
| 조건 | **IEC 61683 / EN 50530** — 입력전압 레벨(V_mpp min/nom/max) × 출력 레벨 |
| 출력 레벨 | 통상 5, 10, 20, 30, 50, 75, 100 % |
| 계측 | **고정밀 전력분석기**(DC·AC 동시), PV 시뮬레이터 |
| 참고값 | ⛔ 심사기준 확인 (정격효율? 가중효율? 가중식?) ❓ |

**가중효율 계산식 ⚠️** (어느 식을 쓰는지 확인 필요)

```
EU  η = 0.03·η5% + 0.06·η10% + 0.13·η20% + 0.10·η30% + 0.48·η50% + 0.20·η100%
CEC η =            0.04·η10% + 0.05·η20% + 0.12·η30% + 0.21·η50% + 0.53·η75% + 0.05·η100%
```

> 두 식 모두 계수 합 = 1.00. **EU는 50 % 부하에, CEC는 75 % 부하에 가중치가 집중**됩니다.
> 어느 식이냐에 따라 **최적화할 부하 구간이 달라지므로** 설계 전에 확정해야 합니다.

## 3. 측정 대장 운용 규칙

### 3.1 마진 관리

사내 검사에서는 **규격 한계에 붙여 통과시키면 안 됩니다.** 공인시험 장비·환경이
다르면 값이 이동하기 때문입니다.

| 항목 유형 | 권장 사내 관리 마진 |
|---|---|
| 치명결함 + 측정 불확도 큰 항목 (14·17·18) | 규격 대비 **충분한 여유** 확보 후 양산 판정 |
| 치명결함 일반 (2·3·5·12·28·29·30·31) | 규격 대비 여유 확보 |
| 중결함 | 규격 내 관리 |

> 구체적 마진 %는 **규격 한계값이 확정된 뒤** 측정 불확도를 반영해 산정하십시오.
> 지금은 한계값이 없어 수치를 제시할 수 없습니다.

### 3.2 기록 필수 항목

각 측정 기록에 다음을 함께 남기십시오. 빠지면 **재현성 분쟁**이 생깁니다.

- 시험일시, 시험자, **시료 시리얼·리비전 번호**
- **주위온도·습도**
- 사용 계측기 **모델·시리얼·교정유효일**
- 시험 조건 설정값 (입력전압, 출력레벨, 부하 조건 등)
- **펌웨어 버전** ← 보호 정정치가 파라미터화되면 필수
- 특이사항

> **펌웨어 버전 기록은 특히 중요합니다.** 저주파수 설정치 변경처럼 파라미터가
> 바뀌는 리비전에서는 "어느 펌웨어로 측정한 값인지"가 성적서의 유효성을 좌우합니다.

### 3.3 리비전 전후 비교

리비전 시에는 **동일 조건에서 전후 값을 나란히** 기록하십시오.
변경의 영향을 정량화해야 재시험 범위를 인증기관과 협의할 근거가 됩니다.
