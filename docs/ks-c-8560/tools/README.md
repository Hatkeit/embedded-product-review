# ks8560_pcb_check — 절연거리 사전 검증 도구

KS C 8560:2020 **8.3.4 절연거리(치명결함)** 를 공인시험 전에 설계 데이터로 점검한다.
V2000 검토([`../V2000_KS-C-8560_적합성검토.md`](../V2000_KS-C-8560_적합성검토.md))에 쓴 분석을 그대로 재현한다.

## 실행

```bash
pip install shapely
python3 ks8560_pcb_check.py \
    --pcb  PCB_MicroInv_V2000_xxxx.xml \   # Allegro → File > Export > IPC-2581 (rev B)
    --net  pstxnet.dat \                   # Capture 넷리스트 (allegro 폴더)
    --out  report.md
```

V2000 데이터 기준 약 8초.

## 하는 일

1. **절연 도메인 분리** — 넷리스트를 union-find로 병합. 광커플러·AMC330x·전력변압기·릴레이(코일/접점)·
   콘덴서·100 kΩ 이상 저항은 병합하지 않고 "교락 부품"으로 기록
2. **PCB 형상 복원** — 패드·트레이스·동박(컷아웃 포함)을 넷별 다각형으로 변환
3. **도메인 간 최소거리** — 외층은 공간·연면거리, 내층은 참고값으로 출력
4. **절연 부품 풋프린트 간격**, **장벽 교락 부품 목록**, **회로도↔PCB 넷 불일치**

## 판정 기준 (CONFIG `checks`)

| 검사 | OVC III | OVC II | 근거 |
|---|---:|---:|---|
| 강화절연 LV(PV/제어) ↔ HV(계통/고압) | 5.5 mm | 3.0 mm | 표 3·4, 인용표준 강화 환산 |
| 기초절연 HV ↔ PE | 3.0 mm | 1.5 mm | 표 3·4 |
| 기초절연 LV ↔ PE | 0.2 mm (71 Vdc) | | 표 3·4 |

OVC·오염등급이 시험기관과 확정되면 값을 바꿔 쓴다.

## 설계가 바뀌면 먼저 확인할 것

- `anchors` — 도메인 기준 넷 이름 (`PV_A+`, `GND`, `AC_L`, `PGND`, `GND_EARTH` …)
- `iso_cells` — 절연 부품 셀 이름과 핀 그룹. **새 절연 부품을 쓰면 반드시 추가** (누락 시 두 도메인이 합쳐져 위반을 못 잡음)
- `hv_like` — 계통 전위에 준하는 노드 (`I_GRID_LK`)
- `iso_refs` — 풋프린트 간격을 볼 부품

## 한계

- 솔더마스크·코팅은 절연으로 보지 않는다(60664-1). 부품 몸체 높이·실장 후 형상은 반영하지 않는다.
- 공간거리를 층 평면 거리로 근사한다(외층 동박 두께 무시). 슬롯은 연면거리만 늘린다.
- 내층 판정은 적층 두께·재질 정보가 있어야 확정된다.
- **공인시험을 대체하지 않는다.**
