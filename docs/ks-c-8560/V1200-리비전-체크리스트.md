## ⛔ 0. 이 체크리스트의 한계

본 저장소(`embedded-product-review`)에는 **V1200 관련 자료가 전혀 없습니다**
(현재 `index.html` 랜딩 페이지 1개뿐). 따라서 아래 항목은 **마이크로인버터 일반 및
KS C 8560/8565 요구사항으로부터 도출한 것**이며, **"V1200의 현재 설계가 무엇을
만족하고 무엇을 못 만족하는지"는 판정하지 못했습니다.**

실제 리비전 항목을 확정하려면 §1의 입력 자료가 필요합니다.

## 1. 판정에 필요한 입력 자료 (요청)

| # | 자료 | 용도 |

| 3 | **펌웨어 소스** 또는 최소한 보호계전 로직 (OVR/UVR/OFR/UFR 정정치, 타이머, 단독운전 방지 알고리즘) | §3 FW 항목 판정 |
| 4 | **회로도 / BOM** (전력단 토폴로지, 절연 방식, 계통 릴레이, 커패시터 종류) | §2 HW 항목 판정 |

## 2. 하드웨어 (전력단 / 회로)

- [ ] **절연 구성** — KS C IEC 62109-1/-2 절연협조 적합성 재확인 (연면·공간거리)
- [ ] **계통 분리 수단** — 보호 동작 시 물리적 분리(릴레이) 요구 여부 확인 ❓
- [ ] **직류분 억제 회로** — 정격 교류출력전류 0.5 % 이하 만족 여부 ⚠️
- [ ] **출력 필터** — THD 종합 5 % / 차수별 3 % 여유 확보 ⚠️
- [ ] **LVRT 대응 전력단** — 계통 전압 급감 시 과전류 없이 연계 유지 가능한
      전류 제한 / DC링크 설계 (**§5.3 필수 항목**)
- [ ] **HVRT 대응** — 과전압 구간 소자 내압 여유 확인
- [ ] **서지 보호** — KS C 9610-4-5 서지 내성 레벨 대응
- [ ] **접지 및 지락 검출** — 직류 지락 검출 회로
- [ ] **전해 커패시터 제거/대체 검토** — 모듈 후면 고온에서 25년 수명 확보
- [ ] **부품 디레이팅 재검토** — 모듈 후면 주위온도 기준 (일반 인버터보다 가혹)
- [ ] **AC 트렁크 케이블·커넥터** — 정격 전류, IP 등급, 인증 부품 사용 여부

## 3. 펌웨어 / 제어 — **리비전 최우선 영역**

### 3.1 🔥 보호계전 파라미터화 (최우선)

- [ ] **UFR(저주파수) 정정치·분리시간이 런타임 파라미터인가?** 하드코딩이면 즉시 개선
- [ ] 저주파수 설정 **59.3 Hz → 57.5 Hz 미만** 변경 가능하도록 반영 ✅근거
- [ ] **299초급 장시간 지연** 지원 — 타이머 변수 폭·오버플로·워치독 상호작용 검토
- [ ] OVR / UVR / OFR **전 보호요소** 동일하게 파라미터화
- [ ] 파라미터 **범위 제한 및 무결성 검증**(CRC 등) — 임의 값 주입 방지
- [ ] **국가/계통 코드별 프로파일** 분리 관리 구조 도입
- [ ] 파라미터 변경 **이력 로깅** (인증 심사·현장 분쟁 대비)

### 3.2 계통 보호 로직

- [ ] 비정상 전압 분리시간 표 준수 (V<50 %: 0.5 s / 50~88 %: 2.0 s / 110~120 %: 1.0 s / ≥120 %: 0.16 s) ⚠️
- [ ] **단독운전 방지 — 수동적 + 능동적 방식 각각 구비** ⚠️
- [ ] **단독운전 0.5초 이내 가압 중지** ⚠️
- [ ] ⚠️ **다수 병렬 연계 시 능동식 상호 간섭 검증** — 마이크로인버터 고유 리스크.
      수십~수백 대가 동일 계통에 연결될 때 능동 신호가 상쇄되어 검출 실패할 수 있음.
      **KS C IEC 62116 시험 조건에 다수기 병렬 조건이 포함되는지 확인** ❓
- [ ] **재연계 지연 5분(300초) 이상** ⚠️
- [ ] 계통 이상 시 **게이트 블록** 동작

### 3.3 FRT (지속운전)

- [ ] **LVRT 구현** — KS C IEC TS 62910 시험절차 기준
- [ ] **HVRT 구현** — 500 kW 이상 현장 대응 (용량 산정 기준 확인 필요 ❓)
- [ ] FRT 중 **무효전력 주입** 요구 여부 확인 ❓
- [ ] FRT 복귀 후 **출력 램프업** 프로파일

### 3.4 성능

- [ ] **MPPT 알고리즘** — 정적/동적 효율 (KS C IEC 62891)
- [ ] **변환효율** — 정격 / 가중효율 목표 대비 검증
- [ ] **대기·야간 소비전력** 저감
- [ ] **역률 제어** — 0.95 이상, 진상/지상 제어 가능 여부 ⚠️
- [ ] **출력 제한(curtailment) 지령 추종** 정확도

### 3.5 업데이트 경로

- [ ] **필드 펌웨어 업데이트(FOTA / 게이트웨이 경유)** 경로 확보
      — 설정치 규제 변경에 대응하려면 필수
- [ ] 업데이트 **롤백 및 실패 복구** 전략
- [ ] 업데이트 **서명 검증**

## 8. 진행 순서 권고

```
1주차   §2 표준 유효성 확정  ←── 반드시 선행 (타깃 표준이 바뀌면 전부 재작업)
        + 인증기관 재시험 범위 질의 발송
        + 시험기관 슬롯 문의

2~3주차 V1200 현행 설계 vs 요구사항 GAP 분석 (§1 자료 확보 후)
        → 실제 수정 항목 확정

이후    FW: 보호계전 파라미터화 → FRT 구현 → 검증
        HW: GAP 분석 결과에 따른 변경
        문서/라벨 갱신

마지막  공인시험 → 공장심사 → 인증
```

> **핵심:** §2(표준 유효성)와 §7(재시험 범위 확답)이 **설계보다 먼저** 끝나야 합니다.
> 순서를 뒤집으면 리비전 후 재설계 위험이 큽니다.
