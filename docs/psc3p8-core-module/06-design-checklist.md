# 06. 설계 검토 체크리스트 및 브링업 절차

## 6.1 회로도 입력 전 (Gate 0)

- [ ] [07-open-items.md](07-open-items.md) 의 **P0 (블로커) 항목이 전부 닫혔는가**
- [ ] PSC3P8 데이터시트 정식 버전 확보 (Infineon 계정 / 대리점)
- [ ] 패키지 확정 및 KiCad/Altium 심볼·풋프린트 확보 또는 작성
- [ ] 대리점을 통한 샘플 수급 일정, MOQ, 정식 양산 OPN 확인
- [ ] ModusToolbox™ 가 해당 디바이스를 지원하는지 확인 (BSP 생성 가능 여부)

## 6.2 회로도 검토 (Gate 1)

### 전원

- [ ] 모든 VDDD / VDDIO 핀에 100 nF 가 **핀 수만큼** 배정되었는가
- [ ] VDDA 가 FB1 이후 다른 부하와 공유되지 않는가
- [ ] **VCCD 에 외부 전원이 연결되어 있지 않은가** (내부 레귤레이터 출력)
- [ ] VCCD 커패시터 값·ESR 이 데이터시트 지정값과 일치하는가
- [ ] VBACKUP 이 미사용 시에도 부유(floating)하지 않는가 (JP1 기본 단락)
- [ ] LDO 입출력 커패시터가 선정 부품의 안정성 조건(ESR/용량)을 만족하는가
- [ ] +5 V 입력 경로에 역전압 보호와 TVS 가 모두 있는가
- [ ] 전원 인가 순서 요구사항(VDDD/VDDA 순서 제약) 확인 — ※ 데이터시트

### 리셋 / 디버그

- [ ] XRES 풀업 저항 존재, 커패시터 ≤ 100 nF
- [ ] XRES 가 헤더로 인출되어 있고 오픈드레인 구동 전제가 문서화되었는가
- [ ] J4 가 Arm Cortex Debug 10핀 표준 배열과 일치하는가 (7번 KEY)
- [ ] VTREF 가 +3V3 에서 나오는가 (5 V 아님)
- [ ] 디버그 포트 잠금(보안) 후 복구 절차가 존재하는가

### 클럭

- [ ] X1 주파수가 ECO 허용 범위 안인가
- [ ] 부하 커패시터 값이 `C = 2×(CL − Cstray)` 로 산출되었는가
- [ ] 크리스털 드라이브 레벨이 정격 이내인가 (R10 필요 여부)
- [ ] 크리스털 미실장(IMO 전용) 구성에서도 부팅되는가

### I/O

- [ ] **GPIO 60 개가 전부 헤더로 인출되었는가** (누락 0)
- [ ] 온보드 기능(LED)이 점퍼로 완전히 분리 가능한가
- [ ] 5 V 톨러런트가 아닌 핀에 5 V 가 인가될 경로가 없는가
- [ ] 부트 시 하이임피던스 상태에서 캐리어 보드에 위험한 조합이 없는가 (특히 HRPWM → 게이트 드라이버)
- [ ] TRIP/FAULT 핀이 하드웨어 PWM 셧다운 경로에 연결 가능한 핀인가

## 6.3 레이아웃 검토 (Gate 2)

- [ ] VCCD 커패시터가 해당 핀 최근접에 있는가
- [ ] 디커플링 커패시터 → 전원 핀 루프 면적이 최소인가
- [ ] X1 배선 ≤ 5 mm, 하단 GND 연속, 가드링 + 스티치 비아
- [ ] L2 GND 플레인에 **분할이 없는가**
- [ ] AGND–GND 접속이 R14 **한 곳뿐인가** (두 곳 이상이면 루프 발생)
- [ ] HRPWM 배선이 아날로그 영역을 통과하지 않는가
- [ ] 아날로그 입력이 클럭·PWM 과 3 mm 이상 이격되었는가
- [ ] U2 방열 카퍼 ≥ 200 mm², 서멀 비아 9개 이상
- [ ] 헤더 GND 핀마다 스티치 비아 2개 이상
- [ ] 헤더 바깥열 간 거리 = 45.72 mm (2.54 의 정수배) 실측 확인
- [ ] 장착 홀 주변 Ø 6 mm 카퍼/부품 키프아웃
- [ ] 하단면에 부품이 없는가 (헤더 테일만)
- [ ] 실크의 핀 이름이 [03-connector-pinout.md](03-connector-pinout.md) 와 100 % 일치하는가

## 6.4 제조 전 (Gate 3)

- [ ] DRC / ERC 무결
- [ ] 3D 뷰에서 J4 리본 케이블 간섭 확인
- [ ] 헤더 테일 길이 ≥ 3.0 mm — 캐리어 보드 소켓 삽입 깊이 확보
- [ ] 거버 / 드릴 / 픽앤플레이스 / BOM 출력 및 상호 대조
- [ ] DNP 부품이 조립 BOM 에서 제외되었는가
- [ ] 스텐실 개구부: U1 파인피치는 1:1, U2 방열패드는 60~70 % 로 축소

## 6.5 브링업 절차 (시제품 수령 후)

**전원을 넣기 전에 1~3 단계를 반드시 수행한다.**

| # | 단계 | 판정 기준 |
|---:|---|---|
| 1 | 육안 / X-ray 검사 | U1 브리지·미납 없음 |
| 2 | 무전원 저항 측정 | +5V–GND, +3V3–GND, VDDA–GND 모두 ≥ 10 kΩ. 수십 Ω 이하면 즉시 중단 |
| 3 | 전류 제한 전원으로 +5 V 인가 (100 mA 제한) | 소비 전류가 제한에 걸리지 않음 |
| 4 | 레일 측정 | +3V3 = 3.3 V ±2 %, VDDA = 3.3 V ±2 %, VCCD = 데이터시트 규정값 |
| 5 | 리플 측정 (20 MHz BW 제한, 스프링 그라운드) | +3V3 ≤ 30 mVpp, VDDA ≤ 10 mVpp |
| 6 | XRES 확인 | 정상 High, SW1 누름 시 Low |
| 7 | 디버거 연결 (J4) | IDCODE 인식, 코어 halt/run 가능 |
| 8 | 블링키 다운로드 | LED2 점멸 |
| 9 | 클럭 검증 | 클럭 출력 핀으로 CLK_HF 를 내보내 주파수 오차 ≤ 100 ppm 확인. 크리스털 파형은 **1:10 프로브 직접 접촉 금지**, 완충단 경유 |
| 10 | GPIO 전수 도통 시험 | 60 핀을 순차 토글하며 헤더에서 확인 (지그 또는 펌웨어 스캔) |
| 11 | ADC 기본 성능 | DC 입력에 대해 노이즈 프리 비트 수 측정. 목표 ≥ 10 bit |
| 12 | CAN FD 루프백 | 외부 트랜시버 연결 후 500 kbps / 2 Mbps, 1 Mbps / 5 Mbps 통신 확인 |
| 13 | 열 시험 | 500 mA 부하 인가 후 30분, U2 표면 온도 실측. 주위 85 °C 조건 환산 |
| 14 | 저온/고온 부팅 | -40 °C, +85 °C 각각에서 콜드 부팅 및 크리스털 기동 확인 |

### 브링업에서 특히 주의할 것

- **9번(크리스털 측정)**: 프로브 용량이 부하 커패시턴스를 바꿔 발진이 멈추거나
  주파수가 틀어진다. 크리스털 노드를 직접 찍지 말고 MCU 의 클럭 출력 기능을 쓴다.
- **11번(ADC)**: 12-bit ADC 에서 유효 비트가 10 bit 미만이면 레이아웃 문제다.
  VDDA 필터, AGND 접속, PWM 배선 이격을 순서대로 의심한다.
- **13번(열)**: 여기서 마진이 부족하면 Rev 0.2 에서 벅 컨버터 변형이 필요하다
  ([05-mechanical-layout.md §5.4](05-mechanical-layout.md) 참조).
