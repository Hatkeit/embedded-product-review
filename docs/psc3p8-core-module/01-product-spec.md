# 01. 제품 정의 및 사양

## 1.1 제품 개요

**PSC3P8-CM100** 은 Infineon PSOC™ Control C3 Performance Line MCU(PSC3P8)를 탑재한
2.54 mm 핀헤더 인출형 코어 모듈이다.

설계 의도는 다음과 같다.

1. **양산 회로의 "MCU 최소 동작 회로"를 모듈로 분리한다.**
   전원 레귤레이터, 발진자, 리셋, 디커플링, 디버그 인터페이스를 모듈이 책임지고,
   사용자는 캐리어 보드에서 애플리케이션 회로(게이트 드라이버, 전류 센싱, CAN 트랜시버 등)만 설계한다.
2. **PSC3P8 의 모든 GPIO 를 하나도 남기지 않고 인출한다.**
   코어 모듈 제품에서 "모듈에서 소모한 핀" 은 그대로 사용자의 설계 제약이 되므로,
   온보드 기능(LED 등)은 모두 점퍼로 분리 가능하게 한다.
3. **범용 2.54 mm 그리드에 얹힌다.**
   브레드보드, 만능기판, 일반 IDC 소켓과 호환되도록 핀 피치와 헤더 간 거리를 모두 2.54 mm 의 정수배로 둔다.

### 참조 제품과의 관계

싱크웍스의 `TMS320F28P650DK9 모듈`(TI C2000 계열, 산업용 최상위 등급)과 **같은 제품 형태**를 목표로 한다.
즉 "고성능 실시간 제어 MCU + 전 포트 2.54 mm 인출 + 온보드 전원/디버그" 구성이다.

차이는 탑재 MCU에서 온다.

| 구분 | 참조 제품 (TI C2000 F28P65x) | 본 모듈 (Infineon PSC3P8) |
|---|---|---|
| 코어 | C28x + CLA (TI 독자 아키텍처) | Arm Cortex-M33 (DSP + FPU) |
| 툴체인 | Code Composer Studio / C2000Ware | ModusToolbox™ / Arm 생태계, Zephyr 지원 |
| 강점 | EtherCAT, 대용량 Flash, C2000 레거시 자산 | Arm 표준 생태계, PQC 대응 보안 부트, HRPWM |
| 조달 | TI 단일 소스 | Infineon 단일 소스 |

> 참조 제품의 상세 사양(기판 치수, 헤더 배열, 가격)은 판매 사이트 접속이 차단되어 원문 확인을 하지 못했다.
> 위 표의 참조 제품 열은 TI 디바이스 계열 수준의 일반 정보이며, **제품 대 제품 비교로 인용하지 말 것**.

## 1.2 탑재 MCU 사양 (PSC3P8)

Infineon 제품 페이지 및 계열 기술 개요에서 확인된 값이다.
확정이 필요한 항목은 `※` 로 표시하고 [07-open-items.md](07-open-items.md)에 재수록했다.

### 코어 / 메모리

| 항목 | 값 |
|---|---|
| 코어 | Arm® Cortex®-M33, DSP 확장 + FPU |
| 최대 동작 주파수 | ※ Main Line 기준 180 MHz, C3M5 EVK BSP 기준 CLK_HF 최대 240 MHz — Performance Line 값 확정 필요 |
| Flash | 512 kB |
| SRAM | 128 kB |
| DMA | 16 채널 |
| 보안 | Secure Boot, 펌웨어 업데이트 검증 (SHA-512, LMS 기반 PQC 대응) |

### 아날로그 / 실시간 제어

| 항목 | 값 |
|---|---|
| ADC | 12-bit, 4 모듈, 아날로그 입력 24 라인, 최대 12 Msps 급 |
| ADC 특징 | 단일 코어 ADC로 최대 16 신호 동기 "idle" 샘플링, 샘플링 지터 없음 |
| 가속기 | CORDIC 수학 보조 프로세서 |
| 타이머/카운터/PWM | 26 블록 |
| HRPWM | 주기·듀티·데드타임 삽입, 대표 분해능 80 ps 미만 |
| 비교기 | 내장 (채널 수 ※ 확정 필요) |

### 통신 / 디버그

| 항목 | 값 |
|---|---|
| CAN | 2 채널, CAN FD 최대 8 Mbps |
| SCB | 6 모듈 (각각 UART / SPI / I²C 로 구성) |
| 디버그 | SWD / JTAG / Trace / Boundary scan |
| USB | ※ PSC3P8 탑재 여부 확정 필요 |

### 전기적 / 패키지

| 항목 | 값 |
|---|---|
| 동작 전압 | 1.71 V ~ 3.63 V |
| 동작 온도 | -40 °C ~ +115 °C |
| I/O 핀 수 | 60 |
| 패키지 | 최대 100 핀 옵션 존재 — ※ 정확한 패키지(LQFP-100 등)와 핀아웃 확정 필요 |
| 대표 OPN | `PSC3P8GFS3PAHQ1` — ※ `Q1` 접미사의 AEC-Q100 인증 여부 확인 필요 |
| 양산 시점 | Performance Line 2025년 말 샘플, 2026년 양산 |

> **조달 리스크**: Performance Line 은 신규 양산 계열이다. 설계 착수 전 대리점을 통해
> 샘플 수급 일정, MOQ, 정식 양산 OPN 을 반드시 확정할 것.

## 1.3 모듈 전기적 사양

| 항목 | 값 | 비고 |
|---|---|---|
| 입력 전원 | +5 V ±5 %, 최대 800 mA | J3(Molex) 또는 J1.1/J1.2 |
| 입력 보호 | 역전압 보호 + TVS | Q1(P-ch MOSFET) + D1 |
| 온보드 3.3 V | 500 mA LDO | 모듈 자체 소비 후 **외부 공급 여유 300 mA 이상** 보장 |
| 3.3 V 출력 | J1.5, J1.6, J2.1 | 사용자 회로 급전용 |
| VDDA | VDDD에서 페라이트 비드 + LC 필터로 분리 | 옵션: 전용 LDO 실장 |
| ADC 기준전압 | 기본 VDDA, 외부 정밀 기준(U3) 실장 옵션 | J2.4 = VREF_EXT |
| 백업 도메인 | VBACKUP, JP1로 VDDD / 코인셀 선택 | RTC·WCO·백업 레지스터용 |
| I/O 레벨 | 3.3 V CMOS | 5 V 톨러런트 아님 (※ 데이터시트 확인) |
| 발진자 | ECO 크리스털 실장(기본), WCO 32.768 kHz 옵션 | IMO 사용 시 DNP 가능 |
| 디버그 | Cortex Debug 10핀 1.27 mm (J4) | KitProg3 / MiniProg4 / 범용 CMSIS-DAP |
| 동작 온도 | -40 °C ~ +85 °C (모듈 기준) | MCU 는 115 °C 까지이나 LDO·크리스털이 제한 |

## 1.4 모듈이 소모하는 MCU 자원

코어 모듈의 가치는 "사용자에게 몇 개의 핀을 온전히 넘겨주는가" 로 결정된다.
본 모듈이 점유하는 MCU 자원은 아래가 전부이며, **GPIO 60 개는 전부 인출한다.**

| 자원 | 용도 | 사용자 회수 가능 여부 |
|---|---|---|
| XRES | 리셋 (풀업 + 스위치 + 헤더) | 회수 불가 (필수) |
| SWDIO / SWCLK | 디버그 | J4 미사용 시 GPIO 로 재사용 가능 ※ |
| SWO / TDI | 트레이스·JTAG 옵션 | 기본 GPIO, J4로도 인출 |
| ECO 크리스털 2핀 | 외부 발진자 | X1 DNP 시 GPIO 회수 |
| WCO 크리스털 2핀 | 32.768 kHz | 기본 DNP, 실장 시에만 점유 |
| 사용자 LED 1개 | 상태 표시 | JP2 제거로 GPIO 완전 회수 |

> ※ SWD 핀의 GPIO 겸용 가능 여부와 디버그 포트 잠금 정책은 PSC3 보안 설정에 따라 달라진다.
