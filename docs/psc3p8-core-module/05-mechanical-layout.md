# 05. 기구 치수 및 레이아웃 규칙

## 5.1 기판 외형

| 항목 | 값 |
|---|---|
| 외형 | 70.0 mm (L) × 50.0 mm (W) |
| 두께 | 1.6 mm |
| 코너 | R2.0 mm 라운드 |
| 장착 홀 | Ø 3.2 mm × 4 (M3), 코너에서 (3.5, 3.5) mm 오프셋 |
| 최대 부품 높이 | 상단 4.0 mm (J4 제외), J4 는 6.0 mm |
| 하단 | 헤더 테일만 존재. 부품 실장 금지 |

## 5.2 좌표계 및 헤더 위치

원점 = 기판 좌하단, X 는 장변(70 mm), Y 는 단변(50 mm).

| 요소 | 위치 |
|---|---|
| J1 1번 핀 | X = 3.25 mm, Y = 2.14 mm |
| J1 열 | Y = 2.14 mm (row A) / Y = 4.68 mm (row B) |
| J2 1번 핀 | X = 3.25 mm, Y = 47.86 mm |
| J2 열 | Y = 47.86 mm (row A) / Y = 45.32 mm (row B) |
| 헤더 바깥열 간 거리 | **45.72 mm = 18 × 2.54** ✔ 표준 그리드 |
| 핀 스팬 (X 방향) | 3.25 → 64.21 mm (24 × 2.54 = 60.96 mm) |

```
        ← 70.0 mm →
   ┌───────────────────────────────┐  ↑
   │ ○                           ○ │  │
   │  J2 ▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪ │  │   (Y=47.86 / 45.32)
   │                               │  │
   │   ┌────────┐        [J4]      │ 50.0 mm
   │   │   U1   │   X1   [SW1]     │  │
   │   └────────┘   [U2] [JP1..3]  │  │
   │ J3                            │  │
   │  J1 ▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪▪ │  │   (Y=4.68 / 2.14)
   │ ○                           ○ │  ↓
   └───────────────────────────────┘
     ↑ 1번 핀 (사각 패드)
```

- J3(전원 커넥터)와 SW1(리셋)은 기판 가장자리에 두어 캐리어 보드 장착 상태에서 접근 가능해야 한다.
- J4(디버그)는 상단 중앙에 두고, 리본 케이블이 다른 부품을 누르지 않도록 주변 3 mm 키프아웃을 둔다.

## 5.3 층 구성

| 층 | 용도 | 비고 |
|---|---|---|
| L1 (Top) | 부품 + 주 배선 | MCU 팬아웃, 전원 배선 |
| L2 | **연속 GND 플레인** | 분할 금지. 아날로그/디지털 리턴 공통 |
| L3 | 전원 플레인 | +3V3 / VDDA / +5V 영역 분할 |
| L4 (Bottom) | 보조 배선 + 헤더 연결 | 넓은 GND 카퍼 채움 |

### L2 를 분할하지 않는 이유

12-bit ADC 급에서는 그라운드 플레인을 아날로그/디지털로 물리 분할하면 **리턴 경로가 늘어나
오히려 커플링이 커진다.** 대신 L3 전원 플레인에서 VDDA 영역을 분리하고, 아날로그 신호를
L2 위쪽 구간에만 지나가게 배치하는 방식(파티셔닝)을 쓴다.

`AGND` 헤더 핀(J2.3, J2.9)은 모듈 내부에서 **R14 (0 Ω) 한 곳**을 통해 GND 플레인에 접속한다.
이 위치는 MCU 의 VSSA 핀 바로 아래로 한다.

## 5.4 레이아웃 규칙

### 우선순위 (배치 순서)

1. **U1 배치 고정** — 기판 중앙, 회전은 J1/J2 로의 크로스오버가 최소가 되는 방향
2. **디커플링 커패시터** — 각 전원 핀에서 2 mm 이내, 비아는 커패시터 패드에 직결(via-in-pad 불필요, 패드 끝 0.3 mm)
3. **VCCD 커패시터** — MCU VCCD 핀 최근접. **이 부품이 모든 수동 중 최우선**이다
4. **X1 크리스털** — MCU 발진자 핀에서 5 mm 이내, 부하 커패시터는 크리스털과 MCU 사이
5. **U2 (LDO)** — 입력 커넥터 쪽. 방열 패드 아래 서멀 비아 9개(3×3, 0.3 mm)
6. 나머지

### 배선 규칙

| 대상 | 규칙 |
|---|---|
| X1 배선 | 최대 5 mm, L1 만 사용, **하단 L2 GND 를 통째로 유지**하고 주변에 GND 가드링 + 스티치 비아 |
| X1 주변 | 크리스털 바로 아래 L2 를 제외한 어떤 층에도 다른 신호 통과 금지 |
| VDDA | 최소 0.5 mm 폭, FB1 이후 다른 부하에 분기 금지 |
| +3V3 주간선 | 최소 0.8 mm 폭 (500 mA 기준) |
| +5V 입력 | 최소 1.0 mm 폭 |
| GND 스티치 비아 | 기판 전면 5 mm 격자, 헤더 GND 핀마다 최소 2개 |
| SWCLK / SWDIO | 최대 30 mm, 인접 GND 핀과 나란히 |
| HRPWM 출력 | 아날로그 영역(J2 측) 통과 금지. L1/L4 로 J1 쪽으로만 |
| 아날로그 입력 | J2 헤더 → MCU 최단 경로, PWM/클럭 배선과 3 mm 이상 이격, 평행 주행 5 mm 이하 |

### 열 설계

U2 최악 손실 0.85 W. SOT-223 (θJA ≈ 60 °C/W, 방열 카퍼 확대 시) 기준:
주위 온도 85 °C 에서 접합 온도 ≈ 85 + 0.85 × 60 = **136 °C** → 여유 부족.

대응:
- U2 탭 카퍼를 L1 에서 최소 200 mm² 확보하고 서멀 비아로 L2/L4 에 연결
- 또는 사용자 급전 부하를 300 mA → 200 mA 로 낮춰 사양 표기
- 또는 전 온도 범위 사용 시 **5 V → 3.3 V 벅 컨버터 변형(-B 파생)** 을 별도 운용

> Rev 0.1 열해석은 계산치이며, **시제품에서 열화상 실측으로 검증할 것**([06-design-checklist.md](06-design-checklist.md) 참조).

## 5.5 실크 표기

| 위치 | 내용 |
|---|---|
| 상단 | `PSC3P8-CM100`, `Rev 0.1`, 제조사/로고 |
| J1 / J2 | 1번 핀 사각 패드 + `1`, 10핀 단위 눈금 표기 |
| J3 | `+5V` / `GND` 극성 |
| JP1 | `VDDD` / `BAT` |
| SW1 | `RESET` |
| 하단 | 전체 핀 신호명 (핀 옆 1:1 대응). 코어 모듈 사용성의 핵심 |

하단면 실크는 헤더에 가려 보이지 않으므로 **핀 이름은 상단면 헤더 안쪽에도 축약 표기**한다.
공간이 부족하면 10핀 간격 그룹 라벨(`D00-D09` 등)만 넣고 전체 표는 데이터시트로 돌린다.
