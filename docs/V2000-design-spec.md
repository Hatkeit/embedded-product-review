## 2. 제품 개요 및 설계 목표

### 2.1 제품 정의

V2000은 태양광 모듈 1장에 직결되는 500 W급 계통연계 마이크로인버터다.
모듈 후면 또는 프레임에 장착되어 모듈 단위 MPPT를 수행하고, 220 V / 60 Hz 단상 계통에
직접 전력을 주입한다. 옥외 무팬(natural convection) 방열, 25년 설계 수명을 목표로 한다.

### 2.3 언폴딩 구조를 선택한 이유와 대가

**얻는 것**

- 출력단 H-브리지가 계통 주파수(60 Hz)로만 스위칭 → 스위칭 손실 실질적으로 0
- DC-DC가 전류를 이미 정현파로 성형하므로 출력 LC 필터가 작아짐 (고주파 성분이 DC-DC 측에만 존재)
- 언폴더는 영전류 부근에서 전환 → 데드타임 설계가 완화됨

**치르는 대가 (설계상 가장 중요한 제약)**

언폴딩 구조에는 **일정한 DC 링크가 존재하지 않는다.** DC-DC 출력이 곧 정류된 정현파이므로,
DC-DC 단은 순시 전력 `p(t) = P(1 − cos 2ωt)` 를 그대로 처리해야 한다.

- DC-DC 순시 피크 전력 = **2 × 500 W = 1000 W**
- DC-DC 입력 전류 RMS = 1.225 × I_DC (§17.2) → **도통 손실이 DC 대비 1.5배**
- 영전압 교차 부근에서 출력 전압이 0 V까지 내려가야 함 → **부스트 계열 토폴로지 사용 불가**

이 두 가지가 §5.1 토폴로지 선정과 §4.3 손실 예산 전체를 지배한다.

### 3.2 절연 경계 및 기준전위

| 영역 | 기준전위 | 절연 등급 |
|---|---|---|
| PV 입력, DC-DC 1차, APD, 주 제어 MCU, RF, CAN | PV(−) | 계통 대비 **강화 절연** |
| DC-DC 2차, 언폴더, EMI 필터, 릴레이, 보호 감시 MCU | 계통 N | — |

- 주 제어 MCU는 **1차측(PV 기준)** 에 배치한다. MPPT·전류 성형·APD 제어가 모두 1차측 신호이므로
  고속 루프에 절연 지연이 끼어들지 않는다.
- 계통 전압·전류는 절연 증폭기(AMC1311 / AMC1301 계열)로 1차측에 전달한다.
- 언폴더 게이트는 절연 게이트 드라이버로 구동한다 (60 Hz 구동이므로 펄스 트랜스가 아닌
  절연 드라이버 IC 필요 — DC 레벨 유지 필수).
- **계통보호 감시 MCU는 2차측에 별도 배치**하고 독립 센싱을 사용한다 (§9.5 이중화).

## 5. 전력단 설계

### 5.1 Stage 1 — 절연형 DC-DC (정현파 성형)

#### 5.1.1 토폴로지 선정

| 후보 | 0 V 출력 가능 | 500 W 적합성 | 판정 |
|---|---|---|---|
| 전류원형 부스트 풀브리지 | **불가** (V_out ≥ n·V_in) | 양호 | **탈락** — 영교차 처리 불가 |
| LLC 공진 | 제한적 (주파수 범위 과대) | 양호 | 탈락 — 광범위 출력 전압 부적합 |
| 위상천이 풀브리지 (PSFB) | 가능 (벅 계열) | 양호 | 차선 — 경부하 ZVS 상실이 영교차 부근 손실 유발 |
| **인터리브드 액티브 클램프 플라이백 (ACF)** | **가능** | 인터리빙 필요 | **채택** |

**채택: 3상 인터리브드 액티브 클램프 플라이백 (ACF)**

- 플라이백은 벅부스트 계열이므로 출력이 0 V ~ 311 V 전 구간을 덮는다 (영교차 처리 가능).
- 액티브 클램프로 누설 에너지를 회수하고 1차 ZVS를 확보한다.
- 3상 인터리빙으로 상당 순시 전력을 333 W로 낮춰 GaN 피크 전류를 관리 가능 범위에 둔다.
- 120° 인터리빙 → 입력/출력 리플 주파수 330 kHz, 필터 소형화.

#### 5.1.3 전압 응력 요약

| 소자 | 응력 계산 | 값 | 선정 등급 | 마진 |
|---|---|---|---|---|
| 1차 GaN (Vds) | V_in(max) + V_out(pk)/n = 60 + 311/6 | 112 V | 150 V | 25 % |
| 2차 정류 (Vr) | V_out(pk) + n·V_in(max) = 311 + 360 | 671 V | 1200 V | 44 % |
| 언폴더 MOSFET | V_out(pk) × 1.1(계통 과전압) = 342 V | 342 V | 650 V | 47 % |

> **n = 6 선정의 트레이드오프**: n을 키우면 1차 전압 응력이 내려가지만 2차 응력이 올라간다.
> n=8이면 1차 94.6 V(150 V 대비 37 % 마진)이나 2차가 791 V로 1200 V 소자 필수가 되고,
> n=6이면 1차 마진이 25 %로 줄지만 2차에 900 V급 선택지가 열린다.
> 현재는 서지 마진 확보를 위해 **n=6 + 1200 V SiC** 를 기준으로 하되,
> 상세 설계에서 실측 링잉 파형으로 재확정한다. **[미결 이슈 OI-01]**

| 스위칭 주파수 | 60 Hz (계통 주파수) |
| Rds(on) | ≤ 150 mΩ @ 25 ℃ |
| 도통 손실 | I²R × 2소자 = 2.27² × 0.3 = 1.55 W |
| 스위칭 손실 | ≈ 0 (영전류 전환) |
| 데드타임 | 100 µs `[산정치]` — §6.5 |
| 게이트 드라이브 | 절연 드라이버 IC (DC 레벨 유지 가능 타입) |

**영교차 처리 원칙**: 언폴더가 전환하기 전에 DC-DC가 먼저 출력 전류를 0으로 만든다.
즉 전류 지령 `i_ref = I_pk·|sin θ|` 를 영교차 전후 ±100 µs 구간에서 강제 0으로 클램프하고,
그 구간 안에서 언폴더를 전환한다. 이 순서가 깨지면 브리지 관통 전류가 발생한다.

### 5.3 능동 전력 디커플링 (APD)

#### 5.3.1 필요성

120 Hz 맥동 전력을 흡수할 에너지 버퍼가 필요하다. 필요 에너지 진폭은
`ΔE = P/ω = 500/377 = 1.33 J` (§17.4).

| 방식 | 버퍼 커패시터 | 판정 |
|---|---|---|
| PV측 수동 (40 V, ±5 % 리플) | **8,300 µF / 63 V** → 전해 필수 | **탈락** — 25년 수명 불가 |
| **PV 병렬 능동 디커플링 (APD, 450 V 버퍼)** | **40 µF / 450 V 필름** | **채택** |

#### 5.3.2 APD 사양

| 항목 | 값 |
|---|---|
| 구조 | 양방향 벅부스트 (2 스위치 + 인덕터), PV 레일 병렬 접속 |
| 버퍼 커패시터 | 40 µF / 450 V 금속화 폴리프로필렌 필름 |
| 버퍼 전압 스윙 | 280 V ~ 420 V |
| 스위칭 주파수 | 110 kHz (DC-DC와 동기) |
| 처리 전력 (피크) | 500 W (순시) |
| 제어 | 계통 전력 피드포워드 + 버퍼 전압 레귤레이션 |
| 목표 성능 | PV측 120 Hz 리플 < 2 %p-p → MPPT 이용률 > 99.5 % |
| 손실 예산 | 1.8 W |

**전해 커패시터 전면 배제.** 옥외 85 ℃ 환경에서 전해 커패시터는 25년 수명의 단일 최대
제약 요소이며, APD는 이를 필름 커패시터로 대체하기 위한 설계 선택이다.
보조 전원 입력 커패시터를 포함하여 제품 내 **모든** 커패시터는 필름 또는 세라믹으로 한다.

#### 5.3.3 APD가 해결하지 못하는 것

APD는 **PV 소스가 보는 전류**를 DC로 만들 뿐이며, **DC-DC 단이 처리하는 순시 전력**은
여전히 0 ~ 1000 W로 맥동한다 (§2.3). DC-DC의 전류 정격은 평균이 아닌 피크로 산정해야 한다.

## 6. 제어 설계

### 6.1 제어 구조 및 루프 대역폭

```
  MPPT (1 Hz)
      │ V_pv_ref
      ▼
  PV 전압 루프 (10 Hz) ──► I_pk (진폭 지령)
                              │
  계통 SOGI-PLL (사이클당) ──► |sin θ|
                              │
                              ▼  i_ref = I_pk · |sin θ|
                    DC-DC 전류 루프 (5 kHz, 110 kHz 샘플)
                              │
                              ▼
                        3상 인터리브드 PWM

  APD 루프 (20 Hz) ◄── V_buffer  + 계통전력 피드포워드
  언폴더 시퀀서 ◄── θ (영교차 검출)
```

| 루프 | 대역폭 | 실행 주기 | 설계 근거 |
|---|---|---|---|
| DC-DC 전류 성형 | 5 kHz `[산정치]` | 110 kHz (PWM 동기) | 360 Hz 고조파까지 충분히 추종 |
| PV 전압 (MPPT 기준) | 10 Hz | 1 kHz | 120 Hz 리플 대비 충분히 낮게 |
| SOGI-PLL | 정정 < 20 ms | 10 kHz | 위상 오차 < 0.5° |
| APD 전압 | 20 Hz | 1 kHz | |
| MPPT P&O | 1 Hz (스텝) | — | §6.2 |

> **핵심 제약**: PV 전압 루프 대역폭은 120 Hz보다 **충분히 낮아야** 한다.
> 그렇지 않으면 APD가 처리해야 할 맥동을 MPPT 루프가 되쫓아가면서 MPP를 이탈한다.

### 6.2 MPPT

| 항목 | 값 |
|---|---|
| 알고리즘 | 가변 스텝 P&O + 주기적 전역 스캔 |
| P&O 주기 | 100 ms |
| 스텝 크기 | 0.1 V ~ 0.5 V (dP/dV 크기에 비례) |
| 전역 스캔 | 15분 주기, 또는 출력 15 % 이상 급변 시 트리거 |
| 전역 스캔 범위 | 28 V ~ Voc |
| 전역 스캔 소요 | < 2 s |
| 목표 정적 효율 | ≥ 99.5 % (EN 50530) |
| 목표 동적 효율 | ≥ 99.0 % (EN 50530) |

전역 스캔은 부분 음영에 의한 다중 피크 상황에서 지역 최대점 고착을 방지한다.
스캔 중 출력은 유지하되 램프 제한을 걸어 계통 플리커를 회피한다.

### 6.3 계통 동기 (PLL)

| 항목 | 값 |
|---|---|
| 구조 | SOGI-QSG 기반 단상 PLL |
| 정정 시간 | < 20 ms (1.2 계통 주기) |
| 정상상태 위상 오차 | < 0.5° |
| 주파수 추종 범위 | 45 ~ 65 Hz (탈조 방지 목적의 광범위) |
| 전압 왜곡 내성 | THD 8 % 조건에서 위상 오차 < 1° |
| 주파수 변화율 내성 | 2 Hz/s |

SOGI는 계통 전압 왜곡·노치에 대해 단순 ZCD 대비 강건하며, 직교 신호에서
전압 진폭을 함께 추정할 수 있어 §9.1 과/저전압 보호에 재사용한다.

### 6.4 전류 성형

전류 지령: `i_ref(θ) = I_pk · |sin θ|`, `I_pk = 2·P_ref/(V_grid,rms·√2·PF)`

| 요구 사항 | 값 |
|---|---|
| 전류 추종 오차 | < 2 % (정격 기준) |
| 3~11차 고조파 보상 | 반복 제어기(RC) 또는 공진 제어기 병용 |
| 부하 계단 응답 | 10 % → 100 % 시 정정 < 2 계통 주기 |
| 계통 전압 왜곡 시 THD | 전압 THD 5 % 조건에서 전류 THD < 5 % |

CCM/DCM 천이 구간(영교차 근방)에서 플라이백의 소신호 전달함수가 크게 바뀌므로
**동작 모드별 게인 스케줄링**이 필요하다. 이 부분이 THD 성능을 결정한다. **[미결 이슈 OI-03]**

### 6.5 영교차 시퀀스

```
  θ → 180°−δ   : DC-DC 전류 지령 램프다운 → 0
  θ = 180°−δ   : DC-DC 게이트 정지 확인 (전류 센서로 i < 50 mA 검증)
  θ = 180°     : 언폴더 전 소자 OFF (데드타임 시작)
  θ = 180°+δ'  : 언폴더 반대 극성 ON
  θ > 180°+δ'  : DC-DC 전류 지령 램프업 재개
```

- δ, δ' 는 각각 100 µs `[산정치]` 를 초깃값으로 하고 THD 측정으로 최적화한다.
- 이 구간의 전류 결손이 **THD의 주 원인**이므로 가능한 한 짧게 하되,
  언폴더 실제 전환 시간(게이트 드라이버 전파 지연 + 소자 턴오프)보다 반드시 길어야 한다.
- 데드타임 축소와 THD 개선 사이의 최적점을 실측으로 찾는다.

### 6.6 상태 머신

| 상태 | 진입 조건 | 이탈 조건 |
|---|---|---|
| `OFF` | 초기 / PV 전압 < 25 V | PV 전압 > 30 V |
| `SELF_TEST` | PV 기동 | 절연저항·릴레이 용착·센서 자가진단 통과 |
| `GRID_MONITOR` | 자가진단 통과 | 계통 전압·주파수 정상 **5분** 연속 유지 |
| `SOFT_START` | 계통 정상 5분 경과 | 출력 램프 완료 (§9.1 재연계 램프율) |
| `MPPT_RUN` | 소프트스타트 완료 | 보호 트립 / 일사 소실 / 원격 정지 |
| `DERATE` | 방열판 > 75 ℃ 또는 계통 과전압 | 조건 해소 |
| `FAULT_RECOVERABLE` | 계통 이상, 과열 | 조건 해소 후 `GRID_MONITOR` 로 복귀 |
| `FAULT_LATCHED` | 절연 이상, 릴레이 용착, HW 과전류 | 전원 재투입 또는 원격 리셋 |

오프셋 드리프트가 2 mA 이하여야 하므로, **기동 시 및 30분 주기로 영점 보정**을 수행한다.

| 수동 방식 | OV/UV, OF/UF (§9.1), 위상 도약 검출 |
| 검출 시간 | < 0.5 s (KS C 8565 요구) |
| 목표 검출 시간 | < 0.3 s `[설계 마진]` |
| 비검출 영역 (NDZ) | RLC 품질계수 Q=1.0 공진 부하에서 NDZ 없음 |
| 다중 인버터 간섭 | 위상 주입에 유닛별 랜덤 오프셋 적용 |

능동 방식은 정상 계통에서 THD를 악화시키므로, 주입 크기는 THD 기여 < 0.5 %p 를
상한으로 두고 검출 시간 요구를 만족하는 최소값으로 튜닝한다. 다중 유닛이 한 계통에
병렬 연결될 때 주입 신호가 상쇄되지 않도록 유닛별 랜덤 위상 오프셋을 둔다.

### 9.3 DC측 보호

| 보호 | 임계값 | 동작 |
|---|---|---|
| 역접속 | — | 이상 다이오드 회로로 차단, 자기복구 |
| 입력 과전압 | > 65 V | 즉시 정지, 래치 |
| 입력 과전류 | > 20 A | HW 비교기 사이클별 제한 + 3회 연속 시 래치 |
| 절연 저항 (기동 전) | < 1 MΩ | 기동 금지, 래치 (IEC 62109-2) |
| 절연 저항 (운전 중) | 30분 주기 감시 | 저하 시 정지 |
| 아크 고장 검출 (AFCI) | 옵션 | 수출 사양 대응 |

### 9.4 열 보호

| 임계 | 동작 |
|---|---|
| 방열판 > 75 ℃ | 선형 디레이팅 시작 |
| 방열판 > 90 ℃ | 출력 50 % 제한 |
| 방열판 > 95 ℃ | 정지, 온도 하강 시 재기동 |
| 트랜스 > 120 ℃ | 정지 |
| MCU 내부 > 105 ℃ | 정지 |

### 9.5 이중화 차단 수단

IEC 62109-2 및 계통연계 요구에 따라 **독립적인 2중 차단 수단**을 구성한다.

| 계층 | 수단 | 제어 주체 |
|---|---|---|
| 1차 차단 | DC-DC 게이트 정지 (전력 주입 즉시 중단) | 주 제어 MCU |
| 2차 차단 | AC 릴레이 2개 **직렬** 개방 (물리적 분리) | 계통보호 감시 MCU (독립) |

- 두 MCU는 서로를 상호 감시한다. 주 MCU 워치독 만료 또는 하트비트 소실 시
  감시 MCU가 독자적으로 릴레이를 개방한다.
- 감시 MCU는 **자체 전압·주파수 센싱**을 사용하며 주 MCU 측정값에 의존하지 않는다.
- **릴레이 용착 검출**: 기동 전과 정지 후에 릴레이 양단 전압을 측정하여 접점 상태를
  확인한다. 용착 검출 시 `FAULT_LATCHED` 진입 및 재기동 금지.

### 주요 리스크

1. **열 (OI-08)** — 현재 손실 예산과 무팬 IP67 구조의 조합이 45 ℃ 정격 출력을 만족하지 못한다.
   4상 인터리빙으로 손실을 15 W까지 낮추면 방열판 온도는 72 ℃로 내려가 기준을 만족하지만
   BOM 비용과 면적이 증가한다. **비용 vs 사양의 경영 판단이 필요한 항목.**
2. **THD** — 언폴딩 구조의 THD는 영교차 데드타임(§6.5)과 CCM/DCM 천이(§6.4)에서 결정된다.
   시뮬레이션만으로는 예측 정확도가 낮아 시제품 실측이 필수다.
3. **단독운전 vs THD** — 능동 주입 크기가 두 사양을 반대 방향으로 민다. 계통 임피던스가
   높은 농촌 배전선로 조건에서의 검출 성능을 별도 확인해야 한다.
4. **500 W 단일 채널** — 대부분의 상용 언폴딩 마이크로인버터는 채널당 250~350 W다.
   500 W 단일 채널은 §2.3의 2배 순시 전력 제약을 그대로 받으므로,
   4상 인터리빙 또는 2채널 250 W 구성으로의 설계 변경 가능성을 열어둔다.

## 17. 부록 — 계산 근거

### 17.1 정격 전류

```
AC 정격 전류     I_ac = P / V = 500 / 220 = 2.27 A rms
AC 피크 전류     I_pk = 2.27 × √2 = 3.21 A
AC 피크 전압     V_pk = 220 × √2 = 311.1 V
DC 입력 전력     P_dc = 500 / 0.96 = 520.8 W
DC 입력 전류     @ Vmp 40 V : 520.8 / 40 = 13.0 A
                 @ Vmp 34 V : 520.8 / 34 = 15.3 A  → 정격 상한 16 A 설정
```

### 17.2 언폴딩 구조의 순시 전력과 RMS 계수

```
순시 출력 전력   p(t) = V_pk·I_pk·sin²(ωt) = P·(1 − cos 2ωt)
                 → 최대 2P = 1000 W, 최소 0 W

DC-DC 입력 전류  i(t) = I_DC·(1 − cos 2ωt)
RMS             I_rms = I_DC·√(1 + 0.5) = 1.225·I_DC
피크            I_peak = 2·I_DC

@ Vmp 34 V :    I_DC = 15.3 A → I_rms = 18.7 A, I_peak = 30.6 A  (정격 32 A 설정)
도통 손실 비율   (1.225)² = 1.50 → DC 대비 1.5배
```

### 17.3 트랜스 권선비

```
플라이백 전달식   V_out = n·V_in·D/(1−D)

n = 6, V_in = 28 V, V_out = 311 V 조건:
  D/(1−D) = 311/(6×28) = 1.851 → D = 0.649   (최대 듀티, 여유 확보됨)

n = 6, V_in = 60 V, V_out = 311 V 조건:
  D/(1−D) = 311/(6×60) = 0.864 → D = 0.464

1차 전압 응력    V_ds = V_in(max) + V_out(pk)/n = 60 + 311/6 = 111.8 V  → 150 V GaN
2차 전압 응력    V_r   = V_out(pk) + n·V_in(max) = 311 + 360 = 671 V    → 1200 V SiC
```

### 17.4 전력 디커플링 에너지

```
맥동 전력 성분   p_ac(t) = −P·cos(2ωt),  2ω = 2π×120 = 754 rad/s
에너지 편차      E(t) = −P·sin(2ωt)/(2ω)
Peak-to-peak     ΔE = 2 × P/(2ω) = P/ω_line = 500/377 = 1.33 J

수동 (PV측 40 V, ±5 %):
  ΔE = ½C(V₁² − V₂²) = ½C(42² − 38²) = ½C × 320
  C = 2 × 1.33 / 320 = 8.3 mF  → 63 V 전해, 25년 수명 불가

능동 (APD 버퍼 280~420 V):
  ΔE = ½C(420² − 280²) = ½C × 98,000
  C = 2 × 1.33 / 98,000 = 27 µF  → 마진 포함 40 µF / 450 V 필름  ✓
```

### 17.5 언폴더 도통 손실

```
경로당 소자 2개 직렬, Rds(on) = 150 mΩ (25 ℃), 고온 계수 1.6 적용 시 240 mΩ
P = I_rms² × 2 × R = 2.27² × 2 × 0.15 = 1.55 W   (25 ℃ 기준)
                   = 2.27² × 2 × 0.24 = 2.47 W   (100 ℃ 기준)
```

### 17.6 열저항 요구

```
주위 45 ℃, 손실 20.8 W, 방열판 상한 75 ℃ (디레이팅 개시점) 조건:
  R_th(요구) = (75 − 45) / 20.8 = 1.44 ℃/W

현재 목표 R_th = 1.8 ℃/W → 방열판 온도 = 45 + 20.8 × 1.8 = 82.4 ℃  ✗ 초과

대안 (a) R_th 개선 : 1.3 ℃/W → 45 + 27.0 = 72.0 ℃  ✓
대안 (b) 손실 축소 : 15 W @ 1.8 ℃/W → 45 + 27.0 = 72.0 ℃  ✓
```
