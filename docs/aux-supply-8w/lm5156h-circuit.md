### 3.1 UVLO 분압 계산 (DS Eq.1/2)

```
R_UVLOT = (V_ON × V_UVLO(F)/V_UVLO(R) − V_OFF) / I_UVLO
        = (16 × 1.45/1.5 − 14) / 5 µA = 293 kΩ → 294 kΩ
R_UVLOB = V_UVLO(R) × R_UVLOT / (V_ON − V_UVLO(R)) = 1.5 × 294k / 14.5 = 30.4 kΩ → 30.1 kΩ
실제 : V_ON = 1.5 × (294+30.1)/30.1 = 16.15 V,  V_OFF = (1.45 − 5 µA × 27.3 k)/0.0929 = 14.14 V
```

정지 직전 14.1 V 전부하는 D 0.68 / (t_on+t_off) 0.98 T — DCM 경계지만 **운전범위(18 V 이상) 밖의 과도 구간**입니다. 18 V 이상에서는 0.83 T.

### 3.2 슬로프보상과 COMP 동작점 (DS 9.3.7)

| 항목 | 값 |
|---|---|
| 1차 환산 하강 기울기 m2 = VOR/Lp | 0.80 A/µs → × Rcs = 26.3 mV/µs |
| CCM이라면 필요 램프 (Eq.8, ×1.2) | 15.8 mV/µs |
| 고정 램프 40 mV × fsw | 4.0 mV/µs |
| 82 % 보상 RSL (Eq.9) | **5.9 kΩ > 최대 2 kΩ** — CCM 보상 불가 |
| **결론** | **DCM 유지가 설계의 필수 조건.** Lp 공차 ±5 % (fsw +15 % 코너에서 0.92 T), DITHOFF = VCC |
| V_COMP @18 V 전부하 | (Rcs·Ipk 79 mV + 램프 21 mV + 오프셋 170 mV) / 0.142 = **1.90 V** |

## 4. 루프 보상 (Type-2)

**플랜트** — DCM 피크전류모드 플라이백 (S1 기준, 1차):

```
변조기   k_mod = 0.142 / (Rcs + 40 mV·Lp·fsw/Vin)  = 3.38 A/V @18 V, 3.92 A/V @50 V
전력     i_out = 0.5·Lp·Ipk²·fsw·η_t / V_out          (η_t 0.90)
소신호   G(s) = (Lp·Ipk·fsw·η_t/V_out)·k_mod / (s·C_out + G_conv + G_load)
         G_conv = P/V² = 0.262 S (DCM 고유),  G_load = ±0.262 S (저항 / 정전력)
C_out    Co1 66 µF×0.6 (X7R DC 바이어스) + POL 입력 20 µF + Co1b 100 µF 폴리머 = 160 µF → 극점 523 Hz
```

**보상기** — gm 2 mA/V, 분압비 1/6, Z_c = (R_COMP + 1/sC_COMP) ∥ 1/sC_HF ∥ 10 MΩ. 반주기 지연 포함.

| 조건 | fc | PM | GM |
|---|---|---|---|
| 18 V, 저항 부하 | 4.2 kHz | 81° | 20 dB |
| 18 V, **정전력 부하 (POL)** | 4.2 kHz | **74°** | 19 dB |
| 50 V, 저항 부하 | 4.7 kHz | 79° | 19 dB |
| 50 V, 정전력 부하 | 4.7 kHz | 73° | 18 dB |

C_out 감도 (정전력, 18 V): 30 µF → fc 20 kHz / PM 31° ✘, 60 µF → 10.6 kHz / 57°, 120 µF → 5.6 kHz / 71°.
→ **Co1b 100 µF 폴리머는 루프 조건입니다.** 빼면 fc가 fsw/5를 넘어 PM이 무너집니다.

**Co1b를 넣은 이유 (Rev.D 변경)**: 60 µF로는 부하 50→100 % 스텝에서 언더슈트 8.5 %(5.49 V)였습니다. 5 V 동기벅의 헤드룸이 0.5 V로 줄어 위험해 100 µF/10 V 폴리머(ESR 30 mΩ, 영점 53 kHz)를 추가하고 R_COMP를 976 Ω → 2.49 kΩ로 다시 잡아 언더슈트 **3.6 %**로 낮췄습니다.

## 8. 레이아웃 (DS 12.1 + 100 mV 문턱 대응)

1. **Q1–Rcs–Cin–T1 1차 루프**를 최소화. Rcs는 PGND 핀 바로 옆.
2. **CS는 Rcs 상단에 켈빈**, C_F는 CS 핀과 PGND 사이 최근접. 게이트 루프(GATE–R_G–Q1–Rcs–PGND)와 분리.
3. **AGND**: R_UVLOB, RT, C_SS, R_FBB, 보상망을 AGND 평면에, EP를 AGND에. PGND와는 IC 아래 1점.
4. C_VCC는 VCC–PGND 핀 최근접. C_BIAS도 BIAS–PGND 최근접.
5. **100 mV 문턱**은 리딩엣지 스파이크에 민감합니다. R_G를 10 Ω에서 시작해 실측으로 조정하고, 필요하면 C_F 1 nF까지 (τ 100 ns, CL 무효 < 200 ns — 정격 t_on 1.9 µs 대비 여유).
