## 3. 심볼 라이브러리 (LIB)

### 001-LIB-01 [필수] 중앙 라이브러리 단일화

회로도 심볼은 **사내 중앙 라이브러리 하나**에서만 가져온다. 과제별·버전별 라이브러리를 만들지 않는다.

> **근거**: V2000 회로도는 심볼 라이브러리 **19개**를 섞어 쓴다. `SCH_MICROINV_V1001`부터 `V2005_1`까지 버전별 라이브러리가 11개이며, 어느 것이 최신이고 검증된 것인지 알 수 없다.

### 001-LIB-02 [필수] 1 사내품번 = 1 심볼 = 1 풋프린트

- 하나의 사내 품번에는 **심볼 하나, 풋프린트 하나**만 연결한다.
- **디자인 캐시에서 심볼을 직접 수정하지 않는다.** 수정이 필요하면 중앙 라이브러리를 고치고 캐시를 갱신한다.

> **근거**: OrCAD는 캐시에서 심볼을 고치면 `_19`, `_20`처럼 번호 붙은 복제본을 만든다. V2000에서 **PMEG10010ELR 한 부품이 심볼 6개**(`DIODE`, `DIODE SCHOTTKY_25, _26, _28, _29, _39`), **BAS100CS는 5개**, 전류검출 변압기 PA1005는 4개로 흩어져 있다. 같은 부품이 서로 다른 심볼을 쓰는 사례가 8건이다. 한 곳을 고쳐도 나머지에 반영되지 않는다.

### 001-LIB-03 [필수] 심볼 형상은 소자 기능과 일치

심볼 모양만 보고 소자의 종류와 극성을 알 수 있어야 한다. **핀 수가 맞는다는 이유로 다른 소자의 심볼을 빌려 쓰지 않는다.**

> **근거**: V2000에서 기능과 다른 심볼을 쓴 사례.

| 부품 | 실제 소자 | 사용한 심볼 | 문제 |
|---|---|---|---|
| D23, D24 | **SCR** (S8008D) | `PHOTODIODE_1` | 게이트 단자가 핀 "3"으로만 표시됨. 언폴딩 브리지 검토 시 오인 |
| D27 | **GDT** (SL1411A600) | `DIODE_25` | 서지 보호 경로 파악이 어려움 |
| TH1 | **SIDACtor** (P2600S) | `VARISTOR_0` | 바리스터로 오인 |
| Q12~Q14 | **650·800 V MOSFET** | `2N7000` | 소신호 FET로 오인, 고압 소자임이 드러나지 않음 |
| Q1~Q8 | 150 V MOSFET (BSC093N15NS5) | `IRF1010E/TO` | 다른 품번 이름 |
| U19 / U20 | TPM / CAN 트랜시버 | `ZSR800/SOT` | 전혀 다른 부품 이름 |
| U13, U14 | 게이트 드라이버 2EDN7524 | `1ED3491MC12M` | 다른 품번 |
| U28 | **비교기** MCP6567 | `TLV9062` (**연산증폭기**) | 기능 오인 |
| ZD1~ZD4 | TVS PTVS3V3 | `BAT54` (쇼트키) | 기능 오인 |
| D2, D13 | TVS SMCJ64A | `DIODE SCHOTTKY` | 기능 오인 |
| D40 / D41 | **양방향** TVS | `DIODE_41` (단방향 형상) | 방향성 오인 |

### 001-LIB-04 [필수] 핀 이름·번호는 데이터시트와 일치

- 핀 번호와 핀 이름은 **데이터시트 그대로** 쓴다.
- 전원 핀은 숨김 핀(hidden power pin)으로 만들지 않는다. 숨김 전원 핀은 같은 이름의 넷에 암묵적으로 연결되므로, 의도와 다른 넷에 붙어도 회로도에서 보이지 않는다.
- 같은 이름의 전원 핀이 여러 개인 부품(예: MCU의 VDD·VSS)은 핀 이름에 고유 접미를 붙인다 (예: `VDD_1`, `VDD_2`).

> **근거**: V2000 `netlist.log`의 경고 53건 중 **50건이 같은 이름 전원 핀의 자동 개명**(ORCAP-36042, STM32G474·ESP32-S3·USB-C·TPM 심볼)이다. 동작 문제는 아니지만, 이런 경고가 쌓이면 **정말 확인해야 할 경고**(아래 001-LIB-05의 ORCAP-36038)가 묻힌다. 목표는 **경고 0건**이다.

### 001-LIB-05 [필수] No_connect 속성은 데이터시트상 NC 핀에만

> **근거**: V2000 ISO2(MOC3063)의 2번 핀(LED 캐소드)에 No_connect 속성이 잘못 붙어 있었다. 넷리스터가 경고(ORCAP-36038)를 내고 무시했기 때문에 동작은 정상이지만, 같은 부품 ISO3에는 그 속성이 없어 심볼이 일관되지 않다.

### 001-LIB-06 [필수] 신규 부품 등록 절차

| 단계 | 담당 | 산출물 |
|:-:|---|---|
| 1 | 설계자 | 등록 요청 (데이터시트, 사용 과제) |
| 2 | 라이브러리 담당 | 심볼·풋프린트·속성 작성 (§4 속성 전부) |
| 3 | **작성자가 아닌 1인** | 검증 — 아래 체크리스트 |
| 4 | 라이브러리 담당 | 승인, `STATUS=승인`으로 배포 |

**검증 체크리스트**: 핀 번호·이름 데이터시트 대조 / 심볼 형상이 기능과 일치 / 풋프린트 치수 데이터시트 대조 / 1번 핀·극성 표시 / 필수 속성 누락 없음 / 안전 등급 기재(해당 시).

## 4. 부품 속성 (ATT)

### 001-ATT-01 [필수] 필수 속성

값·정격·품번을 한 필드에 섞어 쓰지 않고 **속성별로 분리**한다. BOM과 검토 도구가 속성을 읽어 자동 판정할 수 있게 하기 위함이다.

| 속성 | 예 | 필수 대상 |
|---|---|---|
| `PART_NUMBER` | 사내 품번 | 전 부품 |
| `MPN` | B32021A3472K000 | 전 부품 |
| `MANUFACTURER` | TDK (EPCOS) | 전 부품 |
| `VALUE` | 4.7nF | 수동 소자 |
| `VOLTAGE` | 300VAC | 콘덴서, 저항(고압부), 다이오드, FET |
| `TOLERANCE` | 10% | 수동 소자 |
| `POWER` | 0.25W | 저항 |
| `TEMP_RANGE` | -40~105℃ | 전 부품 |
| **`SAFETY_CLASS`** | **Y2** / X2 / Y1 / X1 | **EMI 억제 콘덴서 — 필수** |
| **`INSULATION`** | **강화** / 기초 / 기능 | **절연 부품**(광커플러, 절연 IC, 변압기) |
| **`ISO_RATING`** | 5000Vrms, VDE 0884-17 | 〃 |
| `PCB_FOOTPRINT` | CAPRR1000W60L1300T500H1100 | 전 부품 |
| `DATASHEET` | URL 또는 사내 문서 경로 | 전 부품 |
| `STATUS` | 승인 / 임시 / 단종 | 전 부품 |

> **근거**: V2000 BOM은 `"4.7nF/300VAC,B32021A3472K000"`처럼 값·정격·품번이 한 필드에 섞여 있고, `"100nF"`, `"10uF"` 등 **정격 전압이 없는 콘덴서가 다수**다. 안전 등급도 없어서, 적합성 검토 때 C162/C164가 Y2인지 X2인지 **외부 데이터시트를 조회해야 했다.**

### 001-ATT-02 [권장] 회로도 표시

회로도에는 `VALUE`, `VOLTAGE`(해당 시), `SAFETY_CLASS`(해당 시)를 표시한다. 고압부 부품은 정격 전압이 보여야 검토자가 디레이팅을 바로 확인할 수 있다.

## 5. 회로도 작성과 넷 명명 (NET)

### 001-NET-01 [필수] 넷 이름 기본 형식

- 영문 대문자, 숫자, 밑줄(`_`)만 쓴다. 공백·`/`·`-`·`+`는 넷 이름 중간에 쓰지 않는다 (전원 접두 `+`는 예외).
- 액티브 로우 신호는 접두 `n`을 붙인다 (예: `nRESET`). `/RESET` 형식은 쓰지 않는다.
- 차동·극성 쌍은 접미 `_P` / `_N`을 붙인다 (예: `I_GRID_P`, `I_GRID_N`).

> **근거**: V2000은 `/RESET_C`, `/BOOT_C`처럼 `/`를 쓴다. 일부 CAM·검증 도구는 `/`를 경로 구분자로 해석한다. 또한 `_N`이 극성(Negative)과 중성선(Neutral) 두 의미로 함께 쓰여 혼동된다 (§001-NET-04 참고).

### 001-NET-02 [필수] 전원 넷

형식: `+{전압}V{소수}[_{도메인}]` — 소수점은 `V`로 대체한다.

| 예 | 의미 |
|---|---|
| `+3V3` | 3.3 V (기본 도메인) |
| `+12V0_HV` | 고압 측 절연 도메인의 12 V |
| `+5V0_USB` | USB 버스 전원 |

> **근거**: V2000의 `VCC_12V0`은 **계통/고압 측** 도메인에 있지만 이름만으로는 알 수 없다. 릴레이 코일 전원이므로 제어 측 전원으로 오인하면 위험하다.

### 001-NET-03 [필수] 접지 넷 이름에 도메인을 명시

절연 도메인이 둘 이상인 설계는 **모든 접지 넷 이름에 도메인을 붙인다.** 접미 없는 `GND`는 단일 도메인 설계에서만 쓴다.

| V2000 현재 이름 | 실제 도메인 | 표준 이름 |
|---|---|---|
| `GND` | PV(−) = 제어 측 | `GND_PV` |
| `PGND` | **계통/고압 측** | `GND_HV` |
| `GND_EARTH` | 보호접지 | `PE` |

> **근거**: V2000에서 `GND`(제어)와 `PGND`(고압)는 서로 다른 절연 도메인이다. 그런데 "PGND"는 보통 같은 도메인 안의 전력 접지를 뜻하는 이름이라, 두 접지가 절연돼야 한다는 사실이 이름에 드러나지 않는다. **제어 GND 배선이 고압부를 가로지른 V2000의 절연거리 불합격(0.70 mm)도 이 구분이 흐려진 것과 무관하지 않다.**

### 001-NET-04 [필수] 반드시 이름을 붙여야 하는 넷

다음 넷은 자동 생성 이름(`N12345678`)으로 두지 않는다.

- **외부 단자**에 연결된 넷 — 단자 기능으로 명명 (예: `AC_L_TERM`, `AC_N_TERM`, `PV1_POS`, `PV1_NEG`)
- 절연 장벽을 넘는 교락 부품의 양쪽 넷
- 시험점, 보호 회로 출력, 측정용 넷

중성선은 극성 접미 `_N`과 겹치지 않도록 `NEU`로 쓴다 (예: `AC_NEU_TERM`).

> **근거**: V2000의 계통 단자 넷은 `N17838031`, `N17838172` 같은 자동명이다. 이 때문에 적합성 검토에서 **어느 단자가 L극이고 어느 단자가 N극인지 넷리스트만으로 확정할 수 없었다** (누설전류를 두 경우로 나눠 계산해야 했음).

### 001-NET-05 [권장] 시트 구성

- 시트 하나에 기능 블록 하나 (예: 01.PV입력, 02.DC-DC, 03.계통, 04.보조전원, 05.MCU, 06.통신).
- **절연 도메인 경계를 시트 경계와 맞춘다.** 한 시트에 두 도메인이 섞이면 절연 장벽 위치를 점선으로 표시하고 도메인 이름을 적는다.
- 타이틀 블록에 과제명, 리비전, 작성자, 검토자, 날짜를 적는다.

## 6. 절연·안전 설계 (ISO)

계통에 연결되는 제품, 또는 위험 전압과 사용자 접근 회로가 함께 있는 제품에 적용한다.

### 001-ISO-01 [필수] 절연 다이어그램 작성

회로 설계 착수 시 다음을 담은 **절연 다이어그램**을 작성하고, 회로도와 함께 검토받는다.

| 항목 | 예 (V2000) |
|---|---|
| 도메인 목록과 최대 동작 전압 | PV/제어 ≤ 60 Vdc, 계통/고압 250 Vrms (PHV 최대 373 Vpk), PE |
| 사용자 접근 여부 | 제어 측: USB·CAN 커넥터 → **접근 가능** |
| 도메인 간 절연 등급 | PV/제어 ↔ 계통: **강화**, 계통 ↔ PE: 기초 |
| 과전압 범주(OVC)·오염등급 | 계통 OVC III, PD2 (시험기관과 확정) |
| 요구 공간·연면거리 | 강화 5.5 mm / 기초 3.0 mm (KS C 8560 표 4·5) |
| **교락 부품 목록** | T2·T4·T6·T8·T9, ISO1~5, U23·U24, C46·C47, R219·R228, C162·C164 |

> 이 다이어그램이 HW-STD-002의 PCB 절연 제약값과 검증 도구 설정의 입력이 된다.

### 001-ISO-02 [필수] 교락 부품은 장벽 등급에 맞는 부품만 사용

| 부품 종류 | 강화절연 교락 | 기초절연 교락 |
|---|---|---|
| 콘덴서 | **Y1 한 개** 또는 **Y2 두 개 직렬** | Y2 |
| 광커플러·절연 IC | **강화절연 인증품** (VDE 0884-11/17 등), 패키지 연면거리 ≥ 요구값 | 기초 이상 |
| 변압기 | 강화절연 구조 (3중 절연선 등) — 권선 사양서 확보 | 기초 이상 |
| 저항 | §001-ISO-04 | 정격 전압 ≥ 동작 전압 |

- **X 콘덴서(X1/X2)는 선간 전용**이며 절연 장벽 교락에 쓰지 않는다. X 콘덴서를 Y 콘덴서와 직렬로 놓아도 X는 Y 개수에 포함하지 않는다.

> **근거**: V2000에서 계통 단자 → **C58(X2)** → `I_GRID_LK` → **C164(Y2)** → 제어 GND 경로로, 강화절연을 **Y2 한 개**가 담당한다. C164가 단락되면 제어 GND로 약 12 mA가 흐를 수 있다. ISO1(ELD207)은 3 750 Vrms 범용 SO-8로 패드 간 3.95 mm라 OVC III 강화절연(5.5 mm)에 미달한다.

### 001-ISO-03 [필수] 단일 고장 검토

교락 부품 각각에 대해 **"이 부품이 단락되면 사용자 접근 회로가 위험 전압이 되는가?"** 를 검토하고 결과를 절연 다이어그램에 적는다. "그렇다"면 부품을 이중화하거나 등급을 올린다.

### 001-ISO-04 [필수] 저항으로 장벽을 넘는 경우

- 위험 전압을 사용자 접근 회로에 저항으로 연결하는 **비절연 센싱은 원칙적으로 금지**한다. 절연 증폭기 등 절연 부품을 쓴다.
- 불가피하면 **정격을 각각 만족하는 저항 2개 이상을 직렬**로 쓴다. 각 저항의 정격 전압은 최대 동작 전압 이상이어야 하고, 임펄스 전압에 대한 근거가 있어야 한다.

> **근거**: V2000의 R219/R228은 계통선을 제어 GND 기준 연산증폭기에 **20 MΩ 저항 한 개**로 연결한다. 같은 계통 전압을 강화절연 증폭기 U23(AMC3301)이 이미 측정하고 있으므로 이 경로는 삭제 대상이다.

### 001-ISO-05 [필수] 계통 연결부 보호 부품

| 부품 | 규칙 |
|---|---|
| 퓨즈 | 정격 전류 ≥ 최대 연속 전류 ÷ 디레이팅(§7). **차단 용량 ≥ 설치점 예상 단락 전류** — 근거 문서화 |
| 바리스터(MOV) | 최대 연속 전압 ≥ 시험 최대 전압 (KS C 8560이면 공칭의 120 %) |
| 계통 분리 개폐기 | 극수·접점 간격을 적용 규격과 대조 |
| 서지 보호 협조 | MOV·GDT·SIDACtor 조합의 동작 전압을 절연 다이어그램에 기록 |

> **근거**: V2000 F1(0678L9100-02)은 정격 10 A, 차단 용량 **100 A**(AC)다. 계통 측 단락 시 가용 고장 전류가 100 A를 넘으면 안전 차단이 보장되지 않는다.

### 001-ISO-06 [필수] 외부 포트의 접지

USB·CAN 등 외부 기기와 연결되는 포트는 **어느 절연 도메인에 속하는지**, 그 도메인이 대지에 대해 어떤 전위인지 절연 다이어그램에 적는다. 도메인이 대지에 대해 떠 있으면(부유) 외부 기기 연결 시 전류 경로를 검토한다.

> **근거**: V2000의 USB-C 신호 GND 핀 4개가 **1 MΩ ∥ 4.7 nF로만** 시스템 GND에 연결돼 있고, 제어 측 도메인은 계산상 대지 대비 약 21~119 Vac로 떠 있다. 접지된 PC를 연결하면 D+/D− 선으로 전류가 흐를 수 있다.

## 7. 부품 선정·디레이팅 (DRT)

### 001-DRT-01 [권장] 디레이팅 기준 — 초안

> ⚠️ 아래 값은 업계에서 흔히 쓰는 출발점입니다. **사내 신뢰성 목표와 제품 수명에 맞춰 확정**하십시오.

| 부품 | 항목 | 기준 (최대 운전 조건 대비) |
|---|---|---|
| 저항 | 전력 | 정격의 50~60 % 이하 |
| 저항 | 전압 | 정격 소자 전압 이하. 고압부는 직렬 분할 |
| 세라믹 콘덴서 | 전압 | 정격의 50~80 % 이하. **DC 바이어스에 의한 용량 감소** 확인 |
| 전해 콘덴서 | 전압 | 정격의 80 % 이하 |
| 전해 콘덴서 | 온도·수명 | 실측 온도로 수명 계산. 제품 목표 수명 이상 |
| MOSFET / 다이오드 | 전압 | 정격의 80 % 이하 (서지·링잉 피크 포함) |
| MOSFET / 다이오드 | 정션 온도 | 최대 정격 −25 ℃ 이하 |
| 퓨즈 | 전류 | 연속 전류 ≤ 정격의 75 % 수준 (제조사 디레이팅 곡선 우선) |

### 001-DRT-02 [필수] 입력 전압 정격 사슬

입력 단자에 걸리는 최대 전압을 정의하고(예: PV 최대 개방전압, 저온 보정 포함), **입력에 연결된 모든 부품의 정격이 그 값 이상**인지 확인한다. 보호 소자(TVS 등)의 클램프 전압이 보호 대상 부품의 정격보다 낮아야 한다.

> **근거**: V2000 PV 입력 전해 콘덴서는 **63 V**인데, 입력 TVS SMCJ64A는 스탠드오프 **64 V**(항복 71 V 이상)다. TVS가 동작하기 전에 콘덴서가 정격을 넘을 수 있다.

## 8. 회로 검토 체크리스트

설계 검토 회의에서 사용한다. 지적 사항에는 규칙 ID를 적는다.

### 8.1 라이브러리·속성
- [ ] 모든 심볼이 중앙 라이브러리 출처인가 (001-LIB-01)
- [ ] 같은 부품에 심볼 복제본(`_숫자`)이 없는가 (001-LIB-02)
- [ ] 심볼 형상이 소자 기능과 일치하는가 (001-LIB-03)
- [ ] `netlist.log`에 ORCAP-36038(No_connect 무시), 36042(전원핀 개명) 경고가 없는가 (001-LIB-04, -05) **[자동]**
- [ ] 필수 속성이 모두 채워졌는가 — 특히 `VOLTAGE`, `SAFETY_CLASS`, `INSULATION` (001-ATT-01) **[자동]**

### 8.2 넷
- [ ] 접지 넷 이름에 도메인이 붙었는가 (001-NET-03) **[자동]**
- [ ] 외부 단자 넷이 모두 명명됐는가 (001-NET-04) **[자동]**
- [ ] 절연 도메인별 전원 넷 이름에 도메인이 드러나는가 (001-NET-02)

### 8.3 절연·안전
- [ ] 절연 다이어그램이 최신인가 (001-ISO-01)
- [ ] 교락 부품 목록이 넷리스트와 일치하는가 **[자동]** — 검증 도구의 "장벽 교락 부품" 출력과 대조
- [ ] 강화절연 교락 콘덴서가 Y1 또는 Y2×2인가, X 콘덴서가 장벽을 넘지 않는가 (001-ISO-02)

- [ ] 비절연 센싱이 없는가, 있다면 저항 2개 이상 직렬인가 (001-ISO-04)
- [ ] 퓨즈 차단 용량 근거가 있는가 (001-ISO-05)
- [ ] 외부 포트의 도메인·대지 전위가 검토됐는가 (001-ISO-06)
