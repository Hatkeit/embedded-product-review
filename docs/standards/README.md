## 이 표준을 만든 방식

일반 교과서 규칙을 옮기지 않고, **실제 사내 설계(MicroInv V2000)에서 발견된 문제를 규칙으로 바꾸는 것**을 원칙으로 했습니다. 각 규칙에는 근거가 된 사례를 연결했습니다.

| V2000에서 발견된 문제 | 결과 | 막는 규칙 |
|---|---|---|
| 제어 GND가 고압부를 가로질러 배선됨 (0.70 mm) | KS C 8560 절연거리 **치명결함** | 002-LAY-03, 001-NET-03 |
| 비절연 센싱 저항이 제어 GND 동박 안에 배치 (0.20 mm) | 〃 | 002-LAY-02, 001-ISO-04 |
| 단일 20 MΩ 저항·Y2 한 개가 강화절연을 교락 | 단일 고장 시 감전 위험 | 001-ISO-03, 001-ISO-04 |
| 심볼 라이브러리 19개, 같은 부품의 심볼 복제본 최대 6개 | 검토 누락·오류 전파 | 001-LIB-01, 001-LIB-02 |
| SCR을 포토다이오드 심볼로, 800 V MOSFET을 2N7000 심볼로 표기 | 회로 검토 시 기능 오인 | 001-LIB-03 |
| 안전 콘덴서 등급(X2/Y1/Y2)이 속성에 없음 | 적합성 판정에 외부 조회 필요 | 001-ATT-01 |
| 계통 단자 넷이 자동명(N17838031) | L/N 극 판별 불가 | 001-NET-04 |
| PCB 실크에 단자 극성 표기 없음 | 오결선 위험 | 002-FP-08 |
| IPC-2581 출력에 적층 정보 없음 | 내층 절연 판정 불가 | 002-OUT-02 |

## 규칙 표기

| 표기 | 의미 |
|---|---|
| **[필수]** | 반드시 지켜야 함. 예외는 검토 회의록에 사유를 남기고 승인받아야 함 |
| **[권장]** | 특별한 사유가 없으면 따름 |
| **[자동]** | 도구로 검사 가능 (`docs/ks-c-8560/tools/ks8560_pcb_check.py` 등) |

규칙 ID는 `문서-분류-번호` 형식입니다 (예: `001-NET-03`). 설계 검토 지적사항에 ID를 적으면 근거가 명확해집니다.

## 적용 순서 제안

한 번에 전부 적용하면 진행 중인 과제가 멈춥니다. 위험도가 큰 것부터 단계적으로 적용하기를 권합니다.

| 단계 | 적용 대상 | 이유 |
|:-:|---|---|
| 1 | 절연·안전 규칙 (001-ISO, 002-LAY), 출력물 (002-OUT) | 인증 불합격과 안전 사고에 직결 |
| 2 | 넷 명명 (001-NET), 단자 표기 (002-FP-08) | 신규 회로도부터 바로 적용 가능 |
| 3 | 부품 속성 (001-ATT) | 부품 DB 정비가 필요 |
| 4 | 라이브러리 통합 (001-LIB), 풋프린트·패드스택 명명 (002-NAM) | 기존 자산 이전이 필요해 시간이 걸림 |

## 개정 관리

- 표준 원본은 이 저장소의 Markdown 파일입니다. 변경 이력은 git 커밋으로 관리합니다.
- 개정할 때는 각 문서 끝의 **개정 이력**에 변경 내용과 사유를 적습니다.
- 규칙을 삭제할 때는 ID를 재사용하지 않습니다 (기존 검토 기록과의 혼동 방지).
