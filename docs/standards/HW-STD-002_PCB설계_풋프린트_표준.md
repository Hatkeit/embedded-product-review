## 2. 명명 규칙 (NAM)

### 002-NAM-01 [필수] 풋프린트는 IPC-7351B 명명을 따른다

표준 패키지는 IPC-7351B 명칭을 쓰며, **본체 높이와 밀도 레벨 접미를 생략하지 않는다.**

| 종류 | 형식 | 예 |
|---|---|---|
| 칩 저항·콘덴서 | `RESC` / `CAPC` + 길이폭 + `X` + 높이 + 밀도 | `RESC1608X55N`, `CAPC2012X125N` |
| SOIC | `SOIC` + 피치 + `P` + 리드폭 + `X` + 높이 + `-` 핀수 + 밀도 | `SOIC127P600X175-8N` |
| SOT | `SOT` + 피치 + `P` + 폭 + `X` + 높이 + `-` 핀수 + 밀도 | `SOT95P240X100-3N` |
| 레이디얼 콘덴서 | `CAPRR` + 리드간격 + `W` + 리드폭 + `L` + 길이 + `T` + 두께 + `H` + 높이 | `CAPRR1000W60L1300T500H1100` |

**밀도 레벨**: 사내 기본값은 **N (Nominal)**. 고밀도 보드에서만 L, 수작업 납땜·시제품은 M을 쓴다.

> **근거**: V2000 풋프린트 66종 중 **57종이 이미 IPC-7351 형식**이다. 다만 칩 부품 9종(`RESC1005`, `RESC1608`, `CAPC1608` 등)은 **높이·밀도 접미가 없고**, 같은 보드의 `BEADC1608X80N`에는 있다. 높이가 없으면 같은 이름으로 두께가 다른 부품(예: 1608 0.55 mm와 0.8 mm)을 구분할 수 없다.

### 002-NAM-02 [필수] IPC 체계로 표현할 수 없는 부품

모듈·커넥터·자성 부품 등은 **제조사 약어와 품번(또는 시리즈)** 으로 명명한다. 이름만 보고 무슨 부품인지 알 수 있어야 한다.

형식: `{제조사약어}_{품번 또는 시리즈}[_{변형}]`

| V2000 현재 이름 | 문제 | 표준 이름 예 |
|---|---|---|
| `250T-1` | 의미 불명 (Faston 탭) | `TE_FASTON250_PCB` (실제 품번으로) |
| `FGND` | 넷 이름과 혼동, 형상 불명 | 기능·치수 표기 — 예: `MTG_PTH_C800H400` |
| `SMD-4P_6X6` | 부품 종류 불명 (택트 스위치) | `CK_PTS645` 형식 (실제 품번으로) |
| `USB-C_16PIN` | 제조사 미상, 동종 커넥터 간 호환 오인 | `{제조사}_{품번}` |
| `ESP32-S3-WROOM-1` | 제조사 누락 | `ESPRESSIF_ESP32-S3-WROOM-1` |
| `GDTAD800W100L1016` | IPC 체계에 없는 `GDTAD` 접두 | `LF_SL1411` (실제 시리즈로) |
| `XFMR500P3500X3050-16` 등 | 자체 설계 변압기 — 제조사 품번 체계 없음 | **현행 유지** (핀피치·치수·핀수 형식). 권선 사양서 번호를 `MPN` 속성에 기록 |

> 위 "표준 이름 예"는 형식 예시입니다. 실제 이름은 부품 데이터시트로 확정하십시오.

### 002-NAM-03 [필수] 패드스택 명명 — 현행 다수 체계를 표준으로 채택

V2000 패드스택 **64종 중 56종(88 %)** 이 이미 **0.01 mm 단위 체계**를 쓰고 있다. 이를 표준으로 정하고 예외 8종만 정리한다. 예외 중 비아 `VIA0_3-0_6` 하나가 보드 전체 패드의 45 %(8 352개)를 차지하지만, 패드스택 정의 하나를 바꾸면 되므로 이전 부담은 작다.

| 종류 | 형식 (단위 0.01 mm) | 예 | 의미 |
|---|---|---|---|
| SMD 사각 | `R{가로}X{세로}` | `R90X100` | 0.90 × 1.00 mm |
| SMD 원형 | `C{지름}` | `C60` | 지름 0.60 mm |
| 스루홀 원형 | `C{패드}H{드릴}` | `C260H160` | 패드 2.60, 드릴 1.60 mm |
| 스루홀 사각 | `R{가로}X{세로}H{드릴}` | `R170X170H100` | 1번 핀 등 |
| 장공(슬롯) | `R{가로}X{세로}H{슬롯가로}X{슬롯세로}` | `R240X170H170X120` | 현행 유지 |
| 비도금 홀 | 접미 `N` | `C65H65N` | 현행 유지 |
| 비아 | `C{패드}H{드릴}V` | `C60H30V` | 패드 0.60, 드릴 0.30 mm |

**정리 대상 (V2000 기준)**

| 현재 | 문제 | 표준 이름 |
|---|---|---|
| `VIA0_3-0_6` | 소수점 체계 혼용 | `C60H30V` |
| `PAD24` | 이름으로 형상 판단 불가 (실측 1.0 mm 비아 패드) | `C100H{드릴}V` |
| `TH0_8-1_3` | 소수점 체계 혼용 | `C130H80` |
| `TH4_0-8` | 〃 (드릴 4.0, 패드 8.0 mm) | `C800H400` |
| `R25X70T/B`, `R70X25L/R` | 방향 접미 (QFN 변별 패드) | `R25X70`, `R70X25`로 통합하고 방향은 회전으로 처리. 형상이 실제로 다를 때만 접미 허용 |

## 3. 풋프린트 작성 (FP)

### 002-FP-01 [필수] 원점과 방향

- 원점은 **부품 중심**(IPC-7351B).
- 0° 방향은 IPC-7351B 기준(1번 핀 위치 규칙)을 따른다. 픽앤플레이스 회전값이 제조사 장비와 맞는지 첫 생산 때 확인한다.

### 002-FP-02 [필수] 필수 구성 요소

| 구성 | 필수 | 내용 |
|---|:-:|---|
| 동박 패드 | 필수 | 데이터시트 권장 랜드 또는 IPC-7351B 계산값 |
| 솔더마스크 | 필수 | 패드 확장값은 사내 공정 기준 |
| 페이스트마스크 | 필수 (SMD) | 노출 패드는 002-FP-05 |
| 실크 | 필수 | 외곽, 1번 핀·극성 표시 |
| 조립도(Assembly) | 필수 | 본체 외곽 + 참조번호 |
| 배치 경계(Place Bound) | 필수 | **부품 높이 속성 포함** |
| 3D 모델 (STEP) | 권장 | 외함 간섭·절연 거리 확인용 |

### 002-FP-03 [필수] 실크

- 실크는 노출 패드와 겹치지 않는다.
- 1번 핀, 다이오드 캐소드, 전해·탄탈 콘덴서 + 극을 표시한다.
- 부품 본체에 가려지지 않는 위치에 둔다.

### 002-FP-04 [필수] 코트야드

IPC-7351B 밀도 레벨별 여유를 따른다 (N 기준 본체·랜드 외곽에서 0.25 mm).

### 002-FP-05 [필수] 노출 패드(EP)

- 페이스트는 **분할 개구**로 만들고 면적은 패드의 50~80 % 범위에서 공정 기준으로 정한다.
- 방열 비아는 개수·지름·막음 처리(tenting/plugging)를 풋프린트 속성에 기록한다.

### 002-FP-06 [필수] 절연 부품 풋프린트

광커플러, 절연 IC, 변압기, Y 콘덴서, 고압 저항 등 **절연 장벽을 넘는 부품**에 적용한다.

1. 풋프린트 속성에 **1차 측 패드 ↔ 2차 측 패드 최소 거리**를 기록한다 (예: `ISO_GAP=7.90`).
2. 그 값이 부품을 쓸 장벽의 요구 거리 이상인지 **부품 선정 단계에서** 확인한다.
3. 패키지 아래에 슬롯이 필요하면 풋프린트에 포함한다. 슬롯 폭은 오염등급에 따른 최소 폭 이상으로 한다 (KS C IEC 60664-1 — PD2에서 1.0 mm로 알려져 있음, ⚠️ 원문 확인).
4. **슬롯은 연면거리만 늘린다. 공간거리는 해결하지 못한다.**
5. 조립도에 절연 경계선을 함께 그린다.

> **근거**: V2000 절연 부품의 실측 패드 간격.
>
> | 부품 | 간격 | 강화절연 OVC III 5.5 mm |
> |---|---:|:-:|
> | 변압기 T2·T4·T6·T8 | 32.4 mm | ✅ |
> | AMC3301/3302 (SOIC-16 광폭) | 8.1 mm | ✅ |
> | FOD817 / MOC3063 | 7.9 / 7.7 mm | ✅ |
> | **ELD207 (SO-8)** | **3.95 mm** | ❌ |
> | **20 MΩ 저항 (2512)** | **4.10 mm** | ❌ |
>
> 이 값이 부품 속성에 있었다면 회로 설계 단계에서 걸러졌을 것이다.

### 002-FP-07 [필수] 전력 단자·나사 탭

- 풋프린트 속성에 **정격 전류, 체결 형식**(Faston 폭, 나사 규격)을 기록한다.
- 보호접지(PE)용 탭·나사 구멍은 이름과 속성에 **PE 용도**를 명시한다.

> **근거**: V2000에는 같은 `FGND` 풋프린트를 쓰는 탭이 5개인데, **3개(J5·J10·J17)만 PE 넷**이고 J24는 **PE와 분리된 별도 넷**, J18은 `I_GRID_LK` 넷이다. 풋프린트 이름만으로는 어느 것이 보호접지인지 구분할 수 없다.

### 002-FP-08 [필수] 외부 단자 기능 표기

외부 배선이 연결되는 모든 단자 옆 실크에 **기능을 표기**한다.

| 단자 | 표기 |
|---|---|
| 계통 | `L`, `N`, `PE` (또는 ⏚) |
| PV 입력 | `PV1+`, `PV1−`, `PV2+`, `PV2−` |
| 통신·디버그 | `CAN_H`, `CAN_L`, 커넥터 이름 |

> **근거**: V2000 실크에는 블록 이름(`Grid`, `DC/DC`, `DC/AC`, `MCU`, `USB`, `CAN`)만 있고 **단자 극성 표기가 없다.** L·N을 바꿔 연결하면 퓨즈 F1이 중성선 쪽에 오게 된다.

### 002-FP-09 [필수] 풋프린트 검증

작성자가 아닌 1인이 확인한다.

- [ ] 랜드 치수를 데이터시트·IPC-7351B 계산값과 대조
- [ ] 1번 핀 위치와 회전 방향
- [ ] 심볼 핀 번호 ↔ 패드 번호 일치
- [ ] 실크·페이스트·코트야드·높이 속성
- [ ] 3D 모델 정합 (있는 경우)
- [ ] 절연 부품이면 `ISO_GAP` 속성 (002-FP-06)

## 4. 배치·배선 (LAY)

### 002-LAY-01 [필수] 절연 도메인별 넷 클래스와 간격 규칙

HW-STD-001의 **절연 다이어그램**(001-ISO-01)을 입력으로, Allegro Constraint Manager에 도메인별 넷 클래스와 **클래스 간 간격 규칙**을 설정한다.

**예: KS C 8560 마이크로인버터 (계통 OVC III, PD2, 동작 전압 250 V)**

| 클래스 쌍 | 절연 | 최소 간격 (외층) | 근거 |
|---|---|---:|---|
| `NC_PV` ↔ `NC_HV` | 강화 | **5.5 mm** (OVC II면 3.0 mm) | KS C 8560 표 3·4, 인용표준 강화 환산 |
| `NC_HV` ↔ `NC_PE` | 기초 | **3.0 mm** (OVC II면 1.5 mm) | 표 3·4 |
| `NC_PV` ↔ `NC_PE` | 기초 (≤ 71 Vdc) | 0.2 mm → 사내 하한 적용 권장 | 표 3·4 |
| `NC_HV` 내부 L ↔ N | 기능 | 1.0 mm 이상 권장 | 표 5 (인쇄회로, PD2, 250 V) |

- 간격 값은 **과전압 범주와 오염등급이 시험기관과 확정된 뒤** 최종값으로 바꾼다.
- 클래스 간 규칙은 동박(쉐입)에도 적용되도록 설정한다. **[자동]**

### 002-LAY-02 [필수] 도메인 영역 침범 금지

보드에 도메인별 영역을 정하고, **각 도메인의 부품·배선·동박은 자기 영역 안에만** 둔다. 다른 도메인 영역에 들어갈 수 있는 것은 **교락 부품의 패드뿐**이다.

> **근거 (V2000 RC2)**: 계통 전압 센싱 저항 R219/R228이 **제어 측 GND 동박 한가운데**에 배치되고, 계통선 두 가닥이 보드 가장자리를 따라 그 안으로 들어갔다. 결과는 계통선 ↔ 제어 GND **0.20 mm**, L ↔ N **0.59 mm**로 KS C 8560 절연거리 **치명결함**.

### 002-LAY-03 [필수] 교락 부품은 경계선에 걸쳐 배치

교락 부품은 **한쪽 핀은 한쪽 도메인 영역에, 다른 쪽 핀은 다른 도메인 영역에** 오도록 경계선 위에 놓는다. 교락 부품까지 가기 위해 **반대 도메인의 배선을 끌고 들어가지 않는다.**

> **근거 (V2000 RC1)**: Y1 콘덴서 C46/C47과 귀환 저항 R82/R83이 **고압부 한가운데**에 있어, 제어 GND 배선이 BOTTOM → 비아 → TOP으로 **고압부를 가로질러** 올라갔다. 고압부 안의 제어 GND 동박(TOP 61 mm², BOTTOM 77 mm²)이 연결하는 부품은 R82·R83 두 개뿐이었다. 결과는 제어 GND ↔ 고압 **0.70 mm(TOP), 1.65 mm(BOTTOM)**.
>
> 반면 같은 보드의 **변압기 4개는 경계선을 정확히 걸쳐 배치돼 패드 간 32.4 mm**를 확보했다. 이것이 표준 배치다.

### 002-LAY-04 [필수] 동박(쉐입)

- 도메인 경계 근처 동박 이격은 **넷 클래스 규칙으로** 만든다. 수작업 void로 만들지 않는다.
- **출력 전에 동적 쉐입을 반드시 갱신**한다 (out-of-date 쉐입이 없어야 함).

> **근거**: V2000 BOTTOM 제어 GND 동박과 계통선 패드 간격 0.20 mm는 Allegro 기본 간격과 같은 값이다. 고압 간격 규칙이 동박에 적용되지 않았거나 쉐입이 갱신되지 않은 상태로 출력된 것으로 보인다.

### 002-LAY-05 [필수] 절연 경계 표시

- 절연 경계선을 별도 레이어(예: `BOARD GEOMETRY/ISOLATION_BOUNDARY`)에 그린다.
- 조립도에도 경계선과 도메인 이름을 표시한다.
- 연면거리 확보용 슬롯은 002-FP-06의 폭 기준을 따른다.

### 002-LAY-06 [필수] 내층

- 적층(프리프레그 두께·재질·층 수)을 **설계 착수 시 확정**하고 문서화한다.
- 내층 간 절연을 장벽의 일부로 쓰는 경우, 적층 절연 인정 조건과 내층 간격 규칙을 절연 다이어그램에 적는다.
- **강화절연 장벽 바로 아래 내층에는 반대 도메인 동박을 두지 않는 것**을 권장한다.

> **근거**: V2000 내층에서도 제어 측 ↔ 고압 측 간격 1.22 mm(L3), 1.65 mm(L2)가 측정됐으나, 출력 파일에 적층 정보가 없어 적합 여부를 확정할 수 없었다.

### 002-LAY-07 [필수] 보드 외곽과 나사 구멍

고압 동박과 보드 외곽·나사 구멍 사이 간격은 **외함 재질에 따라** 정한다. 금속 외함이나 접지된 방열판이면 **PE와 같은 것으로 보고** 002-LAY-01의 `NC_HV ↔ NC_PE` 간격을 적용한다.

### 002-LAY-08 [권장] 전류 용량

전력 경로 트레이스 폭은 IPC-2152로 계산하고 허용 온도 상승을 명시한다 (예: 20 ℃). 계산 근거를 설계 기록에 남긴다.

## 5. 출력물 (OUT)

### 002-OUT-01 [필수] 출력 전 확인

- DRC 위반 **0건** (예외는 승인 기록 필수)
- 동적 쉐입 갱신 완료 (002-LAY-04)
- 회로도 ↔ PCB 동기화 — 부품 수와 넷 일치 **[자동]**

> V2000은 동기화가 정상이었다 (부품 672/672, 회로도 넷 전부 PCB에 존재, PCB 전용 넷은 Allegro `Unused_` 미사용 핀 162개뿐).

### 002-OUT-02 [필수] IPC-2581 출력에 적층 정보 포함

IPC-2581 rev B로 출력할 때 **적층(Stackup) 정보를 포함**한다.

> **근거**: V2000 IPC-2581 파일에는 적층 정보가 없어, 적합성 검토에서 내층 절연을 판정하지 못했다.

### 002-OUT-03 [필수] 절연거리 자동 검증

절연 장벽이 있는 보드는 출력 전에 절연거리 자동 검증을 실행하고, **위반 0건 결과를 출력 패키지에 첨부**한다.

```bash
python3 docs/ks-c-8560/tools/ks8560_pcb_check.py --pcb {IPC-2581 파일} --net pstxnet.dat --out isolation_check.md
```

> 도구의 판정 기준·도메인 앵커는 과제별 절연 다이어그램에 맞게 설정한다 ([`tools/README.md`](../ks-c-8560/tools/README.md)).

### 002-OUT-04 [필수] 출력 패키지 구성

| 항목 | 형식 |
|---|---|
| 제조 데이터 | IPC-2581 rev B (적층 포함) 또는 ODB++ / Gerber + 드릴 |
| 적층도 | PDF |
| 조립도 | PDF (절연 경계선 포함) |
| BOM | CSV / XLSX (HW-STD-001 §4 속성) |
| 픽앤플레이스 | CSV |
| 3D | STEP (권장) |
| 절연 검증 결과 | Markdown (002-OUT-03) |

## 6. PCB 검토 체크리스트

### 6.1 라이브러리
- [ ] 풋프린트 이름이 IPC-7351B 형식이며 높이·밀도 접미가 있는가 (002-NAM-01)
- [ ] 비IPC 풋프린트 이름에 제조사와 품번이 드러나는가 (002-NAM-02)
- [ ] 패드스택 이름이 표준 체계인가 (002-NAM-03) **[자동 가능]**
- [ ] 절연 부품에 `ISO_GAP` 속성이 있고 요구값 이상인가 (002-FP-06)

### 6.2 절연
- [ ] 도메인별 넷 클래스와 클래스 간 간격 규칙이 설정됐는가 (002-LAY-01)
- [ ] 다른 도메인 영역을 침범한 부품·배선·동박이 없는가 (002-LAY-02)
- [ ] 교락 부품이 경계선에 걸쳐 있고, 반대 도메인 배선을 끌고 들어간 곳이 없는가 (002-LAY-03)
- [ ] 동적 쉐입이 갱신됐는가 (002-LAY-04)
- [ ] 절연 경계선이 그려졌는가 (002-LAY-05)
- [ ] 적층이 확정·문서화됐는가 (002-LAY-06)
- [ ] 절연거리 자동 검증 위반 0건인가 (002-OUT-03) **[자동]**

### 6.3 표기·출력
- [ ] 외부 단자 기능이 실크에 표기됐는가 (002-FP-08)
- [ ] DRC 0건, 회로도↔PCB 동기화 (002-OUT-01) **[자동]**
- [ ] IPC-2581에 적층이 포함됐는가 (002-OUT-02)
